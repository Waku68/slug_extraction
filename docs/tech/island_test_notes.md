# 灰色の島（IslandTest）のメモ

Oct 8, 2026

島全体（東西 1.5 km）を、`island_map.svg` の形と spec 3章の仮の高さで、1枚の地形にした試作。見た目は色分けした灰色で、目印は箱と円柱の仮の物。作り直しは `Slug/IslandTest Build Scene`（`TestScenes/Editor/IslandTestBuilder.cs`。地形は 1800 m 四方、1.76 m ごとの高さ）。

## 中身

| 場所 | あるもの |
| --- | --- |
| 真ん中 | 岩塩の山（頂上 250 m）。東と南はゆるく、西と北は急。尾根と谷筋の凹凸 |
| 北 | 黒い溶岩台地（115 m）、冷えた火口（縁 200 m、中は 150 m のくぼみ）、火口の縁から山へ続く尾根 |
| 西 | 砂漠の台地（150 m、西の海岸へ向かって 40 m まで下がる）。枯れた谷（深さ 104〜114 m、壁は地層の段々）、谷の上の石橋（仮）、山側の入口の峠、南のふちの崩れた坂 |
| 東・南 | 雨の森（うねる地面、山へ向かって上がる）。大ガジュマル（仮：幹、幅 100 m の枝、垂れた根 40 本） |
| 南西 | 低い花の草原（6 m）と菌輪（直径 72 m、色だけ）、塩田（1 m、塩の上の判定つき）、海との間の砂丘 |
| 川 | 東の川（山 → 森 → 東の海）、南の川（山の南 → 草原の北 → 塩田）。水の板と、湿り気が戻る判定 |
| まわり | 海（水面だけ。入ると傷む、はまだ） |

キャンプは2つの仮置き：出る所は東の森（山を向いて始まる）、帰る所は塩田のそば（今の試合の脱出口）。

**試し方**：再生すると始めから10倍速で這う（右上に表示。F4 で普通の速さと切り替え。`DevFastCrawl`、加速と止まるときの滑りも10倍）。平らな所で秒速 12 m、島の端から端まで2〜3分。晴れの昼は乾くので、長く見て回るときは F3 → \ で空を雨にする。

**海岸**：森と草原の海岸は、海の底からゆるく上がって長い浜になり、内陸へ 100〜200 m かけて上がる（いちばん急な所で、草原側 8°、森の側 20° くらい）。砂漠（西）と溶岩台地（北）の海岸は崖のまま。

## 自分で地形を変える

やり方は2つ。**どちらを元にするかを先に決める**（数字で作り直すと、手で直した地形は消える）。

### A. 手で削る・盛る（Unity の地形ツール）

1. IslandTest を開き、Hierarchy の `Map > Terrain` を選ぶ
2. Inspector の Terrain の上に並ぶアイコンから、筆のアイコン（Paint Terrain）を押す。その下のドロップダウンで道具を選ぶ
   - **Raise or Lower Terrain**：クリックで盛る、Shift を押しながらクリックで削る
   - **Set Height**：決めた高さにそろえる（台地の上を平らにする、谷底をならす）
   - **Smooth Height**：なめらかにする（急すぎる所をなだめる。ナメクジは 50° までしか登れない）
   - **Stamp Terrain**：形を押し付ける
   - **Paint Texture**：地面の種類（色）を塗る。森・草原・砂漠・塩・岩・溶岩・谷・菌輪の8色がもう入っている
3. 筆の大きさ（Brush Size、m）と強さ（Opacity）を下で変える。ナメクジは体長 1.1 m、目の高さ 0.47 m。高さ 1 m のこぶで体が隠れる
4. 間違えたら Ctrl+Z。終わったらシーンを保存（Ctrl+S）。地形の高さと色は `Assets/TestScenes/Generated/IslandTest_Terrain.asset` に入る
5. 手で直したあと、目印・川・キャンプ・プレイヤーだけ置き直したいときは、メニュー `Slug/IslandTest Rebuild (keep my terrain edits)`。地形はそのまま残る（川の水の板や目印は数式の場所に置かれるので、地形を大きく変えた所では浮いたり埋まったりする）

**おすすめ**：Package Manager（Window > Package Manager > Unity Registry）で **Terrain Tools** を入れると、侵食（雨で削れた谷筋）、ノイズ（細かい凹凸）、段々（Terrace）、2点を坂でつなぐ（Bridge）などの筆が増える。

### B. 数字で変える（作り直すたびに同じ形になる）

`Assets/TestScenes/Editor/IslandTestBuilder.cs` のいちばん上の「数字（m）」を変えて、メニュー `Slug/IslandTest Build Scene`（約20秒）。

| 数字 | 中身 | 今 |
| --- | --- | --- |
| `IslandWidth` | 島の東西の幅。島の形はそのまま、全体が大きく・小さくなる | 1500 |
| `MountainTop` | 岩塩の山の頂上 | 250 |
| `MountainFootSteep`、`MountainFootGentle` | 山のすその広がり（西と北／東と南）。小さいほど急 | 230、430 |
| `LavaPlateau`、`CraterRim`、`CraterBowl` | 溶岩台地、火口の縁、火口の中 | 115、200、150 |
| `DesertPlateau`、`DesertWestEnd` | 砂漠の台地（東側と西の海岸の近く）。枯れた谷の深さも台地に合わせて変わる | 150、40 |
| `MeadowHeight` | 花の草原と、そのまわりの低い土地 | 6 |
| `ForestRise` | 森が山へ向かって上がる高さ | 55 |

島の形（区画の線、川、谷の通り道）は、同じファイルの `IslandSvg`・`DesertSvg`・`CanyonSvg` などの点の並び（`island_map.svg` の座標）。

**数字で大まかに作って、仕上げを手で**、がいちばん楽。手で直し始めたら、数字の作り直しは使わない（使うなら、先に `IslandTest_Terrain.asset` を複製して取っておく）。

## 分かったこと（決めるときの材料）

- **島は小さく感じる**。山頂から西を見ると、砂漠の台地と谷と石橋、その向こうの海まで、ひと目で見渡せる。端から端まで（山を越えずに）軽くて 25 分くらい
- **山は東から楽、西は崖**（決めたとおり）。ただし**南は急**になった。頂上 250 m と、低い草原（6 m）の北のふちが横に 250 m くらいしか離れていないので、下りきるには平均でも 44°、どこかは 50° を超える。南も楽にするなら、山を低くする（200 m くらい）か、草原を南へ離すか、南は斜めに巻く道（尾根）を作るか
- **枯れた谷は深くて狭い**。谷底から見上げると両側の壁が空を細く切り取る。幅（底 24 m）を広げるか、ところどころ広い所を作ると、谷の中で戦える
- **谷の壁の段々がギザギザ**に見える（1.76 m ごとの地形で段を作ったため）。段々を本物らしくするなら、壁だけモデルにするか、地形を細かくする
- **川の水の板が、坂で階段のように浮いて見える**。川に乗る仕組みを作るときに、水面を坂に沿った形にする
- 滝（山の南のふもと）の崖はまだない
