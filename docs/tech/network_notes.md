> **決まったこと（Oct 11 わくさん）**：**Fish-Net ＋ Steam のロビーと中継**にする。最初の一歩はボット1体（ネットワークなし）から。

**前提（Oct 11 に決まったこと。spec 1章）**
- 最初の版は試合型。出撃ごとに島はまっさら、時計と天気は島の時刻のまま
- 最初のテストは、ホストする人のパソコンがサーバーになる形（専用サーバーなし）。ボット1体 → 2人 → 友達数人。場所は岩塩の山のまわり
- 一番喜ばせたい人は、友達と2〜4人。島に6〜8人くらい
- いつかは、ずっと続く島を専用サーバーで動かす（人が集まったあと）

**この前提から要ること**
1. ホストする形と専用サーバーの形の両方に、同じコードで使える（あとで作り直さない）
2. 友達のパソコンにつなぐ手間がない（ポートを開けなくていい、IP が出ない）
3. 撃ち合いの当たりはホストが決める（ずるの余地を減らす。弾は 200 m/s の塩で、飛ぶ時間がある）
4. 這う速さは 1.2 m/s と遅いので、動きの先読みは凝らなくていい

**友達につなぐ所**（どの仕組みとも組める）
- **Steam のロビーと中継**（Steam Datagram Relay）：Steam の友達をそのまま招待できる。ポートを開けなくていい、IP が相手に見えない、中継は無料（Steam で出すゲームなら）。ストアのページを作る前は、テスト用の番号（480、Spacewar）で試せる
- Unity の Relay／Lobby：Steam を使わないテストに。無料の枠を超えるとお金

## おすすめ：Fish-Net ＋ Steam のロビーと中継

- ホスト（友達と2〜4人）から専用サーバー（ずっと続く島）まで、同じコードで進める
- 撃ち合いに要る「遅れの補正」（撃った人の画面で当たっていたかを、ホストが巻き戻して確かめる）が入っている
- 友達を Steam で招待するだけでつながる。中継は無料なので、**最初のテストから最初の版まで、サーバー代は0円**（1-2 の答えがしばらく要らなくなる）
- Steam でストアのページを作る費用（Steam Direct、1本ごとにかかる登録料）は、ページを出すとき（1-9）に

**サーバー代（1-2）**：ホストする形のあいだは0円。ずっと続く島を専用サーバーに移すときに、改めて見積もる（`agenda.md` 1-2 はそのときに）

## 作り方の決まり（どの仕組みでも同じ）

| もの | 誰が決めるか | 同期のしかた |
| --- | --- | --- |
| 這う動き | 自分のパソコン（ホストは速すぎないかだけ見る） | 位置と向き。遅いので先読みはほぼ要らない |
| 撃つ・当たる | ホスト。撃った人の画面の時刻に巻き戻して当たりを確かめる | 撃った合図だけ送り、弾はみんなの画面で同じように飛ばす |
| 採取（叩く回数、出てくる物） | ホスト | ピッケルの振りと手応えは自分の画面だけ（手触りを守る）。当たったという合図をホストへ |
| 物（地面・手の中） | ホスト | 1個ずつ通信の物にする |
| バッグの中身 | ホスト | 順番つきのリスト（spec 7章のとおり）。中の物は通信の物にしない |
| 天気と時計 | 時刻から計算 | 時刻だけそろえれば同じになる（今の作りのまま） |
| 乾き・体力 | ホスト | 数字だけ |

## 操作（1-10）

ネットワークに移すときは、「キーを読む所」と「動かす所」を分ける必要がある（自分の入力だけを送るため）。そのついでに：
- キーの直書きをやめて、Unity の操作の設定（Input Actions）に移す。コントローラーとキーの割り当ての変更が使えるようになる
- 三人称（V）は開発用だけにする（本番は一人称）
- キーの数を減らす案は、対人テストで遊んでから

## 進める順番（案）

1. 追ってきて撃つボット1体（1人で、ネットワークなし）
2. 操作の設定に移す（キーを読む所を分ける）

4. 採取と手を通る物、バッグの中身
5. Steam のロビーで友達を招待して数人

## 1. ボット1体（Oct 11、できた）

- メニュー `Slug/IslandTest 800 m/Add Bot On The Mountain`：IslandTest_800 の岩塩の山の肩（57〜67 m）に、テスト用の塩のきのこ（9か所×2）とボットを置く。もう一度押すと置き直す
- ボット（`Assets/Raid/SlugBot.cs`）は、プレイヤーと同じ体（`MoveTestBuilder.BuildPlayer`）を、キーの代わりに動かす。動き・目・ピッケル・銃・持ち替えに `driven` を足して、キーとマウスを読まないようにした（ネットワークの相手もこの口で動かせる）
- 動き：岩塩を掘ってバッグに入れる（掘りきったら次へ、なければ山を歩き回る）→ 見える（80 m、前 150°、3 m 以内は後ろでも）・銃声（150 m）・ピッケルの音（35 m）・這う音（5 m）で気づく → 見えてから 0.5〜1.8 秒で撃ち始める（止まっている相手は気づくのが遅い）→ 3〜6 発ずつ、狙いのずれは見つけた直後が大きく、見続けると縮む。弾の落ちと相手の動きを先読みする → 撃たれて体力が 15% 減ると、相手から見えない物陰（12 m 以内）へ入り、2〜4 秒待って、最後に見た場所へ探しに戻る → 25 秒見失うと掘るのに戻る
- 頭の上に今していること（掘る・気配・撃つ・隠れる・探す）と気づき具合を出す（`showState`）。数字はすべてボットのインスペクタで変えられる
- 試したこと：2つ掘りきって岩塩6個をバッグへ。25 m 先に置いたプレイヤーに気づいて撃ち、約 18 秒で体力 100 → 52（ヘルメットと殻板の上から）。撃たれると物陰へ這い、待ってから戻って撃ち合いを続けた
- まだ：雨・夜・霧で見える距離が変わらない、ぬめり跡を読まない、物陰の選び方は単純（地面を見ていない）、プレイヤーとボットの這う動きの絵（シェーダーの時刻）は共通
