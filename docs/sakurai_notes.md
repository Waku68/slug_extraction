# 「桜井政博のゲーム作るには」から、このゲームに使えること

Oct 10, 2026 · Claude がまとめた

**元にしたもの**：YouTube チャンネルの全 261 本（まとめ動画を除く）のタイトルと公式の説明文、それと Claude がもともと知っている各回の中身。動画そのものと字幕は見られなかった（字幕は YouTube 側で取れなかった）。要点は Claude の言葉で短く書き直したもの。細かいところが本編と違うことがあるので、気になる回は本編で確かめる。

**外したもの（このゲームでは絶対に使わない）**：自作の企画コンセプト回（カービィ、スマブラ、パルテナ、メテオス、ムシキングなど）、会社やチームの運営の回（職種、10人チームは7人分、デバッグの体制など）、ドット絵・ファミコン・昔話・グッズ・猫などの雑談、格闘ゲームの入力（昇龍拳コマンド、はじき入力）、ジャンル別の回のうち関係が薄いもの（落ちものパズル、2Dシューティング、JRPG、戦略シミュレーション）、スマブラ専用の仕組み（ふっとばし、フリップモーション、参戦ムービー）。

印：**◎** いますぐ効く（`agenda.md` の項目とつながる）、**○** 作るときに思い出す

## 1. ゲーム性（かけひき）

| 回 | 要点 | このゲームでは |
| --- | --- | --- |
| ◎ リスクとリターン | 面白さの骨組みは「危ないことをすると得をする」の選択。リスクを取る理由とリターンが釣り合っていると、プレイヤーは自分で判断して遊ぶ | 柱1の土台。岩塩の山（危ない・稼げる）と草原（静か・少ない）、重いバッグで帰るか欲張るか。経済の数字（agenda 3-1）を直すときの物差し |
| ◎ ギュッとしてパッと解消 | ゲームはストレスをかけて、それを解放する気持ちよさでできている。かけたストレスに見合う解放を用意する | 「重い荷物で這う緊張 → 帰ってバッグを広げる」。帰還の解放（拠点で広げる演出）を手厚くする理由 |
| ◎ やり直しに見合う魅力はあるか？ | やられたときの罰が大きいゲームは、もう一度やりたいと思える魅力が要る。罰だけ大きいとやめられる | 全部失う設計の最大の宿題（agenda 0-2、2-1）。死んだ直後に「次はこうする」が浮かぶか |
| ◎ リトライは迅速に | ミスのあと、気持ちが冷める前に操作を返す | 倒れてから次の出撃までの手数と時間を短く。拠点で装備を整える時間を減らす（前回と同じ一式で出る、など） |
| ◎ ハンデをつけてバランス調整 | 作り手は慣れているので、初めての人の不自由さを忘れる。自分に縛りをかけて遊んで調整する | わくさんは島を知りすぎている。地図を見ない、F4 の速さなし、知らない人に遊んでもらう |
| ◎ ゲーム性を上げると､一般性が下がる | かけひきを深くするほど、遊べる人は減る | ハードな PvP とかわいい見た目の客層のずれ（agenda 0-2） |
| ◎ 対戦は複雑になるもの？ | 対戦ゲームは放っておくと複雑になる。敷居を下げる努力が要る | 覚えることの多さ（agenda 2-1）。キーの数（1-10） |
| ○ 長所を伸ばし､短所も伸ばす | 問題をなくすために特徴を丸めると、つまらなくなる | 遅さ、数字のなさ、全部失う、は丸めすぎない。短所を目立たない所へ逃がす |
| ○ 平均と平凡は同じ | 何でも公平にそろえると、平凡になる | 区画・銃・塩の性格をはっきり違える（区画を色違いにしない、と同じ考え） |
| ○ どれぐらい良いことをした？ | 報酬は「プレイヤーがどれだけ良いことをしたか」で決める。ただし単調な上り坂にしない | 稼ぎ＝危なさ×うまさ。値打ちの表の決め方 |
| ○ 単調な坂は山登りにならない | 自分も敵も同じように強くなり続けると平坦。上り下りの波が要る | シーズン（雨季の採取 → 乾季の撃ち合い）の波。熟練の伸び方 |
| ○ ごほうび要素はまっ先に | ごほうびは、使う・消費する楽しさとセットで最初から設計する | 持ち帰った物の使い道（拠点、染め、苗床）を後回しにしない |
| ○ 作業ゲームを面白くするには | かけひきがなくても、黙々と続けたくなる面白さはある | 採取の手触り、バッグが埋まる充足感（agenda 2-11） |
| ○ ゲーム性以外の面白さ | 収集、眺める、自慢、景色など、かけひき以外の楽しみも多い | 雄大な景色、図鑑、飾り枠、色 |
| ○ 浮遊感は落ちてこそ生まれる | 気持ちよさは、反対のいやさがあって引き立つ | 雨の安心は晴れの乾きがあってこそ。濡れた地面の「ぬちゃっ」 |
| ○ ランダム性は彩りを添える | 覚えるだけの攻略より、変わる状況に対応する攻略にはランダムが要る | 天気、珍しい物の候補の場所、人の動き |
| ○ ズルを許す | ルールを厳しくしすぎないほうが面白いこともある（チートは別） | 予想外の近道（崖の帯を抜ける抜け道など）を、すぐ塞がない |
| ○ クリアできないよりマシ | ぎりぎりが一番楽しいが、腕はまちまち。届かない人を出さないほうを取る | はじめての人の最初の数回（カタツムリでの出撃など） |
| ○ やられるとスッキリする？ | 勝ち負けの感情は単純ではない | 倒されたあとの気持ちの受け止め方（「どこから何で撃たれたか」） |
| ○ はたして敵は必要なのか | 敵がいなくても成り立つ遊びはある | カタツムリの NPC をどこまで敵にするか |
| ○ 強制感と攻略バランス | やらされる感と自由のどちらに寄せるかを決める | 区画の門（尾根）をどこまで強制にするか |
| ○ ランキングの功罪 | ランキングで楽しめるのは一部の人だけ | 数字を出さない世界と合わせて、ランキングは作らない方向でよい |
| ○ 遊びって､何？ | 人はなぜ役に立たない遊びをするか（有名な本の紹介と考え） | 柱を考え直すときに |
| ○ アクションゲームのゲーム性 | アクションの中のあらゆる所にリスクとリターンがある | 撃つ・隠れる・採る・覗く、それぞれのすきと得 |
| ○ キャラゲームはらしさが第一 | 版権物は「らしさ」が一番 | ナメクジらしさ（這う、乾く、塩に弱い）を手放さない |

## 2. 企画・ゲーム設計

| 回 | 要点 | このゲームでは |
| --- | --- | --- |
| ◎ 初心者にはやさしく､気持ちよく | 初心者にはやさしく、気持ちよくさせる。手加減は失礼ではない | はじめての1時間（agenda 2-1） |
| ◎ 自然なチュートリアル | 説明を読ませるより、ゲームを進めながら覚えられるように | 最初の出撃そのものを教え方にする |
| ◎ 最初にクライマックスを | 最初に遊んでもらうのが一番難しい。最初からぐっと引き込む | 最初の数分で、雨・採る・バッグが膨らむ・見晴らし、を見せる |
| ◎ とにかくゲームさせてみて | 待たせず、すぐ遊ばせる | 出撃までの手数。拠点から島までを短く |
| ◎ ほめてやれ！ | 気持ちよくなるために遊ぶのだから、どんどんほめる | 「すごく良い物」を手に持ったときの体の反応（6章の値打ちの見せ方） |
| ◎ ノーリアクションを排除せよ | ボタンを押したら、必ず何か返す | 這えない所、入らないバッグ、採れない物、にも反応を |
| ◎ 3Dゲームで酔う場合 | 酔いの原因と減らし方 | 低い視点と揺れ（agenda 2-10） |
| ◎ 色が薄れた世界 | 色の見分けが苦手な人への配慮 | 乾き・塩・雨の彩度を色だけで伝えない（agenda 2-7） |
| ◎ いただく時間を意識する | 遊ぶ人の時間をもらっているという意識 | 這う遅さ、帰り道の長さ、眠る 10 分（agenda 2-2、2-5） |
| ◎ コンピュータープレイヤー | 人のように動く CP は難しい。人と CP は根本が違う | カタツムリの NPC、対人テスト用のボット（agenda 0-1、1-3） |
| ○ 良いおつかい、悪いおつかい | 繰り返しの用事も、見せ方と寄り道で楽しくできる | 行商人の注文の札（保留）を作るとき |
| ○ 目の前に吊られたごほうび | ごほうびは目に見える所に吊ると効く | 見晴らしで次の目印が見える（ゼルダの三角）、山頂の岩塩 |
| ○ 見返りを想定する | 強くならないゲームでも、やりがいの見返りを作り込む | 数字の強化なしの成長（図鑑、来歴、色） |
| ○ カスタマイズは想像で遊ぶ | 装備をいじるゲームは、試す前に結果を想像できる手助けが要る | 塩の種類と弾、バッグの種類の違いを分かるように |
| ○ 知っていることは話が早い | みんなが知っている操作の決まりは使う。好みに合わせられることも大事 | WASD・右クリックで構える等の定番に乗る。キーの変更（1-10） |
| ○ あるものでしかわからない | 人は知っている物にたとえてしか新しい物を理解できない | 「タルコフのナメクジ版」のような一言の説明（agenda 1-9） |
| ○ 同じような作品 | 似た作品はあっていいが、何が違うかを持つ | ほかの脱出ゲームとの違い（雨・乾き・這う・数字なし） |
| ○ 分解､考察､再構築 | 既存のゲームを要素に分けて、より良い代わりを探す | タルコフの要素を分けて、残す・替える・捨てるを決める |
| ○ 階層アウトラインでまとめる | 企画や仕様は階層の見出しで整理する | spec の章立て。決まったことだけ残す（agenda 1-4） |
| ○ ワンボタンでできること | 操作を絞るときは、まず体系を分ける | キーを減らす（1-10） |
| ○ スコアの見せかた | 得点も見せ方しだいで意味が変わる | アモレの数字だけは見せる、の見せ方 |
| ○ パラメーターでキャラ立ちを | 数字も表現。平凡な個性にしない | 銃4種、塩3種、バッグ5種の数字にくせを |
| ○ 世界の窓はとっても狭い | 画面に映る範囲は狭い。見える所に集中する | 一人称で何が見えているか。低い目線（0.47 m） |
| ○ フレームはコマ数／フレームを計れるようになれ！ | 時間はフレームで考え、体で計れるようにする | ピッケル、持ち替え、覗くの秒数の調整 |
| ○ 応援する楽しみ | 観戦はどちらかに肩入れすると楽しい | 配信・観戦で見せやすいか（agenda 1-9） |
| ○ ゲームのシナリオは特異 | ゲームの物語は小説や映画と書き方が違う | 島が乾く謎の見せ方（図鑑の古い名前） |
| ○ ゲーム内ムービー | 箸休めと物語の掘り下げのバランス | 大干ばつ、大雨の演出を入れるなら |
| ○ 続編のありかた | 続編には意味がある。まず最初の種をまく | 最初の島1つに絞る（agenda 0-3） |
| ○ ゲーム作りで食っていくには | 仕事にするために要ること | — |

## 3. 仕様

| 回 | 要点 | このゲームでは |
| --- | --- | --- |
| ◎ 遅さは罪 | 遊ぶ人は待たされるのが嫌い。さっさと進める | 這う速さ 1.2 m/s を選んだ以上、それ以外（画面、出し入れ、持ち替え、拠点）は全部速く（agenda 2-2） |
| ◎ 大事なところはストップ！／8つのヒットストップ仕様 | ヒットストップは当たりだけでなく、大事な瞬間すべてに使える | ピッケルは済。いい物が出た瞬間、バッグがいっぱいになった瞬間、撃たれた瞬間にも |
| ◎ How to Play | 説明書がない今、ゲームの中でルールを伝える | 乾き方のルール（濡れて光る＝乾かない）を体で覚えさせる |
| ◎ 物理ボタンに重たさを感じさせる | 操作感がすべて。手で返す遊び | ナメクジの這い出しの重さ、止まるとぬるっと滑る、は済。銃・バッグにも |
| ◎ オンラインアップデート | アップデートはありがたいが、作り手の時間を食う | ずっと続く島の運営の重さ（agenda 1-2、1-11） |
| ○ 画面遷移は素早く | 画面の切り替えは詰める | 拠点 ↔ 島、覗く画面 |
| ○ マップもゲーム画面 | プレイヤーがどこを見ているかを意識して作る | 地図は拠点だけ、は良い判断。目印で迷わないか |
| ○ 速度の単位 | 速さを仕様書と数字で表せるようにする | m/s でそろえている。続ける |
| ○ ランダム性は彩りを添える | （ゲーム性の同名の考えと同じ） | — |
| ○ 注視点をくっつけない | カメラはキャラにぴったり付けず、少し遅れや先読みを | 一人称の揺れ、三人称（V）を残すなら |
| ○ ガケぎわのふるまい | 崖のふちでの動きにも気配りが要る | 50° の境目、崖の帯、ずり落ちる感じ（progress 次にやること3） |
| ○ ジャンプのしくみ | 基本動作ほど作り込む | 這う・縮んで伸びる、の作り込み |
| ○ ハンデブースト | カジュアルに楽しむには、ハンデの仕組みが要る | 初心者救済（カタツムリでの出撃） |
| ○ 想定外の完成形 | 思いどおりにならずに終わることもある | — |
| ○ 重心をズラすとどうなる？ | 当たり前の動きも工夫の余地がある | 飛び散るバッグの中身、投げた物の飛び方 |

## 5. グラフィック

| 回 | 要点 | このゲームでは |
| --- | --- | --- |
| ◎ キャラを立てるデザイン | 立っているキャラはシルエットが良い。白黒にして確かめる | ナメクジ、目印の大きい三角4つ（シルエットを変える、は決定済み）。敵と仲間の見分け（agenda 2-3） |
| ◎ スケール感は正しく合わせる／ミニチュア効果 | 形が同じなら大きさは分からない。存在感の出し方で大きさを伝える。逆に小さく見せる方法もある | 体高 0.5 m から見た雄大さ。巨大に見せたいか、小さな生き物の世界に見せたいか（map の「見た目だけ巨大」案） |
| ◎ 判定のあるものを強調する | 当たり判定のある物（乗れる・ぶつかる）は見て分かるように | 登れない 50° 超えの見せ方、隠れられる物と隠れられない物 |
| ◎ 大事と小事を見分ける | よく見える所にこそ力を入れる | 一人称で毎回見るもの（手、ピッケル、バッグ、地面）を最優先 |
| ◎ 絵はゲームの楽しさに関係ある？ | 大いに関係ある | 灰色の島の次の一歩（agenda 1-5 の見本の1か所） |
| ○ 素材を描かず、光を描く | 素材そのものより光と影で見せる | 雨、濡れた地面、晴れの影（乾き方と直結） |
| ○ 最終出力 | 絵は光を当てて終わりではなく、最後の処理で深みが出る | URP の後処理 |
| ○ タッチを合わせる／アナログな色合い統一／アニメと実写が戦うような | 作り手が多くてもタッチを統一する。数値が同じでも見た目は同じとは限らない。違う調子の物を並べるときの調整 | Slug/Toon と WorldLook（リアル度 0.2）。わくさん・友達・Claude が作る物をそろえる |
| ○ 無いものをあると感じさせる | 重さや存在感のない表示物を、あるように感じさせる工夫 | 手を通る岩塩、膨らむバッグの重さ |
| ○ マンガ的表現 | 3D でもリアルにする必要はない | 「ジュッ」「ぬちゃっ」の瞬間の表現 |
| ○ モーションブラー | 残像は動きを見せるが、嫌われもする | 酔いと合わせて控えめに |
| ○ 監修あれこれ／レタッチ監修／カベ破壊ひとつに | イメージを伝えるには、絵に直接描き込んで指示する | わくさんが Claude に形を頼むとき（スケッチ＋描き込み） |
| ○ ステージをじっくり見てみよう | 完成品を観察すれば多くが分かる | — |

## 6. モーション

| 回 | 要点 | このゲームでは |
| --- | --- | --- |
| ◎ 攻撃モーションの内訳／かまえは瞬時に極端に／フォロースルーで印象が決まる／攻撃ポーズ | かまえ・攻撃・フォロースルーに分けて考える。かまえは速く大きく、フォロースルーが印象を決める | ピッケルの振り（済）と、ナイフ、投げる、苔玉を使う動き |
| ◎ やり過ぎてちょうどよい／情報が減るからおおげさにふるまう | CG や引いた画面では要素が落ちるので、大げさにして丁度よい | 遠くのナメクジの動き（乾いて縮む、撃たれて白くなる）は大げさに |
| ◎ ダメージモーション | ダメージの動きはゲームが返すリアクション | 撃たれたときの体の縮み、触角を撃たれたとき |
| ○ モーション補間のワナ | 補間に任せるともっさりする | シェーダーで這う動きも、メリハリを |
| ○ 扁平スケーリング | 大きさを変えて質感を変える | 縮んで伸びる、乾いて縮む（ナメクジにぴったり） |

## このゲームで特に効きそうな5つ

1. **リスクとリターン**：経済と区画の数字は、すべて「危なさに見合う得か」で見直す（agenda 3-1、3-2）
2. **やり直しに見合う魅力はあるか**：全部失うなら、もう一度出たくなる理由を最初に作る（agenda 0-2、2-1）
3. **遅さは罪**：這う遅さは個性として残し、それ以外の待ち時間は全部削る（agenda 2-2）
4. **重要度で効果音バランスを取る**：PvP の情報としての音の表を作る（agenda 2-9）
5. **ディレクターは切る仕事**：最初の版を小さくする（agenda 0-3）
