## 1. いま触角に乗っている情報と、ほかに出ている所

| 情報 | 誰に | 触角で | ほかで、もう出ている所 |
| --- | --- | --- | --- |
| 自分の体力 | 自分 | 一人称の先が垂れる | 左上の体（白い塩の跡、触角の張り）だけ |
| 相手の体力 | 相手 | 体の触角が垂れる | 白い塩の跡（当たった所に残る） |
| 乾き | 両方 | ツヤが消える、段を越えるとき「きゅっ」 | 体のツヤ・まだら・縮み、這う音（ぬちゃ／かさ）、ぬめり跡、危ないと画面の端がぼやける |
| 撃たれた瞬間と方向 | 自分 | 撃たれた側が引っ込む | 体がぎゅっ、視点が押される、画面の端の塩の粒、パシッと声、撃った音の方向 |
| 仲間の印 | みんな | 布を結ぶ | なし |

**分かったこと**：乾きと撃たれた方向は、もう3つ以上の所に出ている。**触角にしか出ていないのは「体力」と「仲間の印」だけ**。なので、この記録は主に体力の出し方を考えた。

## 2. ひっくり返した前提

- 状態は**体に**出す → 地面・世界・音に出す
- 状態は**見せる** → 聞かせる
- 状態は**いつも**出ている → 確かめたときだけ分かる
- 自分の体力は**自分が一番よく知っている** → 相手や仲間の方がよく知っている
- 弱っても**動きは同じ**（CoD・Apex） → 弱ると姿勢と動きが変わる
- 【決定】体力と湿り気は**別の物** → 1つにする
- 【決定】（Oct 18）体力は**触角**で見せる → 白い塩の跡、目、姿勢で見せる
- 【決定】縮むのは**乾きだけ** → 撃たれても縮む（大きさが体力）

## 4. 反転案

### 4-1. 【決定】「体力は触角」→ 白い塩の跡がそのまま体力。回復すると流れ落ちる

- **形**：当たった所の白い塩の跡（もう決まっている）を、体力と結ぶ。体力が戻るぶん（湿り気で少しずつ）、跡が薄くなって流れ落ちる。雨では早く流れる。白いほど弱っている
- **自分に**：画面の端にこびりつく塩の粒（方向の合図。もう決まっている）を、**体力が戻るまで残す**。減るほど縁が白く狭まる。左上の体も同じ白
- **相手に**：真っ白に近いナメクジは弱っている。触角より大きく、遠くから見える
- **良い所**：新しい物を足さない。「白い塩＝撃たれた量」の決まりを、そのまま「残りの体力」まで伸ばすだけ。1つの見た目に1つの意味のまま。色覚にも強い（白は明るさ）
- **困る所**：乾いて倒れる（塩なし）ときは白くならない。乾きは乾きの見た目（縮む・まだら）で出ているので、分けたままでいい

### 4-2. ジャンル「弱っても動きは同じ」→ 体力は姿勢。弱ると上体が下がる

- **形**：元気だと上体をすっと起こしている。体力が減るほど上体が前へ下がり、首がうなだれる
- **自分に**：目の高さが下がる（0.47 → 0.38 m くらい。人なら 1.7 → 1.4 m）。草の向こうが見えにくくなって、弱ったのが体で分かる
- **相手に**：シルエットで分かる。形は遠くからでも残る
- **良い所**：画面に何も足さない。前例はバイオハザード（危ないと脇腹を押さえて足を引きずる）
- **困る所**：伏せる（頭が下がる）と見分けにくい。わざと伏せて弱ったふり、ができる（これは遊びにもなる）。目が低いと不利が重なる（弱るほど見えない）

### 4-3. ジャンル「体力は画面に出す」→ 顔に出る。まぶたが重くなる

- **形**：弱るほど目が半分閉じていく。眠そうな顔
- **自分に**：画面の上の端から、まぶたのやわらかい影が下りてくる（照準は隠さない。上の4分の1まで）
- **相手に**：前から見ると目が眠そう。5章の「目は大きく表情を出す」と合う。前例は Doom の画面下の顔（撃たれるほど顔が崩れる）
- **良い所**：かわいいまま弱っているのが分かる。触角よりずっと大きい部品
- **困る所**：後ろからは見えない。顔に当たると視界が白くなる（8章）と、画面の上の端で重ならないように分ける

### 4-4. お題「状態は体に出す」→ 地面に出す。手負いのぬめり跡

- **形**：体力が減ると、ぬめり跡に白い塩のかけらが混じる（4-1 と同じ白）。弱いほど多い
- **自分に**：左上の体の後ろのぬめり跡（いまは湿り気の長さ）に、白い点が混じる
- **相手に**：通ったあとの地面で分かる。手負いを跡で追える。前例は Hunt や DayZ の血の跡
- **良い所**：本人がいなくなっても情報が残る。追う・逃げる遊びが生まれる
- **困る所**：跡を追う遊びは、待ち伏せを強くする。雨で消えるなら釣り合う

### 4-5. お題「状態は見せる」→ 聞かせる。呼吸孔の息

- **形**：本物のナメクジは、外套膜の右わきに呼吸孔という息の穴がある。開いたり閉じたりする。弱るほど速く、大きく、音が鳴る（ひゅっ、ぷすっ）
- **自分に**：息の音がだんだん速くなる。画面を見なくても分かる
- **相手に**：近くでは息の音が聞こえる（居場所もばれる）。目で見えるのは近くだけ
- **良い所**：本物のナメクジの体の仕組みが、そのまま遊びになる。音の地図（`sound_map_discussion.md`）に1つ足すだけ
- **困る所**：遠くからは分からない。音を消して遊ぶ人には別の手（4-1）が要る

### 4-6. ジャンル「自分の体力は自分が一番知っている」→ 確かめる仕草をしたときだけ分かる

- **形**：ふだん自分の体力ははっきり出ない（息の音と姿勢だけ）。体を丸めて自分の体を見る仕草（バッグを覗くのと同じ）で、塩の跡がどれだけあるかが見える。その間は前が見えない
- **相手に**：いつも見える（相手の方が自分より自分を知っている）
- **良い所**：タルコフの「体を確かめる」の手間が、遊びになる
- **困る所**：友達が撃たれたことに気づかなかった問題（Oct 18）に戻る。1発目の合図は残すこと

### 4-7. 【決定】「体力と湿り気は別」→ 1つにする。塩は水を抜く

- **形**：体力をなくし、湿り気だけにする。本物のナメクジが塩で弱るのは、塩が体の水を吸い出すから。**撃たれる＝水を抜かれる**。乾いても、撃たれても、同じ1つの「水」が減る。ゼロで倒れる
- **自分に／相手に**：もう作ってある乾きの見た目（ふくらみ・ツヤ・まだら・縮む・ぬめり跡・這う音）が、そのまま体力の見た目になる。触角も目もいらない
- **良い所**：決まりが2つから1つになる。「乾いていると塩が1.2倍効く」「湿っていると体力が戻る」（8章）は、もう半分つながっている。雨の日に撃ち合うと粘れる、晴れの砂の上は撃たれると危ない、が1つの決まりから出る
- **困る所**：雨だと全員が硬くなる。苔玉が回復薬になる。数字の作り直し（何発で倒れるか）。「縮むのは乾きだけ」と「撃たれて縮むのは一瞬の反射だけ」（Oct 18）を見直す

## 5. 極端案

### 5-1. 体の大きさが体力（撃たれるたびに小さくなる）

- **形**：撃たれるたびに塩で水を抜かれて、体がひと回り小さくなる。弱ったナメクジは豆粒。バッグは大きいまま（小さい体に大きな袋）
- **良い所**：遠くから一目で分かる。前例はマリオ（大きい・小さい＝あと何発）
- **困る所**：小さいほど当たりにくい（弱いほど強い）。目の高さも下がる。「縮むのは乾きだけ」と真っ向からぶつかる
- **小さく取り入れるなら**：撃たれた瞬間に縮むのを、戻りきらずに少し残す（4-7 と合わせる）

### 5-2. 画面にも体にも出さない。音だけ

- **形**：左上の体もやめる。自分の体力は、呼吸孔の息と、心臓の音だけ（ナメクジにも心臓がある）。相手の体力は、近くで息を聞いたときだけ
- **良い所**：一番静かで、一番この世界らしい
- **困る所**：音を消して遊ぶ人、耳の聞こえにくい人が遊べない
- **小さく取り入れるなら**：息の音（4-5）を、ほかの見せ方と重ねて足す

### 5-3. 世界が教える。弱ったナメクジに鳥が寄ってくる

- **形**：本物のナメクジを食べるのは、ツグミなどの鳥、カエル、甲虫。体力が減ると、上の空に鳥が回りはじめ、近くの草でカエルが鳴く
- **自分に**：鳥の影と声で、弱ったのが分かる
- **相手に**：遠くから空を見ると、手負いがどこにいるか分かる
- **良い所**：画面にも体にも何も足さない。島の生き物が増える
- **困る所**：弱った人の居場所が、遠くの全員にばれる。逃げきれなくなる
- **小さく取り入れるなら**：鳥は自分の近くにだけ降りてきて鳴く（遠くからは見えない）

### 5-4. 体力は相手にしか見えない

- **形**：自分には、自分の体力が一切見えない（左上の体も白くならない）。仲間が見て、声で教える。ソロは倒した相手から「弱っていた」と分かる
- **良い所**：仲間と遊ぶ理由が強くなる。仲間の声が、そのまま情報
- **困る所**：ソロがきつい。いちばんやりすぎ

## 6. 仲間の印（触角の布のかわり）

- **バッグに結ぶ**：いちばん大きくて、遠くからも、後ろからも見える。膨らむほど目立つ
- **バッグに流木の竿の旗**：自転車の旗のように、長い竿の先に布。遠くからでも分かるが、隠れにくい
- **仲間のぬめり跡だけが光る**：`friend_or_foe_discussion.md` の 2-1 と同じ。体には何も付けない

**「この案で作って『平凡』と言われた。なぜ？」**：体力を画面の縁の色だけで出すなら、どの FPS の「画面が赤くなる」と同じだから。体と世界（姿勢、塩、跡、息）に出してこそ、このゲームの物になる。

**おすすめ**
- **無難**：**4-1 塩の跡＝体力**（自分は画面の縁にこびりついた塩、相手は体の白さ）に、**4-5 呼吸孔の息**を重ねる。仲間の印はバッグへ。触角は耳と乾きのツヤに戻し、垂れは「おまけ」で残してもいい（今日作った物は無駄にならない）
- **攻め**：**4-7 体力と湿り気を1つに**（塩は水を抜く）。見た目はもう作った乾きの見た目がそのまま使え、決まりが1つ減る。姿勢（4-2）を足すと遠くからも分かる
