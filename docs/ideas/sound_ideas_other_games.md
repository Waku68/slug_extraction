# 他のゲームにあって、いまない音（Nov 2, 2026）

わくさん「打ち終わりかけの時の音みたいに、他のゲームにあっていまこれにない音」。
いま鳴っている音（`docs/tech/sound_list.md` の A）と、すでに「音がない」と書いてある物（同じく B）を見たうえで、**他のゲームで「知らせる」ために鳴っている音**を拾った。B と重なる物は最後に1行だけ。

- ★ = おすすめ（数字を出さずに伝えられる、柱1「ゲットした高揚感」に効く、友達の「撃たれたのに気づかない」に効く）
- つなぎ口：**ある**＝コードはもう呼んでいて、音を入れれば鳴る／**少し**＝`SlugSounds.cs` に数行足せば鳴る／**新しく**＝判定の仕組みから作る

## B と重なる物（すでに書いてある）

這う・伏せて這う・よじ登る、水に入る、苔玉で飲む、乾ききる、倒れる、鍋のカン、脱出、釣瓶、鳥の出発、池。

## おすすめの順（2通り）

- **無難（つなぎ口がある・少しで済む物から）**：空撃ち → 残り少ない弾倉 → 当てた手ごたえ（触角は高く）→ 叩くたびに音が上がる → 珍しい物のジングル
- **攻め（このゲームだけの遊びになる物）**：弾がかすめる音（1発目で気づく）→ 驚いた生き物が騒ぐ（音で人を読む・気をつけて這う）→ 雨が上がる合図（乾く時間の予告）

どれも、決まったら擬音を `docs/sound/requests.md` に足せば Argon が作れる。鳴らすコードは Claude がつなぐ。
