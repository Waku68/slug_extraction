# ケルン風の地形：集めた資料と、このゲームでの作り方

Nov 3, 2026 · Claude

わくさん：「ケルン風の地形にしたい。一次情報でもそれ以外でも集めて、このゲームでどう実装できるか吟味して。山は登れないから、山道とか遠くから見る景色が参考にできるのかな」
ここに書くのは案。決めるのはわくさん（いちばん下の「決めてほしいこと」）。まねするのは作り方だけで、ケルンの山や岩の形・区域は写さない。

## 0. 先にこたえ

- **遠くの景色は、ほぼそのまま使える**。ケルンの景色のよさは描き方（空気の層、くっきりした影、大きな面の岩、描いた空）で、登れるかどうかと関係がない
- **山道は、道そのものより「下から壁を読む → 進む → 平らな所で休む」のくり返しが手本**。ケルンでも、雪の中を歩くだけの所は批評で退屈と言われている。このゲームでは「平場や尾根に出て、次の区間を読む（隠れる物・日陰・塩・人）→ 這う → 次の平場」になる。spec の平場・隠してから見せる・1分ごとの密度と同じ形なので、決まりは増やさなくていい
- **少しだけなら登れる**：ナメクジは 0.45 m（人なら 1.6 m）までの段はよじ登れる（`SlugMoveSettings.climbHeight`）。段の並んだ岩は階段、つるっとした岩は壁。ケルンの「壁を読んで筋を探す」は、2〜5 m の岩（人なら 7〜18 m）で小さく持ち込める（崖の帯は尾根からだけ、の決まりは守る）
- **いちばん差が大きいのは影**：いまは本物の影が 14 m 先までしか出ない（URP の設定）。ケルンの絵の半分は影の形。しかもこのゲームでは、日陰は乾きに直結する

## 2. 絵から読んだこと（公式の絵 17 枚。Claude の読み）

1. **近・中・遠の3層**：近くの岩は暖かい色で、線と影がはっきり。中は暗い緑の森の塊と、白っぽい岩の塔。遠くは青く薄い山の重なり。層の間に雲がたまって切れ目になる
2. **影の形が主役**：影の縁は硬く、色は黒でなく濃い青緑。割れ目の下に必ず細い影があって、割れ目が読める。陰の中に漫画の斜線のような線が入る絵もある
3. **岩は大きな平らな面**：細かいのは縁の線と、淡い地衣類のまだらだけ。割れ目の多い所（登れる）と、何もない所（登れない）の差がはっきり
4. **色は反対の2色**：冷たい青灰の岩 × さび色の草。いちばん鮮やかなのは人と道具（赤い綱、青い服）
5. **描いた空**：大きな積雲、地平線が明るい。朝夕は頂上だけ桃色に光り、下は影の色。頂上はいつも光る目標
6. **木は平らな棚にだけ**：黒い松の塊が棚に並ぶので、遠くから「どこが平らか」が分かる
7. **天気で色が丸ごと変わる**：雨は灰紫で線が消える、霧は白く平ら
8. **島（DLC）**：海から立つ岩の塔は横縞の地層、根元が波でえぐれてキノコの形、上に草とヤシ。遠くの島は低く長い青い影1枚と、地平線の雲

## 4. このゲームでの作り方（吟味）

いまの島：地面は URP の Terrain/Lit（区画ごとに1色、なめらかな陰）、物は Slug/Toon（3段の陰、輪郭線、カクカク）。空は無地の色。空気（`airLook`：遠くが空の色に溶ける、陰に時刻の色）は Nov 2 に入れた。崖は高さの地図なので、縦に引き伸ばされた筋になる（Oct の絵 `Screenshots/Island800/03_canyon_mouth.png`）。地面の濡れ具合（Oct 10 に決めた、焼いた日陰から出す3段）はまだ作っていない。

**まねしない所**
- 岩をひとつずつ手で置くこと（25 人で何年も。一人ではコードで並べて、直すだけ）
- 描いたテクスチャ（このゲームはテクスチャなし。形と Slug/Toon のノイズでやる）
- 歩くだけの長い道（批評で弱いと言われた所）

## 5. おすすめ（2つ）

- **無難：見た目から（A → B → E → C、余裕があれば D・F・G）**。形も遊びも変えずに、いまの灰色の島と作り直す地図の両方に効く。A と B で、乾きの読みやすさ（Oct 10 の決まり）もいっしょに進む
- **攻め：崖を岩の部品にする（I・J・K・L）＋無難の全部**。地図の作り方が「高さの地図＋岩の部品を並べる」に変わる。地図を作り直す前に決めると、やり直しが少ない

試すなら、まず1か所（枯れた谷の口と山頂。`03_canyon_mouth`・`08_summit` と同じ場所）で、前と後をナメクジの目の高さで撮って見比べる。

## 10. 山の意味：PvP の脱出ゲームでは何か、ケルンではどうか、どう使うか（Nov 4）

わくさん：「pvp extraction における山の意味って何だ？ケルンだとどうなってるかと、それをどう使えるか、または応用できるか」

**PvP の脱出ゲームでの山（ほかのゲームでよくある働き）**

| 働き | 中身 |
| --- | --- |
| 稼ぎが集まる所 | いちばん高い所にいちばんいい物。行く理由と、待ち伏せされる理由が同じ所にできる（このゲームでは岩塩の山がそう。spec 3章） |
| 見る・見られる | 高い所は遠くまで見えて偵察できる。代わりに、空を背にしたシルエットが遠くから見える |
| 道が絞られる | 尾根・鞍部・峠に道が集まる。読まれる道ほど待ち伏せが起きる。道が多いほど選ぶ楽しさ |
| 時間がかかる | 登るのに時間がかかり、重い荷物で下りるのが怖い。山に入ること自体が「賭け」になる |
| 島を部屋に分ける | 尾根の向こうは見えない・聞こえにくい。山があると島がいくつもの部屋に分かれる |
| 目印 | どこからでも見えるので、地図の代わりになる（spec の大きい三角） |

**ケルンでは（PvP はないが、山が相手）**
- 山そのものが敵。開発者いわく「ゾンビは壁」、Steam の説明では「壁はどれもボス戦」
- 高さが賭け金。落ちると、登った分の高さを失う（記者の試遊で、のどの渇きで倒れて登った崖を滑り落ちた）。高いほど失う物が大きい
- 下から壁を読んでルートを決める（Steam の説明）。決まった道はなく、選んだ筋がそのまま難しさになる
- 泊まる所（ビバーク）とその時間は自分で選ぶ。休むのも資源の使い方のうち
- 頂上はいつも見えている目標で、登るたびに新しい景色がごほうび（レビュー）
- ほかの人の跡が見える：ほかの人が登った筋と、落ちた所に印（デモのゴーストの更新、公式の絵）。題名のケルンも「跡を残す石積み」

**このゲームでどう使うか**

1. **高さ＝賭け金（ケルンの「落ちると失う」を、脱出の「持っている物を失う」に重ねる）**：いい岩塩ほど高い所に。高いほど帰り道が長く、重いバッグで下る時間が怖い。山のふもとで待つ人が出るので、下り道は1本にしない
2. **壁を読む → 島を読む**：ケルンは下から壁を読む。このゲームは尾根の上から島を読む（人の気配、雨雲、日陰、塩）。読んでから下りる場所を決める。山頂は偵察の場所で、狙撃の場所ではない（spec のまま）
3. **稜線は「見る」と「見られる」の取り引き**：尾根のてっぺんを歩くと、速くて両側が見えるが、空を背にして両側から見える。てっぺんのすぐ下を歩くと、片側からは隠れて、のぞけば見える（軍の言葉で「軍の稜線」）。尾根の形でこの選び方が生まれる
4. **鞍部・切れ目・橋は、会う場所**：道が集まる所で出会いが起きる。切れ目を渡る橋は丸見えの数秒。わきの下り道か沢の道を必ず1本用意して、閉じこめにしない
5. **尾根が部屋を分ける**：尾根と沢で、山の中がいくつもの部屋になる。沢の底は見つかりにくい道、尾根は見通しのいい道
6. **ビバーク → キャンプ**：ケルンの泊まる場所は、このゲームのベースキャンプ（良い場所ほど行きにくい、spec）。尾根の途中の張り出しや岩陰がキャンプの候補になる
7. **跡が残る**：2本足の足跡は、尾根の細い道ほどはっきり残る。誰かが先に通ったか、足跡で読める（ケルンのゴーストの代わり）

**案A・案Bとの合い方（9章）**
- 案A（尾根と沢）：尾根が 8 本あるので、どの尾根で登るかを選べる（3・5 に強い）。沢をはさんで隣の尾根と撃ち合う距離（40〜80 m）になる
- 案B（馬蹄形とカール）：お椀の中で掘る人を、稜線から見下ろせる（1・3 に強い）。入口が南の口に寄るので、出入りの道を足さないと閉じこめになりやすい
