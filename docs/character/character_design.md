# キャラデザイン検討のまとめ

`spec.md` の「キャラの具体的なデザイン」を詰めた試作の経緯と、現在の状態。
すべて手続き的メッシュ＋URP用HLSLシェーダー（`Assets/Slug/`）で作り、ボーンなし（這う動きは頂点シェーダー）。

## 0. 環境
- Unity 6000.5.4f1、URP 17.5.0。URP アセットは `Assets/Settings/UniversalRP.asset`（Graphics・Quality 全段階に割り当て済み）。
- 日本語ラベル用に Noto Sans JP（OFL）を `Assets/Fonts/` に置いている。

## 2. 現在の状態
- 体と顔は、v4 の中央の個体（丸い立ち上がり型、小さな黒い立体の目、小さな口）。ほっぺはなし。
- 触角・手は、根元が太く先端ほど細い円錐形（指なし）。
- 苔系の色、模様 0.5、陰影と輪郭線は 1.0。
- 這う動きは、全身の伸び縮み（±3.5%。装備がはみ出さないよう、最初の±7%から半分にした）＋尾から頭へ進む波。しっぽが反転・膨張しない制限付き。
- 後ろ側（おなか）は短め。おなかは平らに地面に付く（Oct 4, 2026）。足のふちのひだは試して戻した。
- カタツムリ（スカブ枠）も同じ体。見分けは背中の殻だけ。ナメクジはバッグ。

値の一覧は `design_params.md`。

## 3. コンポーネントと使い方
- `SlugPop`：プレハブ `Assets/Slug/Prefabs/Slug_Pop.prefab`。要素別スライダー＋一括スライダー、`bodyStyle`、`eyeKind`。
- シェーダー `Slug/Toon`：色・模様・うねり・フェルト・縫い目・凹凸・半透明などのパラメータ。
- 確認用のシーンとスクショ：`Slug` メニューの `Lookbook Build Scene` → `Lookbook Capture Screenshots`（`SlugLookbook`、シーンは `Assets/Scenes/SlugLookbook.unity`）。決定値は `SlugLookbook.ApplyCurrent`。プレハブを作り直すのは `Lookbook Build Prefab`。
