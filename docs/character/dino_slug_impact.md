# 2本足のナメクジにすると何が変わるか

Nov 2, 2026 · Claude（わくさんの「ほかに影響する所は？ 音とか設定とか」への答え。まだ何も作っていない）

新しい体は `Assets/Slug/Scripts/Editor/DinoSlugPhotoRough.cs`（2本足で立つ、丸い頭、前に傾いた胴、長い尾、短い腕、にっこりした口）。
**目の高さ 0.47 m は今と同じ**なので、島・拠点の大きさ、一人称のカメラの高さ、銃の構え（一人称）はそのまま使える。

## 決まったこと（Nov 2 わくさん）

- 2本足で歩く。**カタツムリも2本足**（1章の4は「攻め」）
- 体の中にしまうのは**口から飲みこむ**（2章の「無難」：ごくん → のどを下りる、出すときは「けぽっ」、塩は「ぺっ」）
- **ぬめり跡は足跡**にする。**跡に乗ると速くなるのはやめる**（spec 4章の【決定】を消す）
- **滑るのはなし**：止まるときのぬるっとした滑りも、跳んだあとの着地の滑りも、両方なし。ぴたっと止まる
- 縮んで伸びるは**しゃがんで跳ぶ**（1章の2の「無難」。操作と数字は今のまま）
- 腕は**伸びる腕のまま**（1章の3の「無難」。付け根を肩へ）
- カタツムリは**ナメクジと同じ2本足の体に、背中から殻が生えている**（殻は今と同じくバッグ兼防具。体の色と頭の形を少し変える）
- 音は4章のとおり。**音はわくさんが自分で作る**（Argon に頼まない）

## 1. 先に決めてほしいこと（Nov 2 に決まった。上の「決まったこと」）

| # | 決めること | 無難 | 攻め |
| --- | --- | --- | --- |
| 1 | 歩く？ 這う？ | **2本足で歩く。足の裏だけナメクジ**（ぺたっと吸いつく）。50° の坂でずり落ちない、乾きは「足元の地面」で決まる、ぬめり跡は足跡になる。今の決まりがそのまま言える | 歩くのは遅い場面だけにして、速く動くときは前に倒れて腹で這う（2つの体の使い分け） |
| 2 | 縮んで伸びる（スペース） | 操作も数字も同じ。ひざを曲げてしゃがみ、胴と尾ごと「びよーん」と前へ跳ぶ | 尾をばねにして跳ぶ（尾で地面を叩いて跳ねる。尾の動きがはたからの合図になる） |
| 3 | 腕 | **伸びる腕のまま**。道具・持つ・バッグに入れる・背中から取るは全部「伸びる腕」で作ってあるので、付け根を肩に移せばほぼ動く。新しい体の短い腕は手ぶらのときの形 | 短い腕のまま、届かない所は体ごと動く（背中の銃は前へ回して取る、など。動きを全部作り直し） |
| 4 | カタツムリ（最初の3回の出撃、ボット、カタツムリの殻） | **今の這う体のまま**（親戚なので形が違っていい。見分けも楽） | カタツムリも2本足で、殻を背負って歩く |

おすすめはどれも「無難」。理由は、作り直す量が少なく、今の決まり（坂・乾き・跡・道具）がそのまま生きるから。

もう1つ：spec の【決定】「這う体に手が生える」「丸い立ち上がり型：尾側だけが地面を這う」は書き直しになる（Nov 3 に spec 5章ほかを2本足に書き直した。前の形は `spec_history.md`）。

## 2. 体の中にしまう → 口から飲みこむ

いいと思う。理由は4つ。

- 口ができた（Nov 2 のにっこりした口）。苔玉を飲む動きも口でやれば、「口＝体に入れる所」でそろう
- 「塩は入れられない」が口だと自然に分かる：塩を口に入れると「ぺっ！」と吐き出す（顔をしかめる）。説明しなくても1回で覚える
- 「生きて帰るほど隠し場所が広がる」（spec 10章）が「胃袋が大きくなる」になって分かりやすい
- 頭より大きい物でも、ヘビのように口がのびて飲みこめばポップで楽しい

動きの形：

- **無難**：手で口へ運ぶ → 口が開いて「ごくん」 → のどを膨らみが下りて、おなかで消える。出すときは手ぶらで X、「けぽっ」と手の上に出てくる。塩は「ぺっ」と吐く
- **攻め**：塩も飲める。そのかわり飲んでいる間ずっと体の中から乾く（湿り気が速く減る）。お金の塩をこっそり持ち帰れるかわりに危ない。経済の数字（何をいくつ持ち帰れるか）に効くので、決めるなら話し合いから

要る物：口が開く形（今は黒い線だけ）、のどを下りる膨らみ、音2〜3つ（下の4章）。仕組みのほう（`SlugBag` の隠し場所、死んでも残る）はそのまま。

## 5. 設定（`Assets/Tuning`）

わくさんの値なので Claude は触らない。新しい数字はコードの初めの値で足して、わくさんが遊びながら直す。

| 設定 | どうなる |
| --- | --- |
| `SlugMoveSettings` | 速さ・加速・止まるときの滑り・坂 50°・段差・覗くときの速さは**そのまま使う**（短い足で 1.2 m/s を出すので、足はちょこちょこ速く回す。→ Nov 2 に、歩く速さ `footSpeed` 1.6 m/s と止まる時間 `footStopTime` 0.1 秒を足した。下の「進み」）。尾の追いつき（`tailFollow*`・`turnKickTail`）は尾の骨に回す。這う波（`idleCrawlRate`・`crawlRatePerSpeed`）は使わなくなり、足の回し方に替わる。縮んで伸びる（`lunge*`）は1章の2しだい。覗くときの目の位置（`peek*`）は合わせ直し |
| `LoadoutSettings` | 取り出す・しまう時間はそのまま。道すじだけ変わる |
| `ExtractSettings` | バッグの大きさ（パンパンで幅 約 1 m）は、立った背中だと重く見えるかもしれない。見てから決める。Q で覗くときのバッグの数字（`bagPeek*`）は合わせ直し |
| `ConditionSettings`・銃の設定 | そのまま |
| `SlugPop` の見た目のスライダー | 新しい体は別のビルダーなので効かない。色と模様だけ引き継ぐ |
