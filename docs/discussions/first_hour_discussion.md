## 1. それぞれの意見

**Claude**
- はじめての人がつまずく所は3つあると思います。①体のルール（手で入れる、乾く、重い）、②地図のない島の読み方、③最初の死
- 覚える順番は「這う → 採って入れる → 乾く → 持ち帰る → 撃つ」。撃つのが最後なのは、撃ち合いは最初の死と一緒に来るからです
- 教えるための仕組みを作るより、世界の置き方で教えたい。ベースキャンプを出てすぐ目の前に塩のきのこ、キャンプへの道は光って濡れた地面、少し離れると白く乾いた所、のように
- 最初の数回は、失う物を小さくしておく。カタツムリでの出撃がもうあるので、それを「はじめての出撃」にも使えます

**廃人**
- タルコフの最初の1時間はひどかった。どこへ行けばいいか分からず、出口も知らず、誰に撃たれたかも分からず全部失う。続けられたのは、友達が横で教えてくれたから
- 守りすぎるのは反対。怖さがこのゲームの売り物。最初から本物の島に出るべき
- ただし、死には必ず情報を付ける。誰に、どこから、何で、何 m で。死ぬたびに一つ賢くなれば、人は続ける
- 最初の版は試合型なので、はじめての人どうしを同じ試合に入れることができる。ずっと続く島ではできないことだから、今のうちに使える

**スプラ**
- スプラは、5分くらいの練習のあと、すぐ広場に出て友達と遊べる。説明を読むのはむり
- 最初の出撃で、友達に見せたいものが一つ欲しい。バッグがパンパンになる、とか
- 友達が教えてくれるなら、指さしができるといい。「あれ採って」「あっちに人」って

**辛口**
- いちばん危ないのは、わくさんが立派な練習用のステージを作り始めること。一人で作るには重すぎるし、作り直しのたびに直すことになる
- 最初の1時間で覚えなくていい物を、はっきり後ろに回すべき。体の隠し場所、地面に下ろす、エコバッグ。これは2回目、3回目に知ればいい
- 教えるのは友達。だから「友達が教える」ための道具を作る方が、練習用のステージより安くて効く

**桜井メモ係**
- 説明を読ませるより、進めながら覚えられるように（「自然なチュートリアル」の回）
- 最初に遊んでもらうのが一番難しいので、最初からぐっと引き込む（「最初にクライマックスを」の回）。メモでは、最初の数分で雨、採る、バッグが膨らむ、見晴らし、を見せる、と書いた
- 初心者には、やさしく、気持ちよく。手加減は失礼ではない（「初心者にはやさしく、気持ちよく」の回）
- 罰が大きいゲームは、もう一度やりたくなる魅力が要る（「やり直しに見合う魅力はあるか？」の回）。そしてミスのあとは、気持ちが冷める前に操作を返す（「リトライは迅速に」の回）
- 作り手は慣れているので、はじめての人の不自由さを忘れる（「ハンデをつけてバランス調整」の回）。わくさんは島を知りすぎている。地図を見ずに、F4 を切って遊ぶこと
- ボタンを押したら必ず何か返す（「ノーリアクションを排除せよ」の回）。採れない物で E を押したとき、入らないバッグに入れようとしたとき、這えない崖。黙っていると、はじめての人は「壊れている」と思う

**初心者**
- タルコフで困ったのは、何をしたら損で、何をしたら得か分からないこと。3分で、相手を一度も見ないまま全部なくして、また装備を買い直す。それで終わった
- 最初の何回かは「死んでも、何か一つは持って帰れた」と思いたい
- 文字で説明されても覚えられない。でも、友達が「それ、白い所は乾くよ」って言ってくれたら覚える

**リーサル勢**
- Lethal Company は、ほとんど何も教えてくれない。友達が教えるし、分からなくて騒ぐのが最初の楽しさ。近くの人の声が、そのまま説明書になっている
- Lethal で最初に死んでも、笑える。荷物はみんなの物だから、一人のせいにならない
- ここは死ぬと自分の物を全部失う。最初の死は、笑えるくらい軽い方がいい

**教習所の人**
- 危ないことを教えるときは、一度に一つ。最初は囲われたコース、次は横に指導員がいる道路、最後に一人。毎回一つだけ足す
- 怖さは大事です。でも、体が基本を覚えてからでいい。ハンドルもおぼつかないうちに高速道路に出すと、怖さしか覚えません
- 失敗したら、すぐに短く返す。「何が起きたか」と「次はどうするか」を一言ずつ。長い説明は、次の運転では思い出せない

## 2. 暗黙の了解をひっくり返した案

### 2-1. 「死なせないように教える」→ 誰かの死から教える

**Claude**：最初の出撃で、はじめての人が最初に見つける物を、**倒れた誰かの荷物**にする。ベースキャンプのそばに、前の出撃で倒れたナメクジ（最初の版ではボットでいい）の地面のバッグが落ちていて、そこに「どこから何で撃たれたか」の札が付いている。拾うと得をする。同時に、ここは死ぬ場所だと分かる。

**スプラ**：最初に拾える物があるの、うれしい。中身がいいとテンション上がる。

**廃人**：タルコフの一番の思い出も、死体を見つけたときの「ここ、やばい」だった。危なさと得を一度に見せられる。

**辛口**：リスクとリターンを、説明なしで一回で見せている。作るのも、地面のバッグと札だけ。

**桜井メモ係**：最初からぐっと引き込む（「最初にクライマックスを」の回）と、ごほうびを見える所に吊る（「目の前に吊られたごほうび」の回）が一緒になっています。

**初心者**：私だったら、拾っている間に撃たれそうで怖い。でも、その怖さは分かる怖さです。

**教習所の人**：見せる順番がいい。まず「事故の跡」を見てから運転する。言葉で言うより残ります。

### 2-2. 「新人が教わる」→ ベテランが新人を連れて行くと得をする

**Claude**：はじめての人を連れて出撃して、一緒に生きて帰ると、連れて行った人にも得がある。教えることを、わくさんが作る仕組みではなく、プレイヤーの遊びにする。

**リーサル勢**：うちらはもう、そうやって遊んでる。新しい友達を連れて行くのが一番盛り上がる。

**廃人**：得があると、新しいアカウントを作って自分で自分を連れて行く人が出る。得は小さく、お金ではない物に。

**辛口**：一人開発でできる最小の形は、はじめての人が初めて持ち帰ったバッグを広げる演出を、連れて行った人も拠点で一緒に見られること。お金も数字も要らない。

**スプラ**：友達の初めてのバッグ、見たい。

**初心者**：連れて行ってもらう側も、気が楽になります。迷惑じゃなくて、相手も得をしてるなら。

### 2-3. 「死は罰」→ 島が、死んだ場所を覚えていてくれる

**Claude**：倒れた場所に、自分にだけ見える印が残る。次の出撃でそのあたりに来ると、地面にうっすら自分の跡が光る。島は試合ごとにまっさらでも、地形は同じなので、印はそのまま「危ない場所」の地図になる。地図とコンパスのない島で、死ぬたびに自分だけの地図が増えていく。

**廃人**：死んだ場所を覚えるのは、ベテランは頭の中でやっている。それを見せるだけなら、情報の差は縮まるが不公平ではない。自分の過去の情報だから。

**初心者**：ありがたい。死ぬたびに何かが増えるなら、また出たくなります。

**桜井メモ係**：罰が大きいなら、もう一度やりたくなる魅力を（「やり直しに見合う魅力はあるか？」の回）。死が「次はこうする」に変わる形です。

**辛口**：ずっと続く島に移ったとき、ほかの人の死の跡も見えたら、と考えると面白い。最初は自分のだけでいい。

**リーサル勢**：友達の死んだ跡も見えると、笑える。「ここでお前死んだよな」。

## 3. 極端案

### 3-1. 最初の3回は、銃を持たせない

**Claude**：はじめての人は、最初の3回の出撃で銃を持てない。採る、隠れる、逃げる、持ち帰る、だけ。ほかの人には撃たれる。

**廃人**：狩られるだけになる。つらいし、撃てないことを知った人に狙われる。

**スプラ**：撃てないのはつまらない。スプラは最初から撃てる。

**教習所の人**：でも、順番の考えは正しい。最初に覚えるのは、ぶつからない運転です。ぶつけ方ではない。

**辛口**：拾える部分は順番。最初の出撃は、撃つより「隠れる・逃げる・持ち帰る」が先に体に入るように場所を置く。銃は持たせてもいい。

**拾える部分**：最初の数回は、軽い一式（拳銃だけなど）で出て、撃ち合うより持ち帰る方が得になるように置く。覚える順番を、置き方で作る。

### 3-2. はじめての人の最初の10時間は、はじめての人どうしだけ

**Claude**：遊んだ時間が10時間になるまで、ベテランとは同じ試合に入らない。はじめての人どうしで、ゆっくり死に慣れる。

**初心者**：それなら続けられた気がします。

**廃人**：新しいアカウントで初心者狩りをする人が必ず出る。10時間は長すぎる。

**辛口**：人が少ない時期（agenda 1-3）に、はじめての人だけで試合が組めるほど人はいない。

**リーサル勢**：友達と一緒に始めたのに、自分だけ別の試合、は絶対いや。

**拾える部分**：試合型の今だけできること。最初の2〜3回だけ、はじめての人が多い試合に寄せる（友達といるときは友達を優先）。完全に分けない。

## 4. まとめ（決めない）

**まとまったこと**
1. **教える仕組みより、世界の置き方で教える**（Claude、辛口、桜井メモ係）。ベースキャンプのすぐ前に塩のきのこ、キャンプへの道は濡れて光る地面、など
2. **一度に一つ**（教習所の人）。覚える順番の案：這う → 採って入れる → 乾く → 持ち帰る → 撃つ
3. **最初の1時間で覚えなくていい物を、後ろに回す**（辛口）。体の隠し場所、地面に下ろす、エコバッグ
4. **死には必ず情報と一言を付ける**（廃人、教習所の人）。「どこから何で何 m」と、「次はどうするか」の一言
5. **倒れてから次の出撃まで速く**（桜井メモ係「リトライは迅速に」）
6. **友達が教えるための道具**（スプラ、リーサル勢、辛口）。指さし（12章の合図のアクションと一緒に）、近くの人の声
7. **押しても何も起きない所をなくす**（桜井メモ係「ノーリアクションを排除せよ」）

**残った意見の違い**
- 最初から本物の怖さを（廃人、リーサル勢）か、守られた数回を（初心者、教習所の人）か
- はじめての人どうしの試合に寄せるか（初心者）、寄せないか（廃人：初心者狩り、リーサル勢：友達と分かれる）

**わくさんに決めてほしいこと**
1. はじめての出撃は、カタツムリ（失う物なし）か、ナメクジの軽い一式か
2. 最初の2〜3回を、はじめての人が多い試合に寄せるか
3. ひっくり返した案のどれを残すか：倒れた誰かの荷物から始める（2-1）、連れて行った人も初めてのバッグを見られる（2-2）、死んだ場所の自分だけの印（2-3）
4. 「最初の1時間で覚える物」と「後で知ればいい物」の線をどこに引くか
