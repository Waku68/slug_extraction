# 体力とダメージの話し合い（Claude と固定の3人＋3人）

Oct 5, 2026

**今回のお題（わくさん）**：体力とダメージの基本（何発で倒れるか）。塩の希少性、人の数（区画の人数・同時に遊んでいる人の数）、ほかの仕様にも関わるので、相談したい。**決めない。**

**前提（決まっていること）**
- 塩＝掘る資源・弾・通貨。撃つたびに財布が減る。弾は拠点の精製所で加工して持ち込んだ物だけ（仮）
- 弾種：粗塩（散弾・近距離・安い）、精製塩（連射・中距離・中）、岩塩の塊（狙撃・高い）。銃は拳銃（精製塩）、ライフル（精製塩）、散弾銃（粗塩）、狙撃銃（岩塩）
- 部位の倍率（仮）：触角 1.4、防具の上 0.6、むき出しの頭・体 1。背中のバッグに当たると耐久が減り、種類によって体へ通る量が変わる
- 死んだら装備は全部失う。保険はない。体の中の隠し場所の1つだけ残る
- 島は試合で区切らない続いた世界。1区画（一辺 800 m）に 20 人まで、パーティは4人まで。島で抜けると10分丸まって眠る（撃たれうる）
- 湿り気は体力と別。湿り気が 0 になると体力が減り、満タンから約90秒で倒れる
- 這うのは遅い（1.2 m/s、重いと 0.36 m/s）。撃たれてから走って逃げることはほぼできない。縮んで伸びるでよけるのがせいぜい
- 新人の救済は、カタツムリでの出撃（失うもののない出撃、仮）

## 1. まず全員の意見

**Claude**：何発で倒れるか（むき出しの体に当てたとき）の型を4つ並べます。

| 型 | ライフル | 拳銃 | 散弾銃（近くで全部当てて） | 狙撃銃（体／頭） | 回復 |
| --- | --- | --- | --- | --- | --- |
| A 速い（タルコフ寄り） | 4発 | 6発 | 1発 | 1／1 | 拠点だけ（または、とても遅い） |
| B 中くらい | 8発 | 12発 | 2発 | 2／1 | 雨の中でゆっくり |
| C 殻で受ける（Apex 寄り） | 体力 8発＋殻アーマー 4発 | 18発 | 3発 | 3／2 | 雨と苔玉。殻は拠点で直す |
| D 体力＝湿り気 | 天気で変わる | | | | 雨・水場がそのまま回復 |

這うのが遅く、撃たれてから逃げにくいので、倒れるまでが速すぎると「先に見つけたほうが必ず勝つ」になります。遅すぎると、塩の弾をたくさん使うので、撃ち合いが高くつきます。

**廃人**：
- A か B。タルコフの怖さは、1回の撃ち合いで全部失うかもしれないこと。数発で倒れるから、物陰から物陰への移動に意味が出る
- ただ、このゲームは遅い。タルコフなら角を曲がって逃げられる距離でも、ナメクジは逃げられない。だから A は少し速すぎる。B 寄り
- 回復は拠点だけでいい。雨で回復すると、雨の中の撃ち合いが終わらない

**スプラ**：
- 一瞬で倒されるのはいや。何が起きたか分からないまま全部なくなったら、もうやらない
- スプラは倒されてもすぐ復活できるけど、これは全部なくなるんでしょ。だったら、倒れるまでに何かできる時間がほしい
- 倒れそうな友達を助けたい

**辛口**：
- 体力の数字は、ほかの3つの数字とつながっています。這う速さ（逃げられるか）、弾の値段（撃つたびにいくら減るか）、人の多さ（どれくらい出会うか）。これを別々に決めると崩れる
- このゲームだけの特別さで言うと、D（体力＝湿り気）は一番「らしい」。塩はナメクジの水分を奪う。でも、決めた湿り気の数字が全部、撃ち合いの数字にもなってしまう。大きすぎる変更です
- 最初は B で作って、撃ってみて動かす。試すための数字です

**競技勢**：
- 大事なのは、うまい人が勝つこと。倒れるまでが速すぎると、先に見つけた人が勝つだけ。遅すぎると、撃ち合いのうまさより弾の多さで決まる
- 頭（顔）に当てると強い、をはっきりさせてほしい。今は頭も体も 1 倍。顔に当てたら 1.5 倍くらいほしい
- 散弾銃の1発で倒れる、は近距離では強すぎる。距離で弱くなるならいい

**経済勢**：
- 塩は「弾」と「通貨」を兼ねている。撃つと、そのぶん塩が島から消える。これは良い「消える先」（シンク）です。EVE でも Albion でも、物が消えていかないと、すぐに物があふれて値打ちがなくなる
- 体力が多いほど、1人倒すのに使う塩が増える。「倒した相手の持ち物の値打ち」より「使った弾の値打ち」が大きいと、誰も撃たなくなる。逆に小さすぎると、撃ちまくる
- 区画に 20 人、島に何百人、と人が増えるほど、撃ち合いが増え、塩が消える。人が少ない時期（ワイプ前や深夜）は撃ち合いが減り、塩が余る。この上下を、精製の値段で調整できるようにしておくべき

**新人**：
- タルコフは、何もできないまま倒されて、全部なくなったのでやめた。何発で倒れるかより、「なんで倒されたか」が分かるかどうか
- 倒されたら、どこから撃たれたか見せてほしい
- 最初はカタツムリで出撃できるなら、それで慣れたい

## 2. 話し合い

**Claude**：A は速すぎる、D は大きすぎる、で多くが一致しました。B と C の間です。

**廃人**：C の殻アーマーは、すでに仕様にある（殻板アーマー）。防具の上は 0.6 倍、と決めてある。C は「防具の上は 0.6」と、どう違う？

**Claude**：今の仕様の 0.6 倍は、防具に当たると減りが少ない、です。C は、殻が別の体力として先に削れて、割れると素の体に通る。Apex の盾のような考えです。

**競技勢**：殻が割れる音や見た目があると、撃ち合いが読みやすくなります。「あと少しで割れる」が分かる。

**辛口**：でも作る量が増えます。0.6 倍のままでも、殻の削れ具合（耐久）を見せることはできる。仕様にもう「殻アーマーの削れ具合」が体表示に出る、とある。まずは 0.6 倍＋耐久で、割れたら 1 倍、で十分では。

**廃人**：それは実質 C だ。殻に耐久があって、割れたら素通り。それでいい。

**経済勢**：殻は拠点で直すのに塩がかかる、にすると、シンクがもう一つ増えます。

**スプラ**：倒れそうな友達を助ける話は？

**Claude**：3-3 で話します。

**新人**：倒されたとき、どこから撃たれたか見せるのは？

**競技勢**：それは入れるべき。死んだあと、相手の位置と使った銃が見えれば、次に生かせる。

**廃人**：撃った側の位置がばれるのは、タルコフでは見せない。見せると、仲間にすぐ伝わる。

**辛口**：見せるのは、倒れた本人が「拠点に戻ってから」でいいのでは。仲間に伝えるのは、ボイスチャットで本人が話すしかない。

**経済勢**：数字の決め方を一つ。1人を倒すのに使う塩の目安を、区画で平均的に持ち帰る塩の何分の1か、で決めると、経済と体力がつながります。例えば「ライフルで1人倒すのに使う弾は、岩塩1つぶんより少し安い」。

**廃人**：分かりやすい。外しまくると赤字、当てれば黒字。

**競技勢**：うまい人ほど少ない弾で倒すので、うまさがそのまま稼ぎになる。いいです。

**辛口**：塩の希少性の話で言うと、仕様に「シーズンの終わりは塩が増えてインフレし、弾は撃ち放題」とある。体力は変えずに、弾の値段が下がる、で終盤の祭りが作れます。体力の数字はシーズンを通して同じにしておくべき。

## 3. 暗黙の了解をひっくり返した案（3つ）

### 3-1. 「体力は数字」→ 体力は体の大きさ（撃たれると縮む）

**Claude**：塩を浴びると、ナメクジは縮みます。体力が減ると、体が少しずつ小さくなる。数字を見なくても、相手の残りが分かる。

**競技勢**：縮むと当たり判定も小さくなる？　それは、弱った側が当てにくくなるので、逆転が起きやすい。公平かどうかは微妙です。

**廃人**：当たり判定は変えずに、見た目だけ縮む、ならいい。

**スプラ**：縮んでいく友達、ちょっとかわいい。

**辛口**：見た目だけなら安い。湿り気の「30を切ると縮む」と見分けがつくように、縮み方を変える必要はあります（塩で白くなる、など）。

### 3-2. 「体力と湿り気は別」→ 1つにする（体力＝湿り気）

**Claude**：湿り気の話し合いの極端案から。塩の弾は水分を奪う。撃たれると湿り気が減り、ゼロで倒れる。雨は回復、晴れは撃ち合いが一瞬。

**経済勢**：晴れの日は弾が少なくて済む（倒しやすい）、雨の日は弾がたくさん要る。天気で弾の値打ちが変わる。経済としては面白いです。

**競技勢**：天気で撃ち合いの長さが倍以上変わるのは、うまさの比べ方が毎回変わるので嫌です。

**廃人**：雨の中で、撃たれながら回復するのは困る。

**辛口**：湿り気の数字はもう決めました。これを入れると全部やり直し。拾える部分は「湿り気が少ないほど、塩の弾が少し効きやすい（例：30 を切ると 1.2 倍）」。乾いた相手は弱っている、が撃ち合いにも出ます。

### 3-3. 「倒れたら死ぬ」→ 倒れたら丸まる（仲間が水をかけると起きる）

**Claude**：体力がゼロになると、まず丸まって動けなくなる（ダウン）。この間に仲間が苔玉の水をかけると起きる。一定時間たつか、とどめを刺されると死ぬ。ソロなら、丸まった時点で死ぬ。

**スプラ**：これ！　友達を助けたい！

**廃人**：パーティが圧倒的に有利になる。ソロは不利だ。それに、とどめを刺すかどうかで、撃ち合いが長引く。

**競技勢**：Apex でもダウンはあるけど、撃ち合いが二段階になって、読み合いが増えます。

**新人**：倒れてすぐ全部なくなるより、少し猶予があるほうが、何が起きたか分かります。

**辛口**：島で抜けたときの「丸まって眠る」と、見た目と仕組み（丸まる、撃たれうる）を共有できます。作るのは一度で済む。ただ、ソロとパーティの差をどうするかは、わくさんが決めること。

## 4. 極端案（2つ）

### 4-1. どの武器でも一撃で倒れる

**Claude**：当たれば倒れる。外せば倒される。

**競技勢**：先に見つけた人が全部勝ちます。

**新人**：絶対やらないです。

**廃人**：極端すぎるが、狙撃銃の頭は一撃、は残したい。

**辛口**：拾える部分は「部位ごとの効果を大きくする」。触角に当たると耳が遠くなる（仕様）、顔に当たると視界が白くなる（塩が目に入る）、など。一撃で倒れなくても、当たった場所で不利が付く。

### 4-2. 誰も死なない。倒れると荷物を落とすだけ

**Claude**：倒れると、バッグの中身と手に持っている物をその場に落とし、拠点に戻される。装備は残る。

**廃人**：失う痛みがなくなる。仕様の「装備は全部失う」と真っ向からぶつかる。

**スプラ**：それなら気軽に遊べる……。

**経済勢**：装備が消えないと、装備（とその材料の塩）の消える先がなくなります。経済が膨らむ。

**辛口**：拾える部分は「新人の救済はカタツムリでの出撃に任せる」の確認です。カタツムリは失うものがないので、ここで慣れられる。ナメクジでの出撃は、仕様どおり全部失う。

## まとまったこと（決めていない。わくさんが決める）

1. **何発で倒れるかは、B（中くらい）から試す**、が多数。ライフル 8発、拳銃 12発、散弾銃（近くで全部）2発、狙撃銃は体2発・頭1発。A は遅いナメクジには速すぎ、D（体力＝湿り気）は湿り気の数字を全部やり直すことになる
2. **体力は、這う速さ・弾の値段・人の多さとつながっている**。1人を倒すのに使う塩の目安を「区画で平均的に持ち帰る塩の何分の1か」で決めると、経済と体力がつながる（当てれば黒字、外し続けると赤字）
3. **塩の希少性の調整は、体力ではなく弾の値段（精製の値段）でやる**。体力の数字はシーズンを通して同じ。シーズン終盤の「塩のインフレ、弾は撃ち放題」も弾の値段で作る
4. **人の多さで撃ち合いの数が変わり、塩が消える量も変わる**。精製の値段を後から動かせるようにしておく
5. **殻アーマーは耐久を持ち、削れ具合が見える。割れたら素の体に通る**（今の 0.6 倍＋耐久）。拠点で直すのに塩がかかる（もう一つのシンク）
6. **顔に当てると強く**（例：1.5倍）、が競技勢から
7. **倒されたら、拠点に戻ってから「どこから、何で撃たれたか」が見られる**
8. 拾った案：見た目だけ縮む（3-1）、乾いていると塩が少し効きやすい（3-2 から）、部位ごとの効果を大きくする（4-1 から）

**残った意見の違い**
- ダウン（丸まって仲間が起こす、3-3）を入れるか：入れたい（スプラ・新人・競技勢）／パーティが有利すぎる（廃人）
- 回復：拠点だけ（廃人）／雨でゆっくり（B の型）／苔玉でも（C の型）
- 倒した側の位置を見せるか：拠点に戻ってから本人にだけ、で落ち着きかけ

**わくさんに決めてほしいこと**
- 何発で倒れるかの型（A／B／C／D。B から試す案が多数）
- 体力の回復のしかた（拠点だけ／雨でゆっくり／苔玉でも）
- ダウン（倒れたら丸まり、仲間が水で起こす）を入れるか。ソロのときはどうするか
- 顔に当てたときの倍率を上げるか
- 1人を倒すのに使う塩の目安（経済とつなげる基準）
