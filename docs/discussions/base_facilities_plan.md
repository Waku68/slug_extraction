# 拠点の設備の案（水の流れに沿って）

Oct 30, 2026 · Claude の案（わくさんが直す）

筋道 `base_rethink.md` の 4〜5 のあいだ。間取り（どこに何 m）はまだ決めない。ここは「どの設備が、水の流れのどのあたりで、何をして、育つと何が見えるか」だけ。

## 前提（Oct 30 わくさんが決めたこと）

- 拠点は自分で育てる工房。中身は硬派（飾りより道具、使い込んだ跡）、落ち着く。形はずんぐりしたポップのまま
- 背骨は水：**天窓 → 池（湧き水。雨の日は天窓の水が足される）→ 小さな滝 → 水車 → 海へ**
- 弾：塩を入れた分だけ、水車が臼で少しずつ挽く（留守の間も。雨の日は速い）。自分の体で回すと少し速い。挽いた粉を、延べ棒の型に押せばアモレ、弾の型に押せば弾
- 育ちの見せ方：上がった瞬間に光と音。鳥の籠で帰るとき、海から育ったのが見える（帳面なしで段が読める）。大干ばつのあとは、地図の台のふちに刻み目だけ
- 育つ仕組み（段・値段・S3 の島の大物）は spec のまま

## 考え方（Claude）

- **「家具が1つ増える」をやめて、「できることが1つ増え、それが形で見える」にする**。段が上がると、その設備でできることが変わる。変わった所が、中では道具の形、外では崖のしるしになる
- **湿った物は上流、乾いた物は水から離す**。ナメクジは湿った所が落ち着く。干す・塩は乾いた所
- **水車の主軸1本で、3つの設備を回す**：精製所の臼、乾燥室の大うちわ、細工場の砥ぎ車。拠点のからくりはこの1本だけ（育ち方の話し合い 3-2 の小さい形）
- **体ですることは、島の操作（這う・つかむ・投げる）だけ**。帳面でも済む（手の動かし方はまだ決めていない：`base_handwork_discussion.md`。ここはその「無難」で書いた）

## 水の流れと設備

```
 [島のてっぺん]  観測所（天窓のふち、空が見える）
       │ 天窓（光と雨）
 [上流]  池（湧き水）── 苗床（光と雨しぶきの当たるふち）
       │              └ 染め場（池から引いた浅い色の池）
 [真ん中] 地図の台（池のそば。帰ってバッグを広げる・帳面・集まる）
       │ 小さな滝
 [中流]  水車 ─ 主軸 ─┬ 精製所（臼と型、塩の入れ口と塩箱）
       │            ├ 乾燥室（主軸の上の乾いた所、大うちわ）
       │            └ 細工場（主軸の先、砥ぎ車）
 [下流]  水路 ── 問屋（海への口、桟橋。行商人の舟）
       │         └ カタツムリの小屋（水路わきの低く湿った所）
 [海]    崖から海へ落ちる。口の外に鳥の発着場（桟橋の横）
 [外]    鳥の巣（崖の上の方）
 [帰り道] 図鑑の棚・飾り枠（滝の横の段を上りきった踊り場）
```

## 設備ごと

段の数と値段は spec のまま（観測所 600・1600、苗床の枠 400・800、乾燥室 500、染め場 400、工房 600、飾り枠 200 ずつ、S3 は島の大物）。

### 精製所（臼と型）
- **すること**：塩の入れ口に塩を入れる → 水車が臼で少しずつ挽く（留守の間も、雨の日は速い）→ 粉が下の箱にたまる → 型に押して延べ棒（アモレ）か弾。粗く砕く＝散弾、細かく挽く＝連射、狙撃＝塊のまま削る（9章）
- **体で**：臼の取っ手に体を押しつけて、這って回すと速い。型に粉を入れて、体で押し固める
- **段**：S1 小さな水車と石臼1つ、型は延べ棒と弾 ／ S2 水車の羽が増えて大きくなり、挽く速さが上がる。狙撃の弾を削る万力 ／ S3 黒い溶岩の大きな臼（二匹で回せる）
- **海から**：水車の大きさ。崖の口から半分出ていて、回っているのが見える
- 延べ棒は槌で割るとすぐ粉に戻る（お金はあるのに弾が足りないとき、待たなくていい）

### 観測所
- **すること**：天気予報。段で刻みが細かくなり（半日ごと → 1時間ごと）、天気の強さと月が分かる
- **体で**：てっぺんへ這って上がる（帳面でも見られる）
- **段**：S1 風見と予報の板 ／ S2 雨量計、板が1時間ごとに ／ S3 回る台にホラガイ（遠くの雷を聞く）と望遠鏡、月の円盤
- **海から**：島のてっぺんのシルエットが、段ごとに高く複雑になる。中からは、天窓を見上げると観測所の影が見える

### 苗床
- **すること**：球根・根株・種を植える。苗床育ちの札
- **体で**：池に浸かってから、這って水を垂らす
- **段**：枠が増える（2〜3 → +1 → +2）。増えた枠の植物が、天窓へ向かって壁を這い上がる
- **海から**：天窓のふちから緑が垂れる。島のてっぺんが緑になっていく

### 染め場
- **すること**：色花を食べ、島の土を体に塗る → 体の色。媒染。銃とバッグも染める
- **体で**：色の池に浸かる、土に這って塗りたくる
- **段**：S1 浅い色の池1つ ／ S2 媒染の壺3つ（灰・岩塩・黒い塩） ／ S3 シャコガイの池2つ、染めた布を干す綱
- **海から**：崖の外に、自分の色の布が干される（友達の拠点と見分けがつく）

### 乾燥室
- **すること**：干す（安い、値打ちが少し落ちる）か、塩漬け（塩がかかる、落ちない）
- **体で**：物を背負って干し棚へ這い上がり、引っかける
- **段**：S1 岩棚と干し縄 ／ S2 棚が3段（干せる数が増える） ／ S3 主軸から大うちわがつながり、揺れて速く乾く
- **海から**：崖の風穴の外へ干し縄が張り出し、干した葉や実が見える

### 細工場（今の「工房」。拠点ぜんぶが工房になるので名前を変える案）
- **すること**：今ある道具の上の版を作る（大きい苔玉、殻の箱）。殻アーマーとバッグを直す
- **体で**：主軸で回る砥ぎ車に、殻を体で押し当てて削る
- **段**：S1 作業台と道具掛け（壁に道具の形の跡。持っている道具が掛かる） ／ S2 主軸に砥ぎ車がつながる、苔玉の型 ／ S3 丸ごとの嵐の実の殻を挟む削り台
- **海から**：崖の穴から湯気（発酵の壺。銃の炭酸ガスの出どころ）

### 地図の台
- **すること**：帰ったらバッグをひっくり返して広げる。帳面（数・売る）。地図とコンパスはここだけ。出撃の前後に友達と囲んで集まり、行き先を相談する（集会所）
- **段**：なし。ふちに、シーズンごとの刻み目
- 池のそばで、滝の音が聞こえる。拠点のどこからも見える真ん中

### 問屋と行商人
- **すること**：植物を売る（いつもの値）。朝は道具の、夕方は花と草の行商人の舟が桟橋に着く
- **体で**：物を窓口に投げ入れる（投げるは島の操作）
- **海から**：桟橋の舟で、いま行商人が来ているか分かる
- 植物の籠（種類ごとに1つ）は問屋の脇。塩箱は精製所の入れ口の脇（置き場は2つ。Oct 17 のまま）

### 図鑑の棚と飾り枠
- **すること**：図鑑は植物と石の見本が1種ずつ並ぶ（押し葉、かけら）。飾り枠は大物や一点物に来歴の札
- **場所**：滝の横の段を上りきった踊り場の両わき。帰るたびに前を通り、友達を招いたときも通る
- **段**：図鑑は埋まった数で棚が伸びる。飾り枠は1つずつ足す

### カタツムリの小屋
- 水路わきの、低くて湿った所。疲れたカタツムリが殻にこもって休む（11章）

### 鳥の発着と巣
- 発着場は海側の口の外、桟橋の横（流木の台にヤシ縄の枠）。巣は崖の上の方。帰りの鳥は、しるしが全部見える向きから拠点に寄る（水車・てっぺん・布・干し縄・緑・湯気が一度に見える角度）
- 口のまわり（発着場・桟橋・問屋の窓口）は、小さな広場になる。招いた友達もここに着く

## 動線（Nov 2 わくさん：無難の形で、わくわくさせる）

**帰りは水をさかのぼり、出るときは水と一緒に海へ下る**。建築家さんの「縮めてから開く」を使う。

帰り：
1. **海から寄る**：鳥が海の上を低く飛んで島へ。崖から海へ落ちる水の筋が目印。水車、てっぺんの観測所、干した布が一度に見え、育ったのが分かる
2. **着く**：口の外の発着場に籠が下りる。目の前は崖の口で、水路の水が海へ落ちるしぶき。桟橋に行商人の舟がいれば、それも見える
3. **縮める**：口の奥は低くて狭い、暗いトンネル。水路と並んで歩く。油の灯がぽつぽつ。奥から水車の音がだんだん大きくなる
4. **水車の横**：トンネルの途中で横の壁が開き、回る水車と太い主軸が見える。臼の下に、留守の間に挽けた白い粉がたまっている（帰ってきて最初の小さなごほうび）。上の岩棚に乾燥室、主軸の先に細工場
5. **滝の横の段**：小さな滝の横の岩の段を上る。しぶきを浴びて、体が濡れて潤う（帰ってきてほっとする）
6. **開く**：段を上りきった踊り場（両わきに図鑑の棚と飾り枠）の先で、天井の高い丸い広間がぱっと開ける。天窓の光の柱、池、苗床の緑、染め場の布。真ん中に地図の台。先に着いた友達が台を囲んでいる
7. **広げる**：地図の台でバッグをひっくり返す

出るとき：
1. **集まる**：地図の台を囲んで、地図と予報を見て行き先を決める
2. **下る**：滝の横の段を下り、水の流れと同じ向きにトンネルを下る
3. **支度は道の途中**：臼の型から、できた弾を取って出る（精製所は通り道にある）
4. **光の口へ**：暗いトンネルの先に、海のまぶしい口。籠に乗ると、鳥が輪をつかんで持ち上げる。振り返ると、崖の水車が回っている

- 一人で帰ってすぐ出るときも、道は一本で迷わない。寄り道の設備（染め場・苗床・観測所）は、広間とてっぺんにある

## 決まったこと（Nov 2 わくさん）

- 水車の主軸1本で、精製所の臼・乾燥室の大うちわ・細工場の砥ぎ車の3つを回す
- 水車は崖の口から半分外に出て、海から回っているのが見える
- 今の「工房」は「細工場」と呼ぶ
- 動線は上の「動線」（鳥は海側の口に籠を下ろす）
- 集会所の面も持たせる：招くのは友達（パーティ4人まで）。出撃の前後に地図の台を囲んで集まり、そのまま一緒に出る
- 出撃前の食事はなし

## 上がった瞬間の光と音（案）

- 晴れなら、天窓の光の柱がその設備まで傾いて当たる。雨と夜は、その設備の油の灯がぱっとともる
- その設備の音（臼のごろり、うちわのばさり、砥ぎ車のしゅう）が、一度大きく鳴る
- 外のしるしも、そのとき一緒に足される（次に鳥で帰るとき、海から見える）
