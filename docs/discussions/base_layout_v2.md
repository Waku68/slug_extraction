## ひとことで

**水が削った岩の段々に、ナメクジが流木の板と梁で足場を渡した工房。**

岩はそのまま（でこぼこ、割れ目、水たまり）。ナメクジが手を入れたのは、歩く所と使う所だけ。板の道は「ここを通ればいい」の印にもなる。

## 床：岩の段々と板の足場

- **岩の床は北（池）が高く、南（トンネル）が低い**。水が上から下へ削った形なので、水の流れと床の傾きがそろう。帰りは水をさかのぼって上っていく（決めた動線のまま）
- 段は3つ。下段（南、トンネルから上がった所）・中段（真ん中）・上段（北、池）。段の差は 0.6 m くらい（ナメクジの目の高さより少し上。人なら 2 m の崖）。段のふちは水にえぐられて丸く、ところどころ割れて水がしみ出す
- 岩の表面はでこぼこ（±0.15〜0.3 m のこぶとくぼみ）。くぼみには水たまり
- **歩く所は流木の板の足場**：太い流木の梁を岩のこぶからこぶへ渡し、その上に板を並べて平らにする。板と岩の間にはすき間があり、下に岩や水が見える。段と段は板の階段（1段 0.15 m）か板の坂でつなぐ
- 設備は板の台（デッキ）の上に置く。臼や地図の台は、でこぼこの岩の上に梁を組んで水平にした台
- 天井の下にも太い梁を何本か渡す（絵の1枚目の木組み）。灯・干し縄・滑車を吊るす。2階は岩の棚ではなく、壁の岩のこぶに梁を差しこんだ**木の回廊**
- トンネルの床もでこぼこの岩。東の水路ぞいに板の道、行商人の前だけ板の床

## 水路：3本

池から3本に分かれて、どれも最後は水車へ集まる。

| | 通る所 | 何をしているか | どこで渡るか |
| --- | --- | --- | --- |
| ① 本流 | 池 → 小さな滝 → 東の段をつたって下段へ → 段の横の滝 → トンネルの東 → 出口の手前で西へ → 水車 | 水車を回す。いちばん太い（幅 0.9 m） | 下段で板の橋、トンネルの出口の手前で橋 |
| ② 染め水 | 池の東のあふれ → 染め場の3つの浅い池を順に → 中段を細く流れて本流へ | 染め場に水を入れて出す。**染めた日は、色のついた筋が本流まで流れていく**（友達にも分かる） | 渡る所は板の橋（Nov 3） |
| ③ 苗床の水 | 池の西 → 苗床の植え箱の足元 → **地図の台の板の下をくぐる** → 下段で本流へ | 苗床に水をやる。地図の台を囲むと、足元の板のすき間から水が見え、音がする | 板の下なので渡らない |

- どれも幅 0.2〜0.4 m の細い溝（①だけ太い）。岩を削った溝で、ところどころ流木の樋でつないだり、小さな落ち口がある
- 水路の小さな水門（板1枚の堰）で流れを切り替える案は、あとで（触って遊べる所になる）

## 動線（決めたとおり、段々が足されただけ）

- 帰り：籠 → 口 → トンネルの板の道（行商人・水車の横）→ 橋 → 段の横の滝の段を上る → 下段の踊り場（図鑑・飾り枠）→ 板の階段で中段へ → 地図の台で広げる
- 出るとき：地図の台 → 下段の精製所で型から弾を取る → 段を下りる → トンネル → 橋 → 口 → 籠
- 寄り道：上段の苗床と染め場（③と②をさかのぼる）、西の回廊から乾燥室 → 3階 → 崖の中腹の観測所
