# 書物などの人工物のレアアイテム：どこに置き、何を強くするか（Claude といつもの3人＋4人）

Nov 3, 2026

> **このあと（わくさんの判断、Nov 3）**
> 1. パワーアップはなし（決めてほしいことの 1 は「強くしない」）。人工物は高い売り物として考える
> 2. 1つは海岸の**ボトルシップ**（栓をしたガラス瓶の中の舟。ガラスが守ったので残った）
> 3. 岩塩の洞窟は**塩に閉じこめられた海の魚**（人工物ではない。山がかつて海だった手がかり）。チャットで出した案：塩漬けの本、人の塩掘りの道具、地球儀、人の靴、オルゴール（拾うと鳴る）、木彫りの人形、昔のアモレ、色の布の巻物、海の魚
>
> 4. 最初の版に塩の魚を入れる（ボトルシップは本版から）
>
> spec 6章「珍しい拾い物」と1章・2章に書いた。出方・値段・大きさは Claude 案の【仮】
>
> Claude の考え（チャットで答えた。決まったら spec に書く）：賛成。値段は一番の当たりと同じ「ふつうの稼ぎ1回分」まで。小さい物は飲みこめるが安く、大きい物（浮き玉・瓶の書物、30 cm くらい）は飲みこめず高い。値段以外の理由は「なぜそこに残ったか」と「売るか飾るか」

**お題（わくさん）**
- 「植物だけじゃなくて、書物とかの人工物みたいなレアアイテムも作りたい。どこに置くかは微妙だけど。主人公のパワーアップとかにも使えるんじゃないか？」

**読み方（違っていたら直す）**
- 「人工物」は、植物・塩・殻のような自然物ではなく、誰かが作った物、と読んだ。人間の物か、昔のナメクジの物かは決まっていない
- 「パワーアップ」は、自分のナメクジが強くなること。体（熟練）・道具・拠点・知っていること、のどれを強くするかは決まっていない、と読んだ
- Oct 26 に「秘伝書はなし（ピンとこない）」と決めている。今回はそれに近いので、「何が違えばピンとくるか」から話す
- 形と遊び方が変わるお題なので、おすすめは「無難」と「攻め」の2つ。本版の話をして、最初の版（試合型、岩塩の山のまわり）に入れるかは最後に聞く

## 前提（いまの状態）

- 【決定】人類が滅んだあと。人間の痕跡はほぼ残っていない。ナメクジの技術は人間の技術を受け継いだ物（2章）
- 【仮】島が乾く理由は謎のまま、ストーリーの縦軸。植物の古い名前に、なぜか海の言葉が残る（ヒデリベニの古い名前「サンゴソウ」）
- 【決定】秘伝書はなし（Oct 26）。中身を「技」に変えた刻み殻（カタツムリの古い殻に刻んだ技）も一緒に外した（`spec_history.md`）
- 【決定】食べて変わるのは湿り気と体の色だけ（数字の強化はしない）。撃ち合いの差は育ちきっても −15% くらい。大きく差が出るのは荷物と乾き
- 【決定】植物のレア度は確率ではなく条件で決まる（予報と図鑑を読めば狙える）。色や星は出さず、形と、手に持ったときのキラキラで分かる
- 【決定】細工場で作るのは今ある道具の上の版だけ。物々交換は植物 → 珍しい道具の一方通行
- 【決定】設備のいちばん上の段（S3）は、アモレと島の大物1つ（シャコガイ、ホラガイ、割らない嵐の実など）で上がる
- 【決定】飾り枠に来歴の札。図鑑は体験で埋まる。大干ばつで全部消える
- 【仮】珍しい物でも、一番の当たりでふつうの稼ぎ1回分くらい
- 体の隠し場所（おなか）には塩は入れられない。いまは「小さくて大事な物」の行き先が少ない
- 【未決定】島に建物を置くか。置くなら昔のナメクジの物（崖の村など。`buildings_discussion.md`）
- 最初の版からは、熟練・体を鍛える・設備の大半を外す（1章）
- spec の参考にピクミン（人間が消えた後の自然）がある。ピクミンは人の物を「お宝」として拾う

## それぞれの考え

**Claude（司会）**
- 秘伝書がピンとこなかったのは、「巻物を読むと強くなる」が、この島のどこにも理由がなかったからだと思う。今回の「人工物」は、**なぜそこに残っていたか**を世界に持たせられれば、別物になる
- その理由の案：熱帯の雨はほとんどの物を腐らせる。残るのは**塩とガラスに守られた物だけ**。だから人間の痕跡は「ほぼ」ない、の「ほぼ」がこれになる。岩塩の洞窟の塩のきのこを掘ると、まれに塩に閉じこめられた古い物が出る。嵐のあとの海岸には、ガラスの浮き玉や栓をした瓶が打ち上がる
- 「書物」は、瓶の中か塩の中の紙なら残れる。人間の植物図鑑の頁が出て、それが「植物の古い名前に海の言葉が残る」理由につながる、という筋が作れる
- パワーアップは、体の数字ではなく**道具か、知っていること**にしたい。体の数字にすると、秘伝書と同じ所に戻る

**廃人**
- タルコフで一番脳汁が出るのは、LEDX みたいな**小さくて高い物**を拾った瞬間。そこから先は「生きて帰れるか」だけになる。このゲームなら、それを**飲みこんで隠し場所に入れる**かどうか、で一回悩める。隠し場所の使い道がやっとできる
- 拾い物で体が強くなるのは反対。運のいい奴が強くなる。タルコフの隠れ家みたいに、**拠点の設備の材料**にするなら大歓迎（S3 の大物の横に「人工物1つ」）
- 出る場所は決まっていてほしい。「あの洞窟の奥のきのこに出るかも」で人が集まる。完全ランダムなら、拾い物は報酬じゃなくて宝くじ

**スプラ**
- 書物って聞くと地味。でもガラスの玉が光ってるとか、知らない形の金属とかなら欲しい。棚に並べて友達に見せたい
- パワーアップなら、見て分かるのがいい。レンズを銃に付けたら、銃の見た目が変わる、みたいな。数字だけ上がっても分からない
- ピクミンのお宝みたいに、人の物にナメクジが変な名前を付けてたら笑う。図鑑を読むのが楽しくなる

**辛口**
- 8日前に秘伝書を外したばかり。名前を変えて戻すだけなら、また「ピンとこない」で終わる。違いを1行で言えないなら作らない方がいい
- 作る量：人工物は1つごとに、モデル・図鑑の文・効き目・出る場所が要る。最初は**3〜5種類まで**。植物の「その植物だけの理由を1つ」と同じ決まりを、人工物にもかける
- 書物の字を読ませるのは重い（文章を書く、訳す、読む人を待たせる）。字は数行まで。**形と出た場所で語らせる**方が、一人で作れて、世界の謎も壊さない
- 人の物があちこちに落ちていたら、「人間の痕跡はほぼない」が壊れる。島に数個、くらいの珍しさを守るべき

**考古学者**
- 残る理由の話は本当にそう。湿った土ではまず木や紙が消え、残るのは土器・石・ガラス・金属の一部。逆に**塩は物を残す**。オーストリアのハルシュタットの岩塩坑では、何千年も前の木の道具や布が塩の中から出ている。イランの岩塩坑からは、塩漬けのまま残った人も出た
- 大事なのは出土の様子。いきなり手に入るより、**半分埋まっているのが見えて、掘り出す**のがいい。大雨で崖や川岸が削れたあとに顔を出す、乾いて池の底が出たら見える、という出方は本物どおり
- 拾った場所と、一緒に出た物を、来歴の札に自動で書いてほしい。「塩の中から、黒い塩と一緒に」という1行で、物の値打ちが変わる

**民俗学者**
- ナメクジは人の物の使い道を知らない（技術は受け継いでも、物そのものは見たことがない）。だから**ナメクジの言葉で呼ぶ**のがいい。浮き玉は「海の目玉」、硬貨は「丸い鱗」、鍵は「歯の生えた棒」。図鑑には「何に使った物かは分からない」と1行
- 言い伝えになっている物があると楽しい。「海の目玉を拠点に置くと雨が来る」とナメクジが信じている。効くかどうかは分からない、でいい
- 書物は1枚では読めず、何枚か集まると**少しずつ読める**、なら島の謎と相性がいい。ただ、全部読めたら謎が終わるので、最後の1枚は出さない

**モンハン勢**
- モンハンの「そこにしかない素材」は好き。でも護石みたいに**何が出るかランダムで、性能もランダム**なのは疲れた。人工物は「どこで出るか」は分かっていて、「出るかどうか」だけ運、くらいがいい
- 使い道は、素材として**道具の上の版**を作るのが一番分かりやすい。例：ガラスの瓶 → 浸し直しが1回多い水筒（苔玉の上の版）、レンズ → 覗くと少し遠くまで見える照準。細工場の決まりの中に収まる
- 道具にすれば、倒れたら失う。「せっかくの瓶の水筒を持って出るか」で迷えるのがいい

**山菜名人（反対）**
- 山の当たりは、天気と季節と場所を読んだ人に来る。それがこのゲームの植物の決まりで、一番いい所。そこへ「たまたま拾った物で強くなる」を入れたら、山を読む人が損をする
- 人の物は、山で見つけても嬉しくない。山で拾うのはごみだ。ナメクジの島なら、なおさら
- 入れるとしても、強くする物にはしないでくれ。図鑑の古い名前を1行増やす、くらいでいい。最後まで、パワーアップには反対だ

## わくさんに決めてほしいこと

1. **人工物で何を強くするか**（大きいほう）
   - おすすめ（無難）：**道具と拠点を強くする**。体は強くしない（秘伝書なしのまま）。人工物は細工場で道具の上の版の材料（ガラス瓶 → 水筒、レンズ → 照準）、または設備の S3 の材料。売る・飾るもできる。道具なので倒れたら失う（モンハン勢・廃人）
   - おすすめ（攻め）：**知っていることを強くする**。書物（人間の植物図鑑の頁）を持ち帰ると、図鑑のその植物に「いつ・どこで」が書き込まれる（ツキシロの咲く6か所、ヒバナの出る割れ目）。集まるほど島が乾く理由に近づく。数字の強化はゼロ。強さ＝知っていること（民俗学者）
   - 売る・飾るだけ（山菜名人）
   - 体を強くする（秘伝書に戻す。【決定】をひっくり返す）
2. **誰が作った物か**：人間の物（塩とガラスの中だけ残った「ほぼ」の分。ナメクジの言葉で呼ぶ。おすすめ）／昔のナメクジの物（建物を置くなら崖の村から）／両方
3. **どこに出すか**（おすすめを1つ目に。いくつ選んでもいい）
   - 岩塩の洞窟の塩の中（塩のきのこを掘ると、まれに。いちばん危ない所に、お金以外の理由ができる）
   - 嵐のあとの海岸（浮き玉、栓をした瓶。予報で狙える＝条件で出る）
   - 大雨で削れた崖と川岸、乾いて出た池の底（シーズンの後半ほど増える）
   - カタツムリの殻とボット（いまの「ときどき珍しい物」の中身）
4. **最初の版に入れるか**：1つだけ入れる（岩塩の洞窟の塩の中から、小さくて高い物。飲みこんで隠し場所に入れられる。おすすめ。廃人）／入れない
5. **書物の字**：数行まで、形と出た場所で語らせる（おすすめ。辛口）／何枚か集めて読める文にする（民俗学者）

この案で作って「平凡」と言われたら、なぜ？ → 人工物が「ちょっと高い拾い物」で終わり、なぜそこに残っていたか（塩とガラス）と、手に入れたあとの迷い（飲みこむか、道具にして持ち出すか）が遊びに出ていなかったから。
