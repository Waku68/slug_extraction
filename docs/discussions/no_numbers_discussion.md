# 数字を出さない世界の話し合い：バッグの数字を島でも拠点でもなくしたら（Claude と固定の3人＋3人）

Oct 5, 2026

> **このあと（わくさんの判断）**：お金としての塩だけは数字を入れたい。人間から文明を受け継いで銃も作れるのに、数字がないのはおかしい。天秤、分銅、秤（解放？）があってもいい。続きは `no_numbers_discussion_2.md`。

**今回のお題（わくさんの問い）**
- この世界にはあまり数字を乗せたくない。調べて分かるくらいがいい。必要ならゲージで出す。現実みたいな不便さもいい（湿り気の話し合いのあと）
- バッグも、島では数字なし、**拠点でも数字なし**だったらどうなるか。**話し合うだけで、決めない。**

**今のバッグの数字**（`SlugBag` の画面）
- 常時（左上）：バッグの形が膨らみで大きくなり、**重さで色が変わる**（緑 → 黄 → 赤）。耐久は細い線
- Q で覗いたとき：一番上とその下の名前、重さ（閾値）、速さの倍率、中身の数、かさ（上限）、価値（塩でいくら）、耐久、体の中の物
- 仕様：「常時は体表示に荷物の影、覗いたときだけ数字、拠点では全部数字」

## 1. まず全員の意見

**Claude**：今出している数字を、数字なしなら何で伝えるか、並べてみます。

| 今の数字 | 数字なしなら |
| --- | --- |
| 重さ | 体で感じる（這う音が重くなる、体が伸びにくい、閾値の手前で体がきしむ）。超えたら ×0.3 なので、超えた瞬間ははっきり分かる |
| 閾値まであとどれくらい | ここが一番難しい。超える前に気づけないと、急に遅くなって驚く |
| かさ・上限 | バッグの膨らみ（もう見えている）。上限のあるバッグは、ふたが閉まらなくなる |
| 耐久 | 破れ、ほつれ、当て布。撃たれるとビリッと音 |
| 価値 | 物の見た目（珍しい物は光る）、図鑑に「高く売れる」 |
| 中身の数 | 覗いたときに見える上の2〜3つ。全部は分からない |
| 速さの倍率 | 動けば分かる |

島の中では、どれも代わりがあります。問題は拠点です。塩は通貨なので、物を買うときに「いくら」が要る。

**廃人**：
- タルコフは表計算のゲームだ。倉庫の総額を計算して、どの装備で出るか決めるのも楽しみの一つ。それが全部なくなるのは正直さみしい
- ただ、タルコフでもマガジンの残りは、手で触って「だいたい半分」としか分からない。あれは好きだ。島で数字なし、はむしろ賛成
- 拠点で数字なしだと、「今週いくら稼いだか」が分からない。それでも続けられるかは、塩の山が目に見えて増えるかどうかだ

**スプラ**：
- 数字ってつまんない。拠点に塩の山がドーンって積み上がってたほうが、絶対かっこいい
- 友達に「今日これだけ取った」ってスクショ見せたい。山の写真なら見せられる
- でも、何をいくらで買えるか分からないのは困る

**辛口**：
- 世界観としては筋が通っています。シックな世界で、数字の表が出ない。柱2（雨に濡れた自然の手触り）にも合う
- ただし、隠した数字は消えません。Wiki に移るだけです。作る側が「調べて分かる＝Wiki で分かる」でいいのか、決めておくべき
- もう一つ。数字は安い。見た目で伝えるのは高い。破れ、膨らみ、きしむ音、体の伸び方。全部作る必要がある。一人開発なら、伝え方を絞らないと手が回りません

**UIデザイナー**：
- 「正確な値が分からない」は、プレイヤーは意外と平気です。困るのは「今どの段階か分からない」とき。3〜4段階がはっきり見分けられれば、数字はいらない
- 一番危ないのは、閾値のような「崖」です。超えると ×0.3 は、とても大きな変化。崖の手前で必ず気づける合図がほしい。体がきしむ、這う音が変わる、を閾値の手前の少しの範囲で
- 画面の常時表示を減らすほど、「確かめる動作」（Q で覗く）の気持ちよさが大事になります

**Wiki編集者**：
- 断言します。発売して1週間で、全部の重さ、閾値、耐久、値段が測られて、表になります。タルコフもエルデンリングもそうでした
- それは悪いことではありません。「調べて分かる」の一番強い形が、みんなで調べることです。ただ、そのためには決まりが一定であること。同じ物はいつも同じ重さ、のように
- 大干ばつ（ワイプ）で数字を少し変えると、毎シーズン「測り直し」のお祭りが起きます

**色覚の人**：
- 今の左上の、重さで緑から黄、赤に変わる色は、私には緑と赤の区別がつきにくいです。数字がなくなるなら、色だけに頼るのはやめてほしい
- 形（膨らみ、破れ）、大きさ、音、言葉なら分かります。「重い」「とても重い」と言葉で出るのは、数字でなくても助かります
- 数字なしの世界ほど、色以外の手がかりを重ねてほしい

## 2. 話し合い

**Claude**：拠点の「いくら」の問題から。物を買うとき、値段をどう伝えるか。

**辛口**：仕様には「拠点で持ち帰ったバッグの中身を広げる演出を作り込む」があります。広げた物が、塩の山になって倉庫に積もる。持っている塩は「山の大きさ」で分かる。

**スプラ**：山！

**廃人**：山の大きさでは、買えるかどうかが分からない。

**Claude**：天秤はどうでしょう。工房で買いたい物を片方の皿に載せ、もう片方に自分の塩を載せていく。釣り合ったら買える。値段は数字ではなく、天秤が傾くかどうかで分かる。

**UIデザイナー**：分かりやすいです。「足りない」「ちょうど」「余る」の3段階が、目で見て一瞬で分かる。

**色覚の人**：傾きは色ではないので、私にも分かります。

**廃人**：……悪くない。ただ、2つの装備のどちらが高いかを比べたい。

**Wiki編集者**：天秤に2つ載せて比べればいい。比べるだけなら数字はいらない。

**辛口**：「比べる」はできる、「いくら」は言わない。この線引きは、筋が通っています。

**UIデザイナー**：閾値の崖の話を。体がきしむのを閾値の手前から始めるとして、どれくらい手前から？

**Claude**：閾値の8割くらいから。きしむ音が少しずつ大きくなり、超えたら一気に遅くなる。

**廃人**：それなら、きしみ始めたら「あと少し」と分かる。数字がなくても計画できる。

**Wiki編集者**：そして Wiki に「岩塩なら6個できしみ始める」と書かれる。

**辛口**：それでいいと思います。自分で体験しても、Wiki で読んでも、同じことが分かる。

**スプラ**：友達に見せたい話は？

**UIデザイナー**：拠点で広げる演出と、塩の山。スクショで見せられるのは、数字の表より山です。

**廃人**：一つだけ譲れない。死んで全部失うゲームで、何を失ったかが分からないのは困る。

**Claude**：拠点に戻ったとき、「持ち帰れなかった物」を広げて見せる（灰色で）。数字ではなく、物で。

**廃人**：それなら痛みが見える。いい。

**色覚の人**：灰色だけでなく、ひびが入ったり、欠けた形にしてもらえると分かりやすいです。

## 3. 暗黙の了解をひっくり返した案（3つ）

### 3-1. 「数字は画面に出すもの」→ 数字は世界の中の道具で測る

**Claude**：拠点に秤、天秤、物差しがある。画面に数字は出さないが、道具で測ればだいたい分かる。秤の針が「ここまで来たら背負える限界」の印を指す。

**Wiki編集者**：秤の目盛りは、調べて分かる、そのものです。

**辛口**：数字を出すかどうかではなく、「測る手間」を入れる、という考え方。わくさんの「調べて分かる」「現実みたいな不便さ」に一番近い。

**UIデザイナー**：秤は拠点だけ。島には持っていけない。島では体で感じる、拠点で答え合わせ、の二段構えになります。

**廃人**：答え合わせができるなら、表計算の楽しみも少し残る。

### 3-2. 「重さは表示で知る」→ 重さは体で感じる

**Claude**：重いと、這う音が重くなる、体が前に伸びにくくなる、一人称の揺れがゆっくり大きくなる。閾値の手前（8割くらい）で体がきしみ始める。

**スプラ**：重そうに這うの、かわいい。

**色覚の人**：音と揺れなら、色に頼らない。助かります。

**辛口**：これは作る量に見合います。這う動きはシェーダーと移動の数字でできているので、重さで値を変えるだけ。新しい絵はほとんど要らない。

**UIデザイナー**：左上の自分の体（自分を映す小窓）にも出ると、外からも見えて確かめられます。重いとバッグが大きく、体が沈んで見える。

### 3-3. 「情報はゲームが教える」→ 自分で記録する

**Claude**：図鑑は、体験で埋まっていく。初めて岩塩を拾うと「重くて小さい」、初めて閾値を超えると「これ以上は背負えない（岩塩なら〇個くらい）」と、自分の言葉ではなく、ナメクジの日記のような書き方で書き込まれる。

**Wiki編集者**：体験して埋まる図鑑は、みんなで調べる文化とも両立します。図鑑を埋めるのが、自分の調べた記録になる。

**スプラ**：日記、見せ合いたい。

**廃人**：図鑑に「〇個くらい」と書くなら、それは数字では？

**辛口**：「だいたい」で書くなら、正確な数字とは違います。人が覚えておく程度の数。わくさんがどこまで許すかです。

## 4. 極端案（2つ）

### 4-1. 数字も文字も一切なし（物の名前も出さない）

**Claude**：拾った物の名前も出さない。見た目だけ。

**色覚の人**：見た目だけだと、似た色の物を見分けられません。

**スプラ**：名前がないと、友達に「あれ取った」って言えない。

**辛口**：拾える部分は「名前は、図鑑で一度調べると出る。初めて見た物は名前なし」。見つける楽しみが増えます。

**Wiki編集者**：初見の物は名前が「？」、は、発見の喜びとして強いです。

### 4-2. 拠点は数字の表だらけ（帳簿の部屋）

**Claude**：島は数字なし、拠点の一室だけ、全部の数字が表で見られる。

**廃人**：俺はその部屋に住む。

**辛口**：世界観が、その部屋だけ崩れます。

**UIデザイナー**：拾える部分は「比べることだけはできる」。天秤に2つ載せる、2つの袋を並べる。絶対の値は出さず、どちらが上かだけが分かる。

**廃人**：比べられるなら、どの装備で出るかは決められる。我慢する。

## まとまったこと（決めていない。わくさんが決める）

**島でも拠点でも数字なしにすると、どうなるか**
- **良くなること**：世界観と柱2に合う。拠点で中身を広げる演出と塩の山が主役になる（スクショで見せられる）。比べる・測る手間が遊びになる。大干ばつのたびに「測り直し」のお祭りが起きる
- **困ること**：
  1. 買い物の「いくら」が要る → 天秤で払う（釣り合えば買える）
  2. 閾値の崖（超えると ×0.3）に、超える前に気づけない → 閾値の8割くらいから体がきしむ、這う音が重くなる
  3. 何を失ったか分からない → 拠点で「持ち帰れなかった物」を、ひびの入った形で広げて見せる
  4. 色だけの合図は見分けられない人がいる → 今の左上の「重さで緑→黄→赤」はやめ、形・大きさ・音・言葉を重ねる
  5. 見た目で伝えるのは作る量が増える → 伝え方を絞る。重さは這う音と揺れ（今の仕組みの値を変えるだけ）、耐久は破れ、上限はふたが閉まらない
- **隠した数字は、Wiki で必ず表になる**。それを「調べて分かる」の一つとして受け入れるなら、決まりは一定にしておく（同じ物はいつも同じ重さ）

**拾った案**
- 拠点の秤・天秤・物差しで測る。島では体で感じ、拠点で答え合わせ（3-1）
- 重さを体で感じる：這う音、伸びにくさ、揺れ、閾値の手前からきしむ（3-2）
- 図鑑は体験で埋まる、ナメクジの日記のような書き方（3-3）
- 初めて見た物は名前なし、図鑑で一度調べると名前が出る（4-1 から）
- 絶対の値は出さず、比べることだけできる（4-2 から）

**残った意見の違い**
- 図鑑に「〇個くらい」のような、だいたいの数を書くか（数字に入るか）
- 廃人の「倉庫の総額」の楽しみは、塩の山と天秤で足りるか

**わくさんに決めてほしいこと**
- 拠点も数字なしにするか（島だけなしにするか）
- 買い物は天秤で払う、でいいか
- 拠点の秤や物差しで「測れば分かる」を入れるか
- 図鑑に、だいたいの数（「〇個くらい」）を書いてよいか
- 今の左上の「重さで色が変わる」をやめて、形と音にするか
