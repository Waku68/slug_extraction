## 4. シーズンの長さ

おすすめ：**10 週（大雨季 3週 → 乾季 2週 → 雨季 2週 → 大乾季 3週）**。祭りは最後の1週。

（無難の数字。攻めもほぼ同じ）

- 値段は「何時間遊ぶと買えるか」で決めたので、長さを変えても値段は変えなくていい。決め手は、お金の谷（塩が少ない）と山（塩が多い）の長さ
- 始めの大雨季を3週に：塩が少なく弾が貴重な「集める時期」に、週11時間の人も拠点の必須を終えて、少し貯められる（3週で約33時間）
- 終わりの大乾季を3週に：塩が多く弾が安い撃ち合いの時期。たまったお金の使い道（良い塩の弾、失う前提の装備）がいちばん多い時期を長く
- 一人で作るので、新しい島や物を足すのは2か月半に1回なら追いつきやすい。12週だと、週28時間の人が「買う物がない」時期が2か月以上続く（雨乞いのような大きな出口が要る）
- 島時間では、3週＝島の 53 日、2週＝35 日

**廃人**
- 無難。装備をなくす怖さが「重い荷物で帰る怖さ」に重なるのが脱出ゲーム。1.8 回分は、タルコフの感覚にちょうどいい
- 攻めの弾3倍だと、撃ち合いの最中に財布を数え始める。撃つか迷った一瞬で撃たれる

**スプラ**
- 攻めがいい。友達と行くとき、毎回いい銃を持っていけるのがうれしい。こわいのは袋をなくすこと、ならみんな同じ
- でも弾が高くて撃てないのはつらい。カタツムリを撃つのも損なの？

**辛口**
- どちらも決まりが1つで覚えやすい。無難は「2倍」、攻めは「装備はそのまま、弾だけ3倍」
- 攻めは、膨らんだ袋が値札になるのがこのゲームだけの形。ただ、膨らみが遠くから本当に見えるかを先に確かめないと、ただの高い弾になる

**運営の経済担当**
- 塩が島じゅうで3.6倍に増えるので、シーズンの後半はお金が余る。出口は、失う装備（無難）か撃つ弾（攻め）。攻めの方が「使った分だけ減る」がはっきりしている
- 最初の版はシーズンがない。試しのシーズンで消すことを最初に言っておかないと、消したときに怒られる

**経済勢**（反対）
- 出口を2倍にするのは、インフレを認めること。1回 40 アモレ、シーズンで1万では、延べ棒1本の重みが消える。袋が3倍になったなら、物の値打ちを3分の1にするべき（岩塩 1、雨カブ 1/3）
- Claude：雨カブ 1/3 は数えにくく、弾の値段とのつながりも全部ずれる（前の話し合いで、岩塩の値打ちは動かさないと決めた）。延べ棒の重みは「1回の稼ぎが約40」で覚えてもらう
- 経済勢：それでも、数字が大きいほど小さな物は捨てられる。色花（5本で1）は、もう誰も摘まない
