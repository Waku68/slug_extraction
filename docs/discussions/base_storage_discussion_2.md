## 1. それぞれの意見

**Claude**
- 困ることは2つに分かれます。①混ぜると「いつ持ち帰った物か」が消える。②腐る前に気づけない
- ①は、**束を混ぜない**で解けます。数はまとめて見せても（雨カブ 23）、期限は束ごとに持つ。籠の中に束が並んでいて、新しい束は奥、古い束は手前
- 売る・使うのは**古い束から**にすれば、見るのは手前の束だけでいい
- ②は、籠の前につるす見本を「いちばん古い束と同じ姿」にします。見本がしおれてきたら、その籠に急ぐ物がある。籠の前を通るだけで分かる
- 拠点は数字を出していい所なので、帳面の一番上に「次に傷む束」と「あと島で何日」を出す

**廃人**
- 期限は数字で欲しい。帳面に「傷む順」の一覧。一番上が次に傷む束
- まとめると期限が平均になる、みたいなのは最悪だ（DST勢の話を聞いた）。混ぜないでくれ
- 相場で寝かせるのは、期限と値段の天秤だ。「あと2日でしおれる、でも相場は明日上がる」で悩みたい。期限が見えないと、ただの運になる
- 傷むのは島の時計で進むのが筋だと思う。相場も行商人も島の時計で動いている

**スプラ**
- 平日は1時間しかできない。月曜に来たら全部腐ってた、だったら泣く。ログアウト中は止めてほしい
- 見た目でしおれていくのはいい。でも気づかないと思う。腐りそうな籠に、なんか合図がほしい
- 腐っても何かに使えるなら、まだ許せる

**辛口**
- 傷む仕組みは、作る量の割にストレスばかり増えやすい。何のためにあるかを先に決めるべきです。いまの理由は2つ：相場で寝かせ放題にさせない（品薄を作る）と、帰るたびに拠点ですることを作る
- 品薄に効くのは高い物（花とキノコ）です。雨カブやヒデリベニまで傷ませる必要があるかは疑問
- 束を混ぜない見せ方は安い。束ごとに山を作るのではなく、籠の中に束が2〜4個並ぶだけ
- 「良いことはログアウト中も進み、悪いことは止まる」で筋は通ります。苗床は育つが、倉庫は傷まない

**学芸員**
- 収蔵庫では、ロットは混ぜません。混ぜた時点で、その標本の記録は死にます
- 札には日付と、処理（生・干し・塩漬け）を書く。何をしたかで、持ちが違うから
- 点検には順番があります。札の古い物から見る。全部は見ない

**収納アドバイザー**
- 冷蔵庫の基本は「手前に古い物、奥に新しい物」と「期限の近い物は目に入る所」です
- 期限の近い物だけを入れる「早く使うかご」を一つ作る家が多い。籠の手前の段が、それになればいい
- 期限の見落としは、物が多すぎると起きます。持つ量を減らすのが一番効く（容れ物の大きさ）

**院生**
- ナメクジの多くは、元気な葉より、しおれた葉や落ち葉、傷んだ植物をよく食べます。ナメクジにとって傷んだ物は、ごちそうでもある
- 腐った物は土に還ります。苗床の肥やしにするのが自然です
- 傷み方は置き場所の湿り気で変わります。乾くとしおれる（水が抜ける）、濡れすぎるとかびる。湿った階の、水に触れない籠がいちばん長持ちです

**青果担当**
- 売り場は先入れ先出しです。新しく入った箱は、古い箱の後ろに入れる。お客さんは手前から取るので、古い物から出ていく
- 箱の横には、入ってきた日を書く。束ごとに札1枚、と同じです
- 毎朝見るのは、いちばん古い箱だけ。全部を見ていたら一日が終わる
- 傷みは3つで見分けます。張りがなくなる、垂れる・しわが寄る、色が抜ける。腐る一歩手前は「張り」です。ゲームでも、この3つで段階を作れる
- しおれかけたら「見切り」で安くして売り切る。捨てるより、少しでもお金に

**DST勢**
- DST は、重ねた物ひとかたまりに鮮度のメーターが1本（緑 → 黄 → 赤）。鮮度の違う物を重ねると、平均になる。便利だけど、どれがいつの物か分からなくなる
- それでも遊べるのは、メーターがいつも見えているから。腐る前に気づける
- DST には氷の箱や塩の箱があって、入れると傷むのが遅くなる。置き場所で傷み方が変わるのは、片付けを遊びにする
- 腐った物は「腐った物」という別の物になって、畑の肥やしに使える。捨てるだけじゃない

## 2. 暗黙の了解をひっくり返した案

### 2-1. 「腐るのは損」→ 腐るのも、使い道の一つ

**院生**：ナメクジは、しおれた葉が好きです。腐った物は土になる。

**Claude**：腐った物を消さずに、「くされ」（肥やし）という別の物にする。苗床に入れると、育ちが少し速くなる。腐らせても、ゼロにはならない。

**スプラ**：それなら許せる。腐ったのを苗床に放り込むの、楽しそう。

**廃人**：損は損だ。花が肥やしになっても、値段の差は埋まらない。でも、ゼロよりはいい。

**辛口**：植物ごとの理由は1つ、使い道は1〜2つまで、のきまりがあります。「くされ」は植物の種類を問わず1つの物なので、きまりに触れない。作るのも、肥やしの山が1つと苗床の効果1つだけ。

**DST勢**：DST でも、腐った物の使い道があるから、腐らせたときの悔しさが少し和らぐ。

**拾える所**：腐った物は「くされ」になり、苗床の肥やしになる（植物の種類を問わず1つの物）。腐らせても、ゼロにはならない

### 2-2. 「時計で傷む」→ 出撃の回数で傷む（帰るたびに一段）

**Claude**：傷みを時間ではなく、出撃の回数で進める。帰るたびに、拠点の植物が一段しおれる。期限は「あと2回」と数えられる。ログアウト中は進まない。

**スプラ**：これがいい！ 平日1時間でも、土日3時間でも、同じ「あと2回」。

**廃人**：相場は島の時計で動くのに、傷みだけ回数というのは筋が悪い。出撃しなければ傷まないから、寝かせ放題になる。

**Claude**：寝かせている間に出撃しないなら、その人は遊んでいないので、困りません。出撃しながら寝かせると、回数で傷む。

**青果担当**：売り場でも、日付より「何回目の入荷か」で見ることがあります。毎朝入るので同じことですが。

**辛口**：数えやすいのは大きい。「あと島で 1.4 日」より「あと2回」。ただ、パーティで出ると、全員の拠点が同じだけ傷むのか、は詰める必要がある。

**学芸員**：札に書くのが日付でなく「何回目の帰り」になると、来歴の札（いつ・どこで）とずれます。

**拾える所**：傷みは「拠点の外で遊んだ時間」か「出撃の回数」で進め、ログアウト中は止める（良いことは進み、悪いことは止まる）。どちらにするかは決めてほしい。帳面の期限は「あと何回」か「あと島で何日」

### 2-3. 「どれを売るか選ぶ」→ 選ばない。いつも古い束から出ていく

**青果担当**：お客さんは手前から取る。だから売り場は、古い物から自然に出ていく。

**Claude**：拠点もそうする。売る・使う・干すは、いつも古い束から。選ばなくていい。プレイヤーが見るのは「手前の束がどれだけ持つか」だけになる。

**廃人**：相場が高い日に、採れたての束だけ高く売りたいことがある。選べないのは困る。

**Claude**：ふだんは古い順。帳面からなら、束を指して選べる。

**収納アドバイザー**：「早く使うかご」と同じです。ふだんは考えなくていい。こだわる人だけ選ぶ。

**DST勢**：古い順に勝手に出ていくなら、混ぜて平均にする必要もない。DST より分かりやすい。

**スプラ**：考えなくていいのは楽。

**拾える所**：売る・使う・干すは、いつも手前の古い束から。帳面から選ぶこともできる。籠の中は、新しい束が奥へ入り、古い束が手前へ寄る

## 3. 極端案

### 3-1. 傷むのをやめる

**Claude**：拠点の物は傷まない。期限の悩みが丸ごと消える。

**辛口**：作る量はいちばん小さい。しおれる見た目も、帳面の期限も要らない。

**廃人**：品薄が起きなくなる。みんなが花を倉庫に積んで、品薄になった日に一斉に売る。相場が死ぬ。

**DST勢**：傷まないなら、片付けの遊びも消えます。急ぐ物がないから。

**院生**：花とキノコは、本物でも数日でだめになります。雨カブのような根の物は長持ちする。

**拾える所**：傷んで消えるのは、花とキノコだけにする案。雨カブ・ヒデリベニ・嵐の実は、しおれて値打ちが下がるところで止まる（消えない）。急ぐのは高い物だけになり、品薄も残る

### 3-2. 1つずつ全部に、期限の数字

**Claude**：Project Zomboid のように、持ち物の1つずつに期限がある。拠点では全部が物のまま、1つずつ手に取ると「あと 1.2 日」。

**廃人**：正確さだけなら、これがいちばんだ。

**スプラ**：無理。頭が痛くなる。

**辛口**：「中身は数」とまっすぐぶつかります。

**青果担当**：売り場でも、1個ずつは見ません。箱で見ます。

**学芸員**：収蔵庫でも、ロットの中の1つずつに日付は付けません。同じ日に採った物は、同じ日付ですから。

**拾える所**：期限は束ごとで足りる（同じ日に持ち帰った物は、同じ期限）。帳面に束ごとの「あと何日（何回）」を出す

## 4. まとめ（決めない）

**まとまったこと**
- **束は混ぜない**。帰った日（出撃1回）の分が1つの束。数はまとめて見せる（雨カブ 23）が、期限は束ごと。平均にはしない
- **籠の中は、新しい束が奥、古い束が手前**。売る・使う・干すは、いつも手前の古い束から（先入れ先出し）。帳面から束を選ぶこともできる
- **籠の前の見本は、いちばん古い束と同じ姿**になる。見本がしおれてきたら、その籠に急ぐ物がある。籠の前を通るだけで分かる
- **傷みは見た目で段階を作る**：採れたて → 張りがない → 垂れてしわが寄る、色が抜ける（値打ちが下がる）→ 腐る。色だけに頼らず、形で分かる（青果担当の3つ）
- **帳面の一番上に「次に傷む束」**と、その期限の数字（拠点は数字を出していい所）
- **腐った物は「くされ」**（肥やし）になり、苗床に入れると育ちが少し速い。植物の種類を問わず1つの物
- 傷み方は置き場所で変わる：1階の湿った籠はふつう、2階の乾燥室で干すと止まる（値打ちは少し落ちる）、塩漬けで止まる（塩がかかる）。いまの決まりのまま

**残った意見の違い**
- 傷むのが何で進むか：島の時計（ログアウト中も。廃人）／拠点の外で遊んだ時間／出撃の回数（スプラ）。辛口は「良いことは進み、悪いことは止まる」
- 傷んで消える物を、花とキノコだけにするか（3-1）。廃人は品薄が残るなら賛成
- 期限の数字を「あと何日」で言うか、「あと何回」で言うか

**わくさんに決めてほしいこと**
1. 束を混ぜない・古い束から出ていく・見本がいちばん古い束の姿になる、の3つでいいか
2. 傷むのが進むのは：島の時計（ログアウト中も）／遊んでいる間だけ／出撃の回数
3. 傷んで消える物を、花とキノコだけにするか（ほかは、しおれて値打ちが下がるところで止まる）
4. 腐った物を「くされ」（苗床の肥やし）にするか

## 5. 追加：ガチ勢の帳面が長すぎる問題の多数決（Oct 17）

**負けた側から拾う所**
- 廃人・DST勢：持ち帰ってから島で半日（現実 4.5 時間）たっていない物は、その夕方には変わらない。直前に帰った損を小さくする
