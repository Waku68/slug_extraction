## 2. 世界観チェック（音を決める前に）

1. **雨の夜のナメクジの世界か**：硬い物（岩塩、石）は明るく割れる。柔らかい物（植物、ナメクジの体、粘液）はくぐもって湿っている
2. **人の機械の音がしないか**：銃は火薬でなく**炭酸ガスと塩の弾**。「パン」「バーン」でなく「プシュ」「ボッ」。金属の「ガチャ」も控えめに（道具は流木・殻・石・つる）。**わくさんの擬音に「バン」「パン」があれば、そちらが優先**
3. **ポップで短いか**：参考は妖怪ウォッチ、あつ森のボタン音。何度も鳴って気持ちいい。耳に痛い高音・長い残響にしない
4. **何度鳴っても疲れないか**：移動の音（伸び・着地・這う）は1分に何十回も鳴る。主張を小さく、毎回少し違うように

## 3. 書き出し（必ず守る）

- 44.1 kHz、16 bit、**モノラル**、wav。ピーク 0.85。最後の 5 ms はフェード（プツ音を消す）。どれも `placeholder_sfx.py` の `save()` がやる
- ファイル名は **`<キー>_01.wav`、`_02.wav`…**（キーは sound_list.md の名前そのまま）。同じ音の揺らぎは番号違い。Unity が毎回 ±6% くらい高さを揺らすので、番号違いは「少し違う」で十分
- 置き場所は `Assets/Audio/Placeholder/`。**今ある音は同じ名前で上書きする**（名前を変えない・消さない・`.meta` を触らない）。そうすれば Unity の SoundBank がそのまま新しい音を鳴らす。Unity は触らなくてよい
- 長さの目安：ボタンや手の音 0.05〜0.2 秒、当たる音 0.1〜0.3 秒、銃 0.2〜0.6 秒、声 0.15〜0.4 秒
- 音の大きさ（どこまで届くか）は Unity のコードが決める。wav は 0.85 にそろえてよい
- 乱数は名前から決めた種（`zlib.crc32(name)`）で、何度作っても同じ音になる
- 動かし方：`uv run --no-project --with numpy python SoundGen/placeholder_sfx.py <キー>`（**キーを渡して、その音だけ**作り直す。渡さないと全部作り直す）。速くしたければ `--with scipy` を足して `scipy.signal.lfilter` を使ってよい

## 4. 進め方（ライフルのときと同じ）

わくさんの OK（✅）が出るまで次へ進まない。

1. **読み返し**（作る前）：わくさんの擬音を音の部品に分けて、短く返す
   ```
   音：<キー>（何のときに鳴るか、1行）
   長さ：〜秒
   形：出だし（〜ms の「〜」）→ 中（〜）→ 消え方（〜）
   高さ・質感：低い／高い、硬い／湿った、粒の細かさ など
   いまの仮の音との違い：〜
   質問：1〜3個（おすすめを1つ目に）
   ```
2. **試作を3案**：`SoundGen/<キー>_demo.py` を作り、`SoundGen/demo_out/<キー>_v1_A.wav`・`_B`・`_C` に書き出す（例：ふつう／軽い／重い）。何度も続けて鳴る音は、続けて鳴らした試し聞き（`<キー>_v1_preview.wav`）も作る。わくさんに「どこが違うか」を1行ずつ書いて渡す
3. **直す**：わくさんの言葉で直して `_v2_`、`_v3_`… と番号を上げる。古い案は消さない（わくさんが消す）
4. **決まったら**：`placeholder_sfx.py` のその音の関数を書き換え（`gun_fire_rifle` のように、関数の頭の説明に擬音と長さを書く）、`uv run … placeholder_sfx.py <キー>` で `Assets/Audio/Placeholder/` へ書き出す
5. **やりとり帳に3行**（`docs/worklog.md`）：作った音のキーと、決まった形（長さ・擬音）。依頼票の「状態」を ✅ に

**1つの会話で1〜2音**。終わったら会話を閉じて、次の音は新しい会話で（同じ会話を続けるほど、1手ごとのトークンが増える）。
音は Argon には聞こえないので、聞くのはわくさん。波形の数字（長さ、ピーク）を確かめるのはよいが、wav を丸ごと読み込まない。

## 5. 鳴り方に気をつける音

| キー | 気をつけること |
| --- | --- |
| `slug_squeeze` | 押した瞬間の「きゅっ」のあと、押している間（最大 0.4 秒）体がしまる音が続く。**離すと途中で切られる**ので、どこで切れても変にならないように |
| `slug_lunge` | 伸びる音。溜めた長さで音量が 0.6〜1 倍に変わる。`bag_rattle`（重いバッグの中身）と同時に鳴る |
| `slug_land` | 着地。伸びのあと毎回鳴る。いちばん疲れない音に |
| `bag_rattle` | 跳ねたときのバッグの中身（岩塩のかけら、カブ）。重いほど大きく鳴る |
| `harvest_pop` → `harvest_stage` | 掘れて1個出る音。岩塩のときは続けて「きのこの形が変わる」音も鳴る |
| `gun_reload_open` → `eject` → `insert` → `seat` | この順に続けて鳴る。4つで1つのリロードに聞こえるように |
| `round_hit_slug` | 撃たれても声は出さない（Oct 27 わくさん。`slug_hurt` は鳴らさない）。当たったと分かる音はこれだけ |
| 銃の発射 | ライフル（✅ Oct 25）にそろえる：短い「ボッ」＋塩の粒の「さらさら」。拳銃は軽く、散弾は粒が多く、狙撃は重く遠くまで |

sound_list.md の **B（音がまだない物）** を作るときは、新しいキーの名前を決めて `placeholder_sfx.py` の `SOUNDS` に足し、同じように書き出す。鳴らすコードは Claude がつなぐので、やりとり帳の伝言でキーの名前と「何のときに鳴らすか」を伝える。
