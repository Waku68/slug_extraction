# 籠を運ぶ鳥（Unity のコード版）のモデル票

Oct 30, 2026 · Claude → Argon。**日本語の1枚だけ**（ケルンと同じ。英語版・`_ja.md` はない）。
拠点と鳥の作り直し（`base_rebuild_plan.md`）の1つ目。いまの鳥（Oct 19、Blender で作った物）を、**Unity のコードだけで作り直す**。
作り直す理由は「見た目の味が違う」（わくさん）。ヤシ・ケルンの味（ずんぐり、部品は少なく大きく、ポップ）に寄せる。
参考：いまの鳥の絵 `Screenshots/Creatures/carrier_bird_color_4views.png`（これを1枚だけ見てよい。まねる物ではなく、比べる物）

## 1. ひとこと

拠点に住む1羽の大きな鳥。ナメクジたちを籠に入れて、島へ運んで帰ってくる。卵から育てる相棒で、怪物ではない。魚を食べる海の鳥で、ナメクジは食べない。
ナメクジの目の高さから見て「大きい、やわらかい、人なつこい、ちょっと間抜け」に見えること。**こわく見えたら失敗**。
形の芯は**首を押しつぶしたちびペリカン**：首がなく、頭が胸に直に乗り、大きなくちばしの下にのど袋が垂れる。

## 2. 大きさと置き方

- 立った高さ 約 2.1 m（頭のてっぺんまで、冠羽は入れない）。ナメクジの目の高さ（0.47 m）の約 4.5 倍、人に置き換えると約 7.5 m の鳥。胴の幅 約 1.3 m。案によって変えてよい（8章）
- 翼を広げると、先から先まで 約 7 m（人なら約 25 m）
- 原点は**両足の真ん中の地面**。上は Unity +Y、**くちばしは +Z**、右の翼は +X
- 飛ぶときは、足（＝原点）が籠の輪をつかんで、籠が真下にぶら下がる。だから原点は足の裏の高さから動かさない
- 置くのは Claude（拠点のデッキと、海の口の上の崖の巣）。この作業では置かなくていい
- 比べるナメクジ：体長 1.1 m・高さ 0.5 m のカプセル

## 3. 形のことば

- **ずんぐり**：首は見えない。頭が胸に直に乗る。脚は短い
- **しずく**：胸が前にふくらみ、背中は細くなって、短くとがった尾が少し上を向く
- **大きなくちばし、先は丸い**：くちばしとのど袋が鳥でいちばん大きな部品。先は丸く、とがらない・曲がらない

## 5. 状態

- **立つ**（ふだん）：たたんだ翼を出し、広げた翼は隠す。ナメクジがデッキで見る姿
- **飛ぶ**：たたんだ翼を隠し、広げた翼を出す。足は下にぶら下がる
- 切り替えと羽ばたき（肩で ±35°）はコード（`CarrierBirdMotion`）がする。ビルダーはアニメーションを作らない。**広げた翼が 0° と ±35° のどれでも、肩で割れたり胴に埋まったりしない**こと
- ひなから大人への育ちは、この作業ではしない

## 6. やめて

- 長い首、S 字のペリカンの首。首にしわ・くびれの線
- とがった・曲がったくちばしの先、鋭い爪、にらむ目。こわい物
- 1本ずつの細い羽、毛の筋。羽らしさは柔らかい冠羽と、段になった色の帯で出す
- テクスチャ（いまの鳥のうろこ模様は使わない。8章の3）
- ドラゴン、コウモリ、よろい、鞍、ハーネス、金物。籠は別の物（この作業ではない）
- 細かい部品をたくさん（部品は少なく大きく。遠目の影で鳥と分かればいい）

## 7. 作り方と渡す物

**Blender は使わず、Unity（MCP for Unity）だけで作る**。

- スクリプト：`Assets/Art/Editor/Creatures/CarrierBirdBuilder.cs`（500 行まで。超えたら部品ごとに partial class で分ける）。メニュー `Slug/Creatures/Build Carrier Bird` で、メッシュ・マテリアル・プレハブを全部作り直す。書き方はケルンの `Assets/Art/Editor/Props/CairnBuilder.cs` をまねる（冒頭のコメントに形の数字、`const` に数字をまとめる、マテリアルは `WorldLook.GetOrCreate`）。メッシュの道具は `Assets/Art/Editor/Nature/NatureMeshKit.cs` を使ってよい（直さない。足りない道具は自分のファイルに書く）。乱数は種を固定
- 出来上がり：`Assets/Art/Models/Creatures/CarrierBirdCode/` に、メッシュ（`.asset`）、マテリアル（`.mat`）、プレハブ `CarrierBird.prefab`。**いまの `Assets/Art/Models/Creatures/CarrierBird/` は触らない**（入れ替えは Claude）
- 三角形：広げた翼とたたんだ翼の両方を入れて、全部で 4,000〜10,000
- 当たり判定：胴に CapsuleCollider 1つ、`Neck` の下の頭に SphereCollider 1つ（塩の弾が当たると驚く。けがはしない）
- 見る場所：新しいシーン `Assets/Scenes/Preview/CarrierBirdLook.unity`（平らな地面、太陽、比べるナメクジのカプセル）。拠点のシーンは触らない
- 動きの確かめ（色の段で1回）：見るシーンで、プレハブの根に `CarrierBirdMotion` を付けて再生し、首を回す・かしげる・鳴く・羽ばたくで、すき間・埋まり・割れがないか見る。`CarrierBirdMotion.cs` は直さない（おかしければ伝言で Claude に）
- 撮る絵（README 3章どおり。768 px 以下）：A ナメクジの目の高さ 0.47 m、4 m 前から／B 横から、ナメクジと並べて／C 斜め上から。**立つ姿と飛ぶ姿を並べる**。灰色ラフの3案は 3×3 を1枚に
- 進め方：README 3章のとおり（読み返し票 → 灰色ラフ → 色 → 完成）。**1ステップ＝1つの会話**
- 終わったら、`docs/worklog.md` の記録に3行。この票の 9 章に進み具合を1行
