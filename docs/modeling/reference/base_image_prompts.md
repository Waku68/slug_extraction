## A：断面の全景（全部の設備と、帰り道）

```
ゲームのコンセプトアートを1枚描いてください。横長 16:9。

【何の絵か】
熱帯の海に浮かぶ、白っぽい石灰岩の小島の崖に掘られた、ナメクジたちの工房兼集会所。人間はいない世界。
島を横から切った「断面図」の構図で、手前の岩を取り払って中が全部見える。少し上から見下ろす角度。絵の左下が海、右上が洞窟の奥。

【床：岩の段々と板の通路】
洞窟の床は、水が削った岩の段々。奥（池）が高く、手前（海側のトンネル）が低い3段で、段の差はナメクジの背丈くらい。岩はでこぼこのままで、くぼみに水たまり、割れ目に苔とシダ。
歩く通路だけ、太い流木の梁を岩のこぶからこぶへ渡し、その上に流木の板を並べて平らにしている。板のすき間から下の岩と水が見える。段と段の間は板の階段。水路を渡る所は、低い手すりの付いた板の橋。
設備の場所の多くは、洞窟の壁を凹ませた横穴（丸くえぐった小部屋）に収まっている。

【水：天窓 → 池 → 3本の細い水路 → 水車 → 海】
天井の丸い天窓（直径 4 m、ふちに木の手すり）から光の柱が落ち、真下のいちばん高い段に湧き水の澄んだ青緑の池。
池から3本の細い水路が、岩を削った溝になって段々を流れ下る。小さな落ち口がいくつもある。
1本目（太い）は東を下って、トンネルへの階段の横を小さな滝になって落ち、トンネルの水路を通って出口の大きな木の水車を回す。水車は崖から半分外に出ている。
2本目は染め場の3つの浅い池を順に通り、赤・藍・黄土の色がうっすら付いた筋になって1本目に合流する。
3本目は苗床の足元を通り、地図の台の板の下をくぐって1本目に合流する。

【設備】
中段のまん中：地図の台。直径 5 m くらいの広い円い板の台座の上に、流木の丸い台。古い羊皮紙の地図と、ぶちまけた白い塩の塊・花・キノコ、閉じた帳面。友達のナメクジ4匹がまわりに集まっている。
下段の西：精製所。水車から伸びる太い木の主軸が回す石臼、塩の入れ口、白い粉を押し固める木の型と小さな白い弾。脇の乾いた横穴に、白い塩の壺がきちんと並ぶ棚と、縄で束ねた白い塩の延べ棒が積まれている。
中段の西：細工場。壁を凹ませた横穴に、主軸の先で回る砥ぎ車と作業台、壁にきちんと掛かった道具（ピッケル、殻の板、苔の玉）。
西の壁：太い梁で壁に差しこんだ木の回廊が2段に重なり、板の階段が折り返して上る。2階は乾燥室：ヤシの葉を蒸気タービンのように放射状に並べた羽根車が回り、干し縄に葉や実。3階から短い通路が崖の外へ抜ける。
上段の東：染め場。段のふちの岩をえぐった3つの浅い池と、染めた布を干す竿。
上段の西：苗床。池のふちに、同じ大きさの木の植え箱が2列3つずつ、まっすぐ整然と並ぶ。小さな芽と木の札。
階段を上りきった踊り場の両わき：壁の小さな横穴に、押し葉と石のかけらの見本棚（図鑑）と、来歴の木札を付けた大きな巻き貝の飾り。
下段の東、1本目の水路の横：カタツムリの寝床。湿った岩を丸くえぐった低い横穴に苔が敷かれ、2本足のカタツムリが殻にこもって眠っている。
トンネルの出口の手前の脇：問屋の窓口。カウンターに天秤、奥の壁に植物の籠が並ぶ棚。

【外】
崖の口の外：流木の桟橋に、丸い編み籠（直径 2.4 m、上の輪に4本の綱が集まる）の発着場と、大きな鳥（デフォルメしたペリカン：首をちぢめて頭が胸に乗り、先の丸いオレンジのくちばし、黄色いのど袋、クリーム色の体、立って 2.1 m）。桟橋の横に行商人の丸木舟。
崖の中腹（3階から抜けた先）：流木の台に小さな観測所（風見と予報の板）と鳥の巣。

【生きている感じ】
池に赤い小エビ。天井近くを小さなアナツバメが飛ぶ。岩の割れ目にシダ、濡れた岩に苔、天窓のふちから垂れるつる。しずくが落ちる。

【ナメクジ】
恐竜のように2本足で立って歩くナメクジ。丸い大きな頭、顔の横寄りに小さな黒い長丸の目、頭のてっぺんから先に玉のついた触角が2本 V 字に開く。洋なし形の胴が少し前に傾き、うしろに先のとがった長い尾がまっすぐ伸びる。短く太い2本の足（ひざがある）がはっきり見える。短く細い腕。なめらかでつやのある体。目の高さは床から 0.47 m（広間の高さ 7 m に対してとても小さい）。色は鮮やか（緑、オレンジ、水色、ピンク）。背中に布のバッグ。
カタツムリは同じ2本足の体で、背中から大きな巻き貝の殻が生えている。

【見た目のスタイル】
ずんぐりして、部品は少なく大きい、ポップな 3D ゲームの見た目。トゥーンシェーディング。描いた模様やテクスチャはなく、形の凹凸と単色の面とやわらかい陰影で質感を出す。
硬い物（岩、塩、殻、流木）は、平らな面がカクカク集まった多面体の質感。かじれる柔らかい物（苔、葉、キノコ、つるの縄、布、ナメクジの体）は、なめらかで丸い。
色：世界はくすんだ落ち着いた色（白っぽい石灰岩、流木のベージュ、苔の緑、水の青緑）。ナメクジと鳥だけ鮮やか。灯りは暖かい橙色の油の灯を20個くらい。夕方の光。
雰囲気：硬派で使い込まれた職人の工房。飾りより道具。直した跡とすり減った跡。物は持ち帰った物で埋まっていて、きちんと並んでいる。落ち着く、湿った空気。
描かない物：人間、人の手、レンガ、ガラス窓、金属板、ネジ、魔法、光る結晶、文字、ロゴ、矢印。
```
