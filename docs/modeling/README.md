## 1. 世界観チェック（形を決める前と、ラフを見せる前に、5問とも「はい」か）

1. **人の痕跡はないか**：人類が滅んだあとの熱帯の群島。コンクリート・金属の工業製品・文字・看板は出さない（ナメクジが拾って作り直した物はよい）
2. **ナメクジの手仕事か**：滑車、炭酸ガスの銃、油の灯、流木・つる・ヤシ縄・石・殻。粘液で作る魔法の道具（粘液工学）は出さない
3. **ナメクジの大きさで見て普通か**：世界は等身大。でかい木や岩は目印のときだけ。段差 0.45 m まで登れ、坂は 40〜50° まで歩ける
4. **雨に濡れて、くすんでいるか**：世界の物の彩度はナメクジより上げない。鮮やかなのはキャラと、珍しい物の1か所だけ
5. **シルエットで言えるか**：細部より形を大げさに。部品は少なく大きく。遠目の影だけで何か分かる

ナメクジの好み（形に効く）：湿った所・暗い所・狭い所が落ち着く。塩は敵（武器でもある）。

## 2. 寸法と書き出し（必ず守る）

- 1 単位 ＝ 1 m。ナメクジ：2本足で立って歩く（Nov 2 から）、目の高さ 0.47 m（人の約 1/3.6）、歩く速さ 1.6 m/s くらい（前の這う体は体長 1.1 m・1.2 m/s）
- 大きさは「ナメクジの何倍」と「人に置き換えると」の両方で言う
- 地面に置く物は底の真ん中が原点。上は Blender +Z、Unity +Y
- 滑らかな法線で書き出す。薄い部品（葉、布、板）も厚みのある閉じた形
- テクスチャは描かない（絵そのものが中身の物と、籠を運ぶ鳥の羽の模様だけ例外。Oct 19 わくさん）。部品ごとにマテリアルを分けて色で塗る。名前は `<物>_<部品>`。シェーダーは `Slug/Toon`、世界の物の値は `Assets/Art/Editor/WorldLook.cs`（質感リアル度 0.2）
- 三角形：手に持つ物 300〜1,500、採る場所 1,000〜4,000、名所・拠点の大物 5,000〜20,000（部品ごと）
- 当たり判定は Box・Capsule・凸の MeshCollider で別に作る
- 作り方はスクリプトに残す：`Blender/<種類>/<name>_gen.py` と同じ名前の `.blend`、FBX は `Assets/Art/Models/<種類>/<Name>/`（種類：Harvest・Base・Creatures・Landmarks・Props）。書き出しの設定は `Blender/Harvest/rocksalt_gen.py` の `export_fbx`。空の親に子を入れる入れ子は `bake_space_transform=False, axis_forward='Y', axis_up='Z'` ＋ Unity の Bake Axis Conversion ON（例 `Blender/Base/cenote_furniture_gen.py`）
- **Unity のコードで作るとき**（ケルン Oct 25、拠点と鳥 Oct 30 から）：Blender と FBX は使わない。ビルダー `Assets/Art/Editor/<種類>/<Name>Builder.cs`（500 行まで）、メニュー `Slug/<種類>/Build <Name>`、出来上がりはメッシュ `.asset`・`.mat`・プレハブを `Assets/Art/Models/<種類>/<Name>/` に。見るシーンは `Assets/Scenes/Preview/<Name>Look.unity`。手本は `Assets/Art/Editor/Props/CairnBuilder.cs`
- 使わない試作は消さずに `Assets/_Old/Art/`・`Blender/_Old/` へ

## 3. 進め方（食い違いを防ぐ）

わくさんの OK が出るまで次へ進まない。OK の印は ✅。

1. **読み返し票**（作る前。手は動かさない）：モデル票を読んで、下の形で返す。わくさん ✅ で次へ
   ```
   作る物：〜（1行）
   大きさ：ナメクジの〜倍／人なら〜
   置き場所と向き：〜（+Y が何の方向か）
   何をする所・物か：〜
   世界観チェック：1〜5 で気になる所（なければ「なし」）
   質問：2〜4個（読み違いそうな所。絵の向き、天井の有無、大きさ、場所、使い方。おすすめを1つ目に）
   ```
2. **灰色ラフ**：色なし。案を出すなら3案まで。必ず横に比べるナメクジ（体長 1.1 m・高さ 0.5 m のカプセル）。撮るのは決まった3枚だけ：
   - A ナメクジの目の高さ（0.47 m）から、いちばん大事な向き
   - B 横から、ナメクジと並べて（大きさが分かる）
   - C 真上か斜め上から全体（置き場所が分かる）
3. **色と細部**：✅ の案だけ。同じ3枚で撮る
4. **ゲームに入れる**：FBX → Unity のマテリアル → ナメクジの目の高さから撮る。ここで「完成」
5. **記録**：スクリプト冒頭のコメント（数字はここ）、`docs/README.md` の地図、相手に関係あれば `docs/worklog.md` に3行

**作ったら、わくさんが自分で見られる場面にも置く**（2〜4のどのステップでも。絵を見せるだけで終わらない。Nov 2 わくさん）：島の植物・小物は `Assets/Scenes/Preview/IslandPropsLook.unity`（`IslandPropsLook.cs` の Groups に1行足して、メニュー Slug/Nature/Props/Build Island Props Look で作り直す）、ほかは物ごとの `Assets/Scenes/Preview/<Name>Look.unity`。並べ方は大きさの見本のナメクジの横に A・B・C。いま開いている場面には触らず、場面を足して保存して閉じる（Unity をほかの会話と分け合っているため）。チャットでは場面の場所を言う

直しは「どこを・どう・どれくらい」で受ける。「なんか違う」なら、違いそうな所を3つ挙げて極端に振った版を並べる。

## 5. モデル票の書き方（Claude が書く）

`docs/modeling/<name>.md`（英語、150 行まで）と `<name>_ja.md`（日本語訳、わくさん用）。Unity のコードで作る物は、日本語の1枚だけ（ケルンから。訳なし）。見出しは決まった順に：

## 6. ナメクジの動き（モーション）

Oct 18 わくさんと決めた。**Claude が Unity のコードで作る**（前の這う体はボーンなしで、波・伸び縮みはシェーダーとコード。Nov 2 からの2本足の体は骨で動かす：`docs/character/dino_slug_impact.md`）。Argon はナメクジの体と動きに触らない。
前に食い違ったこと（Oct 3〜14）：腕の位置と浮き方が一人称と他人からで違った、振り返るとお尻が横すべり、縮んで伸びるが「ちょっと速い」、ピッケルの握る所と振り下ろす所、速さの値がコードの初期値と Tuning の2か所にあった。

1. **動き票**（作る前。Claude が書いて、わくさん ✅）
   ```
   動き：〜（1行。遊びで何が伝わればいいか。例：重い塩の塊を、体ごと叩き割る手応え）
   きっかけ：どのボタン／何が起きたら。続けて押したら・途中で離したら
   コマ：構え → 溜め → 動く → 当たる → 戻る。それぞれ「何秒」と「体・腕・道具がどこ」
         （向きは体から見て：右後ろ上、肩の高さ、など。握る所は右手・左手それぞれ）
   当たったら・ぶつかったら：止まる／跳ね返る／めり込まない
   一人称と他人から：それぞれ何が見えるか（腕は一人称では先だけ、など）
   体のついてき方：振り返る・止まる・坂で、尾や体がどう遅れてついてくるか
   音が合う瞬間：どのコマ
   参考：ゲームの動き1つと、どこが良いか
   やめて：〜
   ```
2. **止め絵（キーポーズ）**：動かす前に、コマごとの形を止めて撮る。上の段が一人称、下の段が横から（他人から 3 m）で、1枚に並べる。✅ が出るまで動かさない（形と向きのずれは、ここで見つける）
3. **動かす**：コマ撮り（`MoveFilmStrip`・`SwingFilmStrip`・`GunFilmStrip`。決まった時刻で撮って1枚に並べる）。一人称と他人からの両方を撮る
4. **手触りの数字はわくさんがスライダーで決める**：速さ・溜め・戻りの時間などは、最初から `Assets/Tuning/` の設定アセットにスライダー（Tooltip つき）で出す。Claude が入れるのは最初の値だけで、そのあとは触らない。コードの初期値とアセットの値が違うときは、アセットの値が正
5. **直しの言い方**：「何コマ目の・どこが・どう」（例：3コマ目の左手を柄の下へ）。速さはスライダーで

よくある失敗：止め絵だけで決めて、這う波・伸び縮み・振り返りで壊れる／一人称だけで決める／動きの途中で体や装備が埋まる（いちばん縮んだ瞬間と、いちばん伸びた瞬間を必ず撮る）。

## 8. わくさんの好み（直しから分かったこと）

形を決めるときに、まずここを見る。わくさんのフィードバックが来るたびに Claude が1行ずつ足す（どの物で・いつ）。

- **ポップはずんぐり寄り**：同じ物を3案（曲がり・まっすぐ高い・ずんぐり低い）並べたら、太く低い案が「めっちゃいい感じ」。背を低く、幹や胴を太く、葉や頭を大きめに（ヤシ、Oct 20）
- **知っている物は本物の大きさ**：ヤシの実のように、遊ぶ人が大きさを知っている物は、形をポップにしても本物の大きさ（ヤシの実は直径 約 28 cm）で付ける。ナメクジと比べて大きさが分かる手がかりになる。形に合わせて大きくすると、ナメクジくらいの大きさになって大きさの感じが崩れる（ヤシ、Oct 20）
- **幹や胴は思ったより明るい色に**：Slug/Toon の陰で、細く縦に長い物（幹など）はかなり暗く見える。ヤシの幹は #6E6253 では黒茶に見えて「もう少し明るく」→ #B0A28A にした。色はナメクジの目の高さ（下から見上げる）で Unity で確かめてから決める（ヤシ、Oct 20）
- **のっぺりは形と色の帯で直す（テクスチャは貼らない）**：ヤシの幹が「のっぺりして分かりづらい」→ 節を形で強く（半径の ±10%）して、溝だけ暗いマテリアルの帯にしたら、テクスチャなしで幹らしく読めた。シェーダーのまだら模様（`_MottleAmount`）は FBX の物では見えなかった（ヤシ、Oct 20）
- **カクカクとなめらかは「かじれるか」で分ける**：かじれない硬い物（岩・塩の結晶・貝殻・乾いた木・流木）はカクカク（`_Facet` 1）、ナメクジがかじれるくらいやわらかい物（葉・草・苔・きのこ・海藻・縄・カブ）はなめらか。1つの物の中でも部品ごとに分ける（苔の乗った岩なら、岩はカクカク・苔はなめらか）（島の小物、Nov 2）
- **ナメクジの2倍より大きい物は形を凝る、それより小さい物は質感を凝る**：大きい物（倒れた大木・根の円盤・シロアリ塚など）はシルエットで読ませる（板根・折れた根・折れた枝・めくれた樹皮・裂けた先）。小さい物（岩・切り株・小石・葉・貝など）は表面で読ませる。質感はテクスチャを描かずに、形の細かさ（地層の段・割れ目・欠け・樹皮の溝・木目・葉脈）と Slug/Toon の物の座標のノイズ（`_MottleAmount` むらと点、`_CamoAmount` ぶち、`_DentAmp` 細かいでこぼこ、`_FeltAmount` 粒）で付ける。ぶちの色は地の色から一段だけ離す（離しすぎると迷彩柄に見える）。溝だけ暗いマテリアルにするときは、縦の長い溝だけ（横の切れ目も塗るとレンガに見える）（島の小物、Nov 2）
- **植物はケルン（山登りのゲーム、絵はバンド・デシネの画家）風に**（以後の植物は全部これを手本に。手本のコードは `Assets/Art/Editor/Nature/MassBushBuilder.cs`、絵は `Screenshots/Nature/mass_bush_try.png`）（塊の茂み、Nov 2）：
  - **葉は1枚ずつ描かず、大きな塊で見せる**：茂みや木の葉は 3〜5 個の大きな塊にする。陰は葉の向きでなく塊の丸みで付ける（`NatureMeshKit.Mass`：塊ごとに 1、そのあと全体に半分）。塊の中は描き込まない（ノイズのまだらは大きく弱く、細かいでこぼこ `_DentAmp` は使わない。上の「小さい物は質感」は硬い物のほう）
  - **ふちだけギザギザ**：輪郭からだけ葉先を出す。とがった細い葉先はトゲやサボテンに見えるので、丸い葉の形を半分塊に埋めて、上と外へ向けて、うろこのように重ねる
  - **明るい所は暖かく、陰は冷たく、段は 3 つ**：陰の色は青みの緑（`_ShadeColor` 約 (0.5, 0.62, 0.74)）、段の境目はくっきり（`_BandSoftness` 0.04、`_ToonSmooth` 0.05）、輪郭線は暗い緑。島の空気（`WeatherPresenter.airLook`）で、陰は時刻の色、遠くは空の色に溶ける
  - **群れには主役を1つ**：同じ物を並べず、大きい主役1つと小さい子 2〜3 個
  - **少しだけ揺れる**：風は塊ごとにゆっくり（頂点の色の B を塊ごとにそろえる）
  - 大きな葉が1枚ずつ見える植物（クワズイモ・ヤシ）は、葉そのものを大きな色の面として扱い、葉脈などの描き込みは控えめに
- **跡や遺跡は「崩れて草に埋もれる」まで荒らす**：形は残して何だったかは分かるまま、傾ける・抜く・倒す、地面に沈めて半分埋める、根元に土を吹きだまらせる、苔を乗せる、草を中から突き抜けて生やす、杭や脚につるを巻く（`SlugTraceBuilder` の `Ruin`・`Vine`）。草と苔とつるはケルン風（ナメクジの暮らしの跡、Nov 2）
- **ヤシは細く高い A 曲がり・B まっすぐ高い**：ヤシだけは、ずんぐりより Oct 20 の 3 案の A・B（高さ 8〜10 m、太さ 0.2 m）がいい。立っているヤシ・立ち枯れ・落ちた葉はみな同じ形（`Assets/Art/Editor/Nature/PalmShape.cs`）から作り、見た目をそろえる（ヤシ、Nov 3）
- **珍しい物（高い売り物）は細部を凝る**：塩の魚の灰色ラフを見て「ボトルシップもレア物だからもっと凝って」→ 部品を増やした（ひも・フジツボ・海藻、船の帯・丸窓・帆桁・三角の帆・張り綱・赤い旗）。三角形は手に持つ物の目安（1,500）を超えてよい（いまは 4,500 前後）。鮮やかなのは1か所だけ、は守る（ボトルシップ・塩の魚、Nov 4）
- **全体を太く、手に持てる物ほど太く大きく**：細い部品は目の高さから線や点になって消え、トゥーンの輪郭線に埋もれる。拠点の木材（板・梁・柱・手すり・はしご）は約 1.5 倍の太さで角を大きく丸め、刻みは少なく。手に持てる物（延べ棒・弾・ミニアモレ・灯・塩の塊）は少し大げさに太く大きくして、刻みを増やしてなめらかに。ポリゴンは物ごとに分けてよい。テクスチャは使わない（ポップさが欠ける）（精製所の一角、Nov 5。`Assets/Art/Editor/Base/Refinery/`）
