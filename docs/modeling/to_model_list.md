# 島のためにモデリングする物のリスト

Oct 20, 2026 · Claude（わくさん用。Argon に頼むときは、1つずつモデル票にする）

**Oct 26 追記：無料素材（FinottiGames・Happy Little Trees・Runemark など）は使わないことになり、プロジェクトから外した。島の自然は Claude が Unity のコードで作る。下の「0.」の表は古い。**

木は FinottiGames、草・花・植物・きのこ・茂み・岩・切り株・倒木は Happy Little Trees（色をくすませて Slug/Toon）に決めた。その2つで**足りない物**だけを並べる。
印：◎ 最初の版に要る、○ 島をごちゃごちゃにするのに要る、△ あとでいい。大きさは「ナメクジにとって／人に置き換えると」。

## 0. モデリングしなくていい物

| 物 | どうするか |
| --- | --- |
| 森の木 | FinottiGames の3本（0.25 倍で約 7.5 m） |
| 草、花、植物、きのこ、茂み、岩、切り株、倒木 | Happy Little Trees（0.3 倍） |
| 溶岩の岩、砂岩、流木 | Happy Little Trees の岩と倒木を、色だけ変えて試す（足りなければ作る） |
| 色花（採る花） | Happy Little Trees の花で試す |
| 地面の色むら、砂の風紋、溶岩のひび、塩田の六角のひび | 地形の色とコードで Claude が作る（モデルなし） |
| 置き方（理由のある固まり、近くは細かく遠くは大きく） | Claude のコード（`docs/ideas/map_clutter_ideas.md`） |

## Claude のおすすめの順

1. **大ガジュマル**（森の目印で、いちばん大きい。いまは仮の箱）
2. **ヤシ一式**（これだけで熱帯の島に見える）
3. **ナメクジの暮らしの跡**（拠点の部品で安く作れて、島に世界観が出る）
4. **菌輪のキノコとツユリ**（草原の目印と、次の植物を一緒に）
5. **石橋とベースキャンプ**

区画の小物（3）は、無料素材の色替えで足りるかを先に島で試して、足りない物だけ頼む。
