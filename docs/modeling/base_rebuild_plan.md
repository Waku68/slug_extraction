## コードとの約束

- **鳥**：部品の名前（`carrier_bird_code.md` の4章）と原点（両足の間の地面）は今のまま。名前が同じなら、首を回す・鳴く・羽ばたく・籠を運んで飛ぶコード（`Assets/Base/CarrierBirdMotion.cs`・`CarrierFlight.cs`）がそのまま動く
- **拠点**：名前も並びもゼロからでよい。Argon の形ができたら、Claude がゲームのコード（`Assets/Base/` の拠点を組む・這う試し・リフト・鳥の発着）を付け直す
- 新しい物がゲームに入るまで、古い物（`Blender/Base/`・`Blender/Creatures/`、FBX、`base_cenote.md`・`base_furniture.md`・`carrier_bird.md`）は残す。入れ替えたら古い物は `_Old` へ（消すのはわくさん）
