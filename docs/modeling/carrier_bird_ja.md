# 籠を運ぶ鳥（モデル票・日本語訳）

Oct 18, 2026。わくさん用の訳。Argon が読むのは英語版 `carrier_bird.md`（中身は同じ）。
参考：

- 灰色ラフ2回目のあとの方向（Oct 18）：**首をちぢめたデフォルメのペリカン**。わくさんが見せたペリカンの絵（素材サイトの絵なのでリポジトリには入れない）から取る所を下に書いた。鉛筆の絵の「目の下の線とふくらみ」は、ペリカンののど袋

## 1. ひとこと

拠点に一羽だけいる大きな鳥。パーティを籠に乗せて島へ運び、連れ帰る。シーズンごとに卵から育てる相棒で、怪物ではない。魚を食べる海鳥で、ナメクジは食べない。
ナメクジの目の高さから「大きくて、やわらかくて、やさしくて、ちょっとまぬけ」に見えること。天敵に見えないこと。

## 2. 大きさ

- 立って頭のてっぺんまで約 2.1 m（房は数えない）。ナメクジの目の高さ（0.47 m）の約4.5倍。人に置き換えると約 7.5 m の鳥。体の幅は約 1.3 m
- 翼を広げて、端から端まで約 7 m
- 原点：地面の、両足のあいだの真ん中。上は Blender +Z。くちばしは Blender +Y（書き出すと Unity +Z）
- いる所：拠点のデッキ（ヤシ縄の輪に降りる）と、海側の口の上の崖の巣

## 3. 形のことば

- **ずんぐり**：首は見せない。頭は胸にそのまま乗る。脚は短い
- **しずく形の体**：胸は前へふくらみ、背中は細くなって、短くとがった尾が上を向く
- **大きなくちばし、先だけ丸く**：長いくちばしと垂れたのど袋が、鳥でいちばん大きい所。先は丸く、とがらせない・かぎ形にしない

## 5. 状態

- **立つ**（ふだん）：たたんだ翼を出し、広げた翼は隠す。デッキでナメクジが見る姿
- **飛ぶ**：たたんだ翼を隠し、広げた翼を出す。足は下に垂れ、籠は足から下がる
- 翼の付け替えと羽ばたき（肩で回す）は Unity でする。Blender では動かさない。広げた翼が 0° と上下 ±35° で自然に見えればよい
- ひなから大人への育ちは、あとで（今回は作らない）

## 6. しないこと

- 長い首にしない（ペリカンの長い S 字の首にしない）。短い首はなめらかな1本の曲線で、折れ目にしない
- くちばしの先をとがらせない・かぎ形にしない。鋭い爪、にらむ目もなし。怖くしない
- 細い羽1枚ずつ・毛の束は作らない（羽の模様は上のテクスチャだけ）。羽はやわらかい房と、段の帯だけ
- ドラゴン・コウモリにしない。鎧・鞍・ハーネス・金属なし。籠は別の物（今回は作らない）
- 参考の絵の文字やロゴは入れない

## 7. 渡す物

- スクリプト `Blender/Creatures/carrier_bird_gen.py`＋共通の形の道具 `Blender/Creatures/creature_mesh.py`（500 行まで。print はオブジェクト名・三角形数・エラーだけ）と `Blender/Creatures/carrier_bird.blend`
- FBX `Assets/Art/Models/Creatures/CarrierBird/CarrierBird.fbx`（全部品を root の子で）。入れ子の書き出し設定と Unity の Bake Axis Conversion ON（`cenote_furniture_gen.py` と同じ）
- 三角形は全部で 12,000 まで（いま約 7,800）（広げた翼とたたんだ翼の両方を数える）。滑らかな法線
- 当たり判定は Unity で：体にカプセル1つ＋頭に球1つ（塩の弾が当たると驚く。ケガはしない）
- 進め方：読み返し票 → 灰色ラフ → 色 → Unity、あいだにわくさんの ✅。灰色ラフの絵は A（ナメクジの目の高さで正面から）、B（横から、比べるナメクジと並べて）、C（斜め上から）。立つと飛ぶを並べる
