# 石積みの道しるべ（ケルン）のモデル票

Oct 25, 2026 · Claude → Argon。**この票は試しに日本語で書いた**（英語版・`_ja.md` はない。これだけ読めばいい）。
わくさんが「Argon が Unity でモデリングするとどんな感じか」を見るための、小さな試し。参考の絵はなし。

## 1. ひとこと

昔のナメクジが「塩の道」に沿って積んだ、平たい石の道しるべ。ナメクジの目の高さから、遠目に「ここが道」「道はこっち」と分かればいい。
自然の岩ではなく、**ナメクジの手仕事**（積んだ、縄を巻いた）だと分かること。古くて、苔むしている。

## 2. 大きさと置き方

- 高さ 0.8 m：ナメクジの目の高さ（0.47 m）の約 1.7 倍、人に置き換えると約 2.9 m の石の塔。這っているナメクジから見て、少し見上げるくらい
- 底の幅 0.6〜0.7 m（人なら約 2.3 m）。上へ行くほど細く、ずんぐり
- 原点は底の真ん中、地面の高さ。上は Unity の +Y。**+Z が「道の進む向き」**（いちばん上の細長い石の先がそちらを指す）。下の石は 5 cm 地面に埋めて、でこぼこの地面でも浮かないように
- 置くのは Claude（塩の道に沿って 40〜60 m ごと）。この作業では置かなくていい
- 比べるナメクジ：体長 1.1 m・高さ 0.5 m のカプセル。段差 0.45 m まで登れる（ケルンには登れなくていい）

## 3. 形のことば

- **ずんぐり**：背を低く、石を太く大きく。わくさんは細く高いより太く低いが好き
- **ころん**：石は角を丸めた平たい楕円の塊。割れた岩のとがった形ではない
- **ちょっと傾く**：石ごとに 3〜8° 傾け、真ん中から 2〜5 cm ずらす。きれいに揃った柱にしない

## 4. 部品

`Cairn_A` などの空の親 → 下の部品。面はカクカク（`WorldLook` の Flat Facets、ヤシのカクカク版と同じ）。

## 5. 状態（3つ作る）

- `Cairn_A` 立っている：高さ 0.8 m、石 7 個、縄あり
- `Cairn_B` 低い：高さ 0.55 m、石 5 個、縄あり
- `Cairn_C` 崩れた：下の 2〜3 個だけ残り（高さ 0.35 m）、落ちた石 2〜3 個が横 0.5〜1 m に転がる。縄は切れて地面に落ちている（輪ではなく、ゆるいひも）

## 6. やめて

- 文字・矢印・模様の彫り、看板、木の札（人の痕跡になる。指すのは上の石の形だけ）
- 塩の結晶を載せる、光る石、鮮やかな色（世界はくすんだ色。ナメクジより目立たない）
- 完璧に揃った円柱や、レンガのように四角い石
- とがって割れた岩、ぎざぎざの縁（ポップで丸く）
- 石を何十個も積む細かい形（部品は少なく大きく。遠目の影で「積んだ石」と分かればいい）

## 7. 作り方と渡す物

**Blender は使わず、Unity（MCP for Unity）だけで作る**（今回の試しの目的）。

- スクリプト：`Assets/Art/Editor/Props/CairnBuilder.cs`（300 行まで）。メニュー `Slug/Props/Build Cairn` で、メッシュ・マテリアル・プレハブを全部作り直す。書き方はヤシの `Assets/Art/Editor/Nature/PalmBuilder.cs` をまねる（冒頭のコメントに形の数字、`const` に数字をまとめる、マテリアルは `WorldLook.GetOrCreate`）。メッシュの道具は `Assets/Art/Editor/Nature/NatureMeshKit.cs` を使ってよい（直さない。足りない道具は CairnBuilder の中に書く）。石の形は乱数の種を固定して、何回作り直しても同じ形にする
- 出来上がり：`Assets/Art/Models/Props/Cairn/` に、メッシュ（`.asset`）、マテリアル（`.mat`）、プレハブ `Cairn_A` `Cairn_B` `Cairn_C`
- 三角形：1つあたり 300〜900
- 当たり判定：`Cairn_A`・`Cairn_B` は CapsuleCollider 1つ（石の塊を包む）。`Cairn_C` は残った石に BoxCollider 1つ、転がった石は判定なし
- 撮る場所：新しいシーン `Assets/Scenes/Preview/CairnLook.unity`（Oct 26 にここへ移した）（平らな地面、太陽、比べるナメクジのカプセル）。いまの島のシーンは触らない
- 撮る絵（`docs/modeling/README.md` の3章どおり、決まった3枚だけ。768 px 以下）
  - A ナメクジの目の高さ 0.47 m、3 m 手前から（+Z を指す石が分かる向き）
  - B 横から、ナメクジと並べて
  - C 斜め上から A・B・C の3つ並び
- 進め方：README 3章のとおり（読み返し票 → 灰色ラフ → 色 → 完成）。**1ステップ＝1つの会話**
- 終わったら、`docs/worklog.md` の記録に3行（作った物の場所／決めた数字はスクリプト冒頭／Claude に頼むこと）
