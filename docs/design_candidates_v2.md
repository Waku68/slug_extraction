# キャラデザイン候補 v2（配色と目の調整）

v1 の9体は**形をそのまま**にして、色と目だけを直した。方向性は「雨に濡れた自然に溶け込む落ち着いた見た目」。
初期の体色は保護色、鮮やかな色は後からゲーム内で手に入れるレア色、という位置づけにした。

- シーン：`Assets/Scenes/SlugGalleryV2.unity`（暗い雨の背景。苔系×控えめな目の9体）
- スクリーンショット：`Screenshots/v2/`
- v1 のシーン・スクリーンショット（`Screenshots/` 直下）はそのまま残してある

## 変えたもの / 変えていないもの

| 変えた | 変えていない |
| --- | --- |
| 体色・影色・腹色・模様色・輪郭線の色 | 体・耳・手のメッシュ（同じ生成コードから作るので v1 と同一） |
| ほっぺの色と大きさ | 顔の位置、口、うねりの動き、トゥーンのシェーダー |
| 耳・手・背中の突起の色（体になじむ色に） | 各案のパラメータ構成（縫い目、凹凸、半透明、フリル、ファセット） |
| 目の大きさ・ハイライト・まぶた | |

## 色（3パターン）

彩度を大きく下げ、本物のナメクジの体色に寄せた。縞・水玉などの模様は、体色との差を小さくして透明度を下げた（斑点や、かすかな模様くらい）。
輪郭線は体色を暗くした色（濃い緑固定ではない）、太さも v1 の約7割にした。

| 配色 | 体色 | 腹色 | 模様色 | イメージ |
| --- | --- | --- | --- | --- |
| 苔系（moss） | `#6E7A4C` | `#A4AA82` | `#4C5A36` | 濡れた苔むす倒木 |
| 土系（earth） | `#7C5F49` | `#B19B7E` | `#563F30` | 樹皮・湿った土 |
| 灰系（gray） | `#878A84` | `#BAB9AE` | `#64686A` | 濡れた石・ヒョウモンナメクジの灰色 |

- ほっぺは体色に寄せた色にして、大きさも6割にした（ごく薄い赤み）。
- 耳・手・背中の突起は、体色と腹色の中間（体色寄り）に統一した。黄色などの差し色はなくした。
- きらめき（グミ型・結晶型）は強さを約半分にし、色も体色寄りの白にした。
- レア色の位置づけの確認用に、v1 のポップ配色を `pop_subdued` として残した（`overview_rare_pop.png`）。

## 目（3パターン）

目の大きさ・形・ハイライトだけを差し替える。色は黒に近い焦げ茶に変更。

| 目 | 内容 |
| --- | --- |
| 今より控えめ（subdued） | v1 の約82%の大きさ。ハイライトは小さいものを1つだけ（v1 は大小2つ） |
| 点目（dot） | v1 の約4割の小さな丸い目。ハイライトなし |
| 眠たそうなまぶた付き（sleepy） | 控えめな目の上に、体より少し暗い色のまぶたが半分かぶさる。外側が少し下がる |

## 気づいたこと

- 3配色とも、雨の背景ではっきり地味になった。灰系は寒色のライトの影響で青みがかって見える。灰系を採るなら、ライトの色との相性を見てから決めたい。
- 点目は「落ち着いた」方向に一番振れるが、表情の変化が出しにくく、ほっぺと口に頼る形になる。
- まぶた付きは表情が出る反面、まぶたの出っ張りが顔の輪郭にうっすら見える案がある（頭でっかち型など）。形は変えない前提なので、そのまま残している。
- 控えめな目は、v1 の「かわいさ」をほぼ保ったまま落ち着いて見える。最初の候補にはこれが無難。
- 「ポップすぎる」のは配色が主因で、形はどの案もそのままで落ち着いた雰囲気になった。

## 作り直す手順

Unity メニューの `Slug` から。

1. `Slug > V2 Build Variants` — 配色×目の6種類のプレハブを `Assets/Slug/GeneratedV2/` に生成
2. `Slug > V2 Build Scene` — 雨の背景のシーンを生成
3. `Slug > V2 Capture Screenshots` — `Screenshots/v2/` に書き出し

配色は `Assets/Slug/Scripts/Editor/SlugLook.cs`（`Palette` と `EyeStyle`）で定義している。色の調整はそこの値だけでよい。
