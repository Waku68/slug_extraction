# 道・けものみち・石橋

先に [README.md](README.md) の共通のやり方。

## 作る所
- 道とけものみちは **地形を掘る**（`IslandTest800Paths.cs` の `CarveRoads`）。石橋は **モデル**（`BuildRingBridges`、今は仮）

## 決める数字
| 部分 | 数字（今） |
| --- | --- |
| 道 | 15° まで。通せない所は 22°・30° まで急にして通す。それでもだめな区間は切れ目 |
| けものみち | 道より細く、急でいい（尾根道は 38〜48°） |
| 肩の道 | 山を一周、671 m。谷の頭は石橋 |
| 這う速さ | 軽い 1.2 m/s、重い 0.36 m/s |

## 作り方
- `FindPath`（いちばん急な角度と曲がりやすさを決めて地形の上を探す）→ `Smooth` → `Profile`（道の高さ）→ `Carve`（幅、肩、溝）
- 道を先に、けものみちをあとから掘る。川を渡る所は道をあとから切り込む

## 確かめる（数字）
- `Measure Ways`（道ごとの長さ、時間、いちばん急）。50° を超える所の長さ（肩の道に 87 m 残っている）

## 撮る
- `Shoot Ways And Cover`（道の上からナメクジの目）

## 本物の手本
- 山のつづら折り、けものみちは尾根と水場をつなぐ（山岳ガイドの話：`discussions/island_flow_discussion.md`）

## 失敗しやすい
- 道のまわりに急な所ができる（掘った肩が崖になる）
- 道が見えすぎて、地形の形が負ける。道は色を薄く、細く
