# 隠れる物・岩・木の散らし

先に [README.md](README.md) の共通のやり方。名所の大物は [../map.md](../map.md)。

## 作る所
- コードのモデルを並べる（`PlaceCover`）。形は仮：岩は `RockMesh`（でこぼこの球 5 種類）、木は `Tree`、倒木は `Log`、草むらは `Soft`
- 見た目の本番は Blender でシード違いを 3〜5 種類（[../map.md](../map.md)）

## 決める数字（区画ごとの間隔）
| 区画 | 物と間隔（m） |
| --- | --- |
| 雨の森 | 木 8（高さ 5〜9 m、ときどき 10〜13 m）、下草 6.5、倒木 20、苔の岩 22 |
| 花の草原 | 草むら 6（体の高さ）、岩 30 |
| 砂漠 | 砂岩 22、乾いた茂み 16、流木 34 |
| 台地の上 | 岩の柱 22（2.5〜5.5 m） |
| 溶岩原 | 溶岩の岩 14 |
| 塩田 | 真ん中の大岩1つだけ |

## 作り方
- 矢を投げるように置き、近すぎる所はやめる（区画ごとの間隔）
- 急な所（38° より上）、道、川、塩田、海、キャンプ・池・泉のまわりには置かない
- 門（尾根の下、洞窟の口）の手前は厚くする

## 確かめる（数字）
- 区画ごとの数、見通し（森 20〜40 m、開けた所 60〜120 m）

## 撮る
- 区画ごとにナメクジの目で1枚、空から1枚

## 失敗しやすい
- 人の目線で間隔を決める。ナメクジの目は 0.47 m、草 30 cm で前が見えない
- 当たり判定に見た目のでこぼこを入れて引っかかる
