# 崖・張り出し

先に [README.md](README.md) の共通のやり方。

## 作る所
- 75° までは **地形**。それより急、垂直、張り出しは **モデル**（滝つぼの岩壁と同じ「角度ごとの断面」か「断面 × 道筋」）
- 近くで見る崖の細かさは、地形を細かくせず、モデルの岩をすそに置いて出す

## 決める数字
| 部分 | 数字（今） |
| --- | --- |
| 地形の崖の角度 | 72〜75°（もっと急は、0.94 m ごとの地形で櫛の歯の筋が出る） |
| 層の崖（砂岩） | 下から：落ちた岩のすそ 40° → 下の崖 72° → 岩棚 → 柔らかい斜面 40° → 細い岩棚 → 上の崖 75°（壁 45 m のとき 4・12・0.5・10・0.3・18.7 m） |
| 岩塩の山の崖の帯 | 62〜88 m を 約 75° で囲む。尾根4本だけが抜ける |
| 登れる所 | 崩れて 33° の坂の所。50° より急は登れない |

## 作り方
- 崖の形は `WallAt`（ふもとからの距離 → 高さ）を使い回す。高さを変えるときは `WallFromFoot` で縮める
- 崩れて登れる所は、決まった場所（`MesaBreaks`）＋ノイズ。必ず登れる所を2〜3か所決めておく
- 縞は形でなく色（5 m ごと、少し波打つ）

## 確かめる（数字）
- 50° より急な地面の割合と場所（`Measure Flow` の地図の赤）
- 崖の上と下を行き来する時間（崩れた坂を通る）

## 撮る
- 崖のふもとから見上げる1枚、崖の上から見下ろす1枚、空から1枚

## 本物の手本
- ユタ・アリゾナの砂岩の谷（硬い層は崖、柔らかい層は斜面、すそに落ちた岩）

## 失敗しやすい
- 75° より急にして櫛の歯
- 崖の計算が隣の区画まで削る（谷の崖が岩塩の山の西を削っていた）。削る範囲を区画の中に限る
- 崖ばかりで、登れる所が分からない。崩れた坂は遠くから見える形（扇形の岩のすそ）に
