# 峡谷・谷

先に [README.md](README.md) の共通のやり方。崖の断面は [cliff.md](cliff.md)。

## 作る所
- **地形**（`IslandTest800Canyon.cs` の `Canyon`）。台地の中だけを削る

## 決める数字
| 部分 | 数字（今） |
| --- | --- |
| 谷底の幅 | 口で 約 20 m（`CanyonFloorWidth` 24）、奥で 約 8 m |
| 谷底の上り | 口から奥まで 6 m（`CanyonFloorRise`） |
| 台地 | 50 m（`Mesa`） |
| 脇の谷 | 3本。床が上っていって壁の高い所で終わる。1本は台地の上まで這い上がれる（約 34°） |
| 扇状地 | 口から砂漠へ、高さ 2 m・50 m くらい |

## 作り方
- 谷の線（`CanyonSvg`）から距離で谷底 → 層の崖。蛇行、ふくらむ所（岩の窪み）と細る所、奥ほど細く
- 谷底は砂の色、涸れ川の筋。奥は涸れ滝の行き止まり、下にくぼみ
- ところどころ壁が崩れて 33° の坂（谷から登れる）

## 確かめる（数字）
- 谷底の幅のいちばん狭い所、口から奥までの時間、谷から台地へ上がれる所の数

## 撮る
- 口から中へ、谷底から奥の壁、台地のふちからのぞく、空から（`Shoot Views` の 03・04・14・15・air_canyon）

## 本物の手本
- ユタ・アリゾナの砂岩の谷、カウアイ島のワイメア渓谷

## 失敗しやすい
- 谷を削る計算が台地の外まで及ぶ
- 谷底が平らすぎて退屈。蛇行と幅の変化、落石で見通しを切る
