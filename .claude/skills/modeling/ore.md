# 鉱石・塩

Blender のスクリプトで作り、`Slug/Toon`（`WorldLook`、リアル度 0.2）で描く。お手本は `Blender/Harvest/rocksalt_gen.py`（今の本番：採る場所 `RockSalt_Node_A〜C` と手に持つ塊 `RockSalt_Chunk_A〜C`）、`rocksalt_mushroom_gen.py`（塩のきのこ）、`Blender/_Old/rocksalt_v2_gen.py`（形の考え方10種の見比べ。試作なので _Old）。Unity でシーンに置くのは `Assets/Art/Editor/HarvestVisuals.cs`、段階の切り替えは `Harvestable`。

塩は重くて小さい資源。**叩いて採る気持ちよさ** と **「塩だ！掘ろう！」と一目で分かること** が形の目的。種類と産地は spec.md 6章（粗塩＝塩田、黒い塩＝溶岩台地、岩塩＝洞窟の山）。

## 追加の欄（共通の型に足す）

```
【産地・種類】 どの区画の、どの塩（鉱石）か
【塩らしさの手がかり】 何で「塩だ」と分かるか（立方体の結晶、割れ口の真っ白、足元の欠片、水位の跡の輪…）
【段階】 何段で減るか（例：満タン → 掘りかけ → 切り株）。1段で何が無くなるか
【叩く所】 ピッケルが当たる場所（かさの縁、割れ目、表面全体）
【出てくる塊】 大きさ（地面で 20 cm、手に持つと 30 cm に見せる）、形の種類（A／B／C）
【欠片】 叩いたときに飛ぶ小さな欠片（2〜5 cm）
【育ち戻り】 戻る途中の姿を見せるか（乾くと育つ、雨では育たない）
【周り】 根元の地面、混ざる岩、置かれる地形（洞窟の床、塩田のひび）
```

## 作る物（1種類ごとに）

| 物 | 名前の例 | 中身 |
| --- | --- | --- |
| 採る場所の段階 | `<Name>_Node_Full／Half／Stump` | 段階ごとに別メッシュ。1段ずつシルエットが目に見えて減る |
| 形違い | `_A／_B／_C` | シードを変えて。並べたときに同じに見えないように |
| 塊 | `<Name>_Chunk_A／B／C` | 手でつかんでバッグに入れる1個 |
| 欠片 | `<Name>_Shard_A／B／C` | 叩いたときに飛ぶ（エフェクト用） |

## 決まり

- マテリアルは部品ごと：岩（`_Rock`）、結晶（`_Crystal`）、割れたばかりの面（`_Fresh`、真っ白で一番明るい）。岩塩は今の本番の `RockSalt_Rock`・`RockSalt_Crystal`・`RockSalt_Fresh` を使い回し、違うのは形だけにする
- 塩らしさは形で：岩塩は立方体に割れる（へき開）、骸晶（面が階段状にくぼむ）。粗塩は平たい白い皮と六角形のひび。黒い塩は暗い溶岩に白・灰の結晶
- 段階は 10 m 先からでも読める差にする（半分になったら、本当に半分の量に見える）
- 叩く所は面が大きく、ピッケルが刺さる向きに向いている。叩く所に割れたばかりの白い面を見せると「ここを叩く」が伝わる
- 塊は重くて小さく見える：密で角ばった形。植物より小さく、詰まった感じ
- 当たり判定は段階ごとに形に合わせる（`Harvestable.FitBox`）。切り株になったら這って乗り越えられる高さか、避ける大きさか

## 進め方

1. spec 6章の「塩」と、既存の見比べ（`RockSalt/V2/`、`Mushroom/`、`Realism/`）を見る
2. ラフは **形の考え方3案**（`rocksalt_v2_gen.py` のように、塩らしさの手がかりを変えて）。ナメクジと並べ、這う目の高さと 10 m 先から撮る
3. 選んだ案の段階（満タン → 掘りかけ → 切り株）と塊・欠片を作る。段階を横に並べて1枚撮る
4. 書き出して `HarvestVisuals` に足し、ExtractTest で叩いて、段階が変わる・塊が出る・手に持つまで通して撮る
5. スクリプト冒頭に形の考え方を書く。`docs/README.md` の `Art/Models/` の行に足す

## 記入例（黒い塩）

```
【作る物】 黒い塩 ／ 鉱石
【ひとこと】 溶岩の割れ目から、白い塩の結晶がにじみ出ている
【形のことば】 ごつごつ、かくかく、平たい
【大きさ】 満タンでナメクジの体長くらいの幅、高さは目の高さまで
【どこから見る】 這う目の高さ、溶岩洞の暗がりで 10 m 先から
【変わる】 満タン → 結晶が半分 → 割れ目だけ（3段、叩く6回で塊3個）
【色】 黒い溶岩、灰色がかった白の結晶、割れ口は真っ白
【塩らしさの手がかり】 割れ目に沿って並ぶ小さな立方体
【叩く所】 割れ目の結晶の束
【出てくる塊】 黒い岩が少し付いたままの白い塊
【参考】 ハワイの溶岩の割れ目
【やめて】 光らせない（溶岩はもう冷えている）
【何案】 3案
```
