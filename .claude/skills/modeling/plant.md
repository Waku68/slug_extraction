# 植物

Blender のスクリプトで作り、`Slug/Toon`（`WorldLook`、リアル度 0.2）で描く。お手本は `Blender/rainturnip_gen.py`（畑と抜いた1個）と `Blender/ugotake_gen.py`（倒木の上に並べて1本ずつ摘む）。Unity でシーンに置くのは `Assets/Art/Editor/HarvestVisuals.cs`。

植物の名前・場所・条件・値打ちは spec.md 6章の表。**「その植物だけの理由」を形で見せる** のが一番大事。

## 追加の欄（共通の型に足す）

```
【その植物だけの理由】 spec の表の一言（例：晴れ間の1時間だけ咲く）。それが形のどこに出るか
【採り方】 手で摘む（E）／ ピッケルで叩く ／ 拾う（大物）
【生え方】 1本だけ ／ 3〜5本の群れ ／ 一面 ／ 倒木や岩の上
【手に持った1個】 大きさ（10〜20 cm が目安）、どこを持つか
【状態】 生えている ／ 摘んだあと（何が残る）／ 根ごと掘った形（球根・根株）／ しおれた ／ 季節の色
【珍しさの見せ方】 大きさ・花の形・かすかな光など（色や星では出さない）
【周りの物】 一緒に作る物（倒木、湿った窪み、岩の割れ目）
```

## 作る物（1種類ごとに）

| 物 | 名前の例 | 中身 |
| --- | --- | --- |
| 生えている形 | `<Name>_Node_A／B` | 地面に植わった姿。採ると出てくる物が植わっているなら、植わっている物は手に持つ1個と同じ大きさ・同じ原点で作り、Node は周り（土の小山など）だけにする。畑で目立たせたい所（葉など）だけ別の版で大きくしてよい（雨カブ：葉の大きい `Planted` を小山に半分埋めて植え、掘ると同じ玉の `Item` が同じ所から出てくる） |
| 手に持つ1個 | `<Name>_Item` | 摘んだ・抜いた1個。手で持つ所が分かる形 |
| 摘んだあと | `<Name>_Picked` | 茎だけ、切り株、くぼみ（また生えるまでの姿） |
| 状態違い | `<Name>_Dry`、`<Name>_Red` | しおれ、季節の色。形を変えずにマテリアルだけで済むなら作らない |

## 決まり

- 薄い葉・花びらにも厚みを持たせて閉じた形に（輪郭線が出るように）。両面描きに頼らない
- 植物は軽くてかさばる資源：手に持つと「ふわっと大きい」。塩の塊より、大きさの割に軽そうに
- 色は部品ごとに 2〜4 色。世界のくすんだ色より少し明るくしてよい（雨カブの葉は「ナメクジの苔色より明るい緑」）。幻の物だけ彩度か光で目立たせる
- 手で摘む物は、這う目の高さ（0.47 m）から見えて、近づいたら摘む所が分かる。ピッケルで叩く物は、叩く所（根元、球根の頭）がはっきり見える
- 群れはシードを変えた同じ部品の並べ替えで作る。1本ずつ摘めるなら、1本ずつ別オブジェクト
- 当たり判定は摘む用の小さな Box／Capsule。這うのを邪魔しない（大きな物は別）

## 進め方

1. spec の表と、話し合い（`plants_discussion.md`、`plant_names_discussion.md`、`plant_uses_discussion.md`）を読む
2. ラフは **シルエット3案**（例：ツユリ＝しずく形の一輪 ／ 低く広がる星形 ／ 茎の先に垂れる鈴）。ナメクジと並べて、這う目の高さと、手に持った一人称の2つから撮る
3. 選んだ案に色と状態違いを足す
4. 書き出して `HarvestVisuals` に足し、ExtractTest に置いて、摘む・叩く・手に持つ・バッグに入れるまで通して撮る
5. スクリプト冒頭に「形の考え方」と色を書く。`docs/README.md` の `Art/Models/` の行に足す

## 記入例（ツユリ）

```
【作る物】 ツユリ ／ 植物
【ひとこと】 大雨のあとの晴れ間に、湿った窪みで1時間だけ開く白い花
【形のことば】 ひょろ長い、くたっと、しずく
【大きさ】 花まで 25 cm（ナメクジの目の高さの半分）。花は手に持つと 10 cm
【どこから見る】 這う目の高さ、5 m 先で「あ、咲いてる」と分かる
【変わる】 つぼみ（閉じたしずく）→ 開いた花 → 摘んだあとの茎だけ。根ごと掘ると球根
【色】 花は白に少し青、茎と葉はくすんだ緑、球根は薄茶
【その植物だけの理由】 晴れ間の1時間だけ → つぼみと開いた花の差を大きく
【採り方】 花は手、球根はピッケル
【生え方】 窪みに 2〜3 本
【珍しさの見せ方】 開くと花びらが水滴を抱えている
【参考】 カタクリの花のうつむき方
【やめて】 チューリップっぽい形
【何案】 3案
```
