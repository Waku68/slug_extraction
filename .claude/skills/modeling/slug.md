# ナメクジ（体、装備、バッグ、銃・道具）

ナメクジまわりは **全部 Unity のコード** で作っている（ボーンなし、這う動きは頂点シェーダー）。Blender で作った形は這う波・伸び縮みに乗らないので、基本は使わない。

| 物 | コード | 見比べるシーン |
| --- | --- | --- |
| 体と顔 | `SlugPop`（要素別のスライダー）、`SlugMeshFactory`（`Loft`・`PathLoft`・`ConeHand`…）、シェーダー `Slug/Toon` | `SlugLookbook`（`Slug/Lookbook Build Scene`） |
| 装備（ヘルメット、殻板、バッグ、カタツムリの殻） | `SlugEquipment`（`GearMesh` で作り、`GearFollower` で体の表面に沿わせる） | `EquipTest`（3体並び） |
| 銃・道具 | `SlugRifle` などの形のクラス（`ProfileMesh` の押し出し・回転体・管）、`SlugGunModel.Warp` | `GunTest`、コマ撮り `GunFilmStrip` |
| 腕 | `SlugArmMesh`（ベジェに沿った管） | `SwingTest` |

今の値は `docs/character/design_params.md`、道具の作り方は `docs/tech/tool_craft_notes.md`。

## 追加の欄（共通の型に足す）

```
【部位】 体 ／ 顔 ／ 装備（どれ）／ バッグ ／ 銃・道具（どれ）
【付く場所】 体のどこ（頭、背中、尾の近く…）、何で支える（ベルト、紐、手）
【見せる場面】 一人称の画面 ／ 他人から（10 m・30 m）／ 左上の小さな自分 ／ 地面に置いたとき
【他人から分かること】 シルエットで何が分かればいいか（銃の種類、バッグの膨らみ、装備の強さ）
【動く部品】 開く・外れる・回る・膨らむ所（マガジン、ふた、ボルト、バッグの口）
【手で持つ点】 右手・左手が握る所（道具）
【状態】 空・半分・満タン、壊れかけ、破れた、濡れた
【塩らしさ】 塩・炭酸ガス・手袋など、この世界の物らしい手がかり
```

## 部位ごとの決まり

### 体と顔
- 形の言葉はスライダーに置き換える（「もっと丸く」→ 丸みのスライダー、など）。直すときは新しい値を `SlugLookbook.ApplyCurrent` に入れ、`design_params.md` を直す
- 気持ち悪く見えないことが最優先。濡れたテカリを描かず、マットな単色、輪郭は丸く
- 這う動きは全身の伸び縮み ±3.5% ＋ 尾から頭への波。形を変えたら動かして撮る（`MoveFilmStrip`）

### 装備・バッグ
- 体の表面に沿わせる（`GearFollower` の体の長さ方向の位置と角度）。伸び縮みではみ出さない・埋まらないかを、縮んだ瞬間と伸びた瞬間の両方で見る
- バッグは柱1（埋まっていく充足感、保持の緊張感）をそのまま形にする：中身の量で膨らみ、ふたは後ろへ開く。地面のバッグも同じ形。耐久が減った・破れたが形で分かる
- 左上の小さな自分（`SelfPortrait`）でも、膨らみが読めるか

### 銃・道具
- 形は本物の大きさで作り、`SlugGunModel.Warp` で手前を縮めて銃身を長く見せる（`BodyScale` 0.75 など）。動く部品は丸ごと縮めて位置だけ同じ変換で動かす。持つ側は縮めた後の座標しか見ない
- 動力は炭酸ガス（ボンベの付き方で銃の種類が分かる）。弾は塩
- 一人称では画面の右下に収まるか、照準をふさがないか。他人からは 30 m でシルエットで種類が分かるか
- 握る点（右手・左手、マガジンを持つ点）は名前を付けた定数にして、腕がそこへ伸びる
- 一人称の道具は目に向かって縮めて描く（めり込み防止）。形を変えたら一人称と体の両方で撮る

### Blender を使うなら
ヒーロー版の銃など、どうしても Blender で作りたいとき：握る点・銃口・マガジンの軸を空のオブジェクト（`Grip_R`、`Grip_L`、`Muzzle`、`MagPivot`）にして一緒に書き出し、動く部品は別メッシュに分ける。`Warp` をどう当てるかは未決定なので、作り始める前にわくさんに聞く。

## 進め方

1. 今の形を撮る（直す前の絵）。見せる場面ごとに1枚
2. ラフは **コードの値を振った版** を3つ並べる（例：ボンベを銃床／下／前）
3. 選んだら詰める。動く部品は動かしてコマ撮りする
4. 決定値を設定アセットか定数に入れ、`tool_craft_notes.md`・`design_params.md` を直す

## よくある失敗

- 止まった絵だけで決めて、這う波・伸び縮み・振りで破綻する
- 一人称だけ、他人からだけで決める（両方見る）
- 細かい部品を足しすぎて、10 m 先でただの塊に見える
